Manifolds

From micron reference
micron reference › Numerics and mathematics

Compile-time manifold policies over fixed vector/matrix point representations, concrete SO/SE Lie-group values, tangent-space/metric operations, and borrowed batched SO3/SE3 actions. A manifold policy describes operations; its point and tangent values hold the numeric data.

Manifold selection and representation

The complete umbrella is math/manifolds/manifolds.hpp. Dimensions describe mathematical coordinates and do not necessarily equal object storage: SO3 owns four quaternion coefficients while its traits report ambient_dim=9. In addition to each policy's dimension constraints, vec<F,N> requires 2<=N<=16 and N*sizeof(F)<=128, and mat<F,R,C> requires positive extents with R*C*sizeof(F)<=1024. Extended-precision vector policies and large matrix policies therefore have tighter usable extents than their own dimension clauses alone imply.

Operations and mathematical guarantees

Free identity/compose/inverse/between/act wrappers delegate to static policy methods. between defaults to inverse(a)*b when a specialized method is absent. Group interpolate uses a specialized method or a*exp(t*log(a^-1*b)); non-group interpolate uses exp_map(p,t*log_map(p,q)). geodesic requires a base-point exp_map and is not automatically supplied by the one-argument Lie-group exponential.

Concept satisfaction checks a subset of expressions, not every wrapper or mathematical axiom. Some policy methods intentionally provide approximations under standard names: Stiefel exp/log/parallel transport and several inverse retractions are specified in their type entries. Input points must satisfy unit, orthogonality, positivity, or group invariants unless explicitly projected; no universal validity checker or status result is supplied.

Storage, lifetime, and concurrency

Embedded manifold policies have static functions and no owned point state. Point/tangent vec/mat values and concrete Lie-group members own fixed inline arrays/scalars; copying is proportional to stored extent, and operations use fixed automatic scratch rather than a heap. Matrix decompositions can require full N-by-N working matrices even when a point has only P columns. No allocator or runtime workspace parameter is exposed here.

Methods do not retain references or maintain mutable caches. Separate result/output storage supports concurrent read-only use of valid points and group values. Mutation requires synchronization. Borrowed batch views retain only addresses and require caller-controlled extents/lifetimes; destruction or relocation of the arrays invalidates them. No iterators are provided.

Lie-algebra helpers

hat_so3 maps a three-vector to its 3x3 cross-product skew matrix; vee_so3 extracts entries [2,1],[0,2],[1,0] without checking skew symmetry. hat_se3 embeds the translation-first six-vector in a 4x4 algebra matrix; vee_se3 extracts the corresponding six entries without checking the homogeneous row. These fixed conversions cost O(1). hat_son and vee_son are identity matrix copies, O(N²), rather than compact coordinate packing or skew projection.

lie_bracket(X,Y)=X*Y-Y*X performs two dense products, O(N³) work and O(N²) temporary storage. algebra_exp/algebra_log accept general square matrices and do not enforce Lie-algebra/group membership; their output follows the underlying real matrix-function algorithm and diagnostic checks.

Numerical limits and diagnostics

Specialized low-dimensional methods use fixed small-angle polynomials and transcendental formulas, with no user convergence tolerance. SVD/eigensystem/matrix-function wrappers use their underlying fixed defaults and often discard convergence/existence flags. Invalid or rank-deficient data can therefore yield a numeric fallback or NaNs without a manifold status object.

Sphere antipodal logarithms and invalid hyperbolic projections report domain_error through micron::exc. Generic Lie algebra_exp/algebra_log check the matrix-function flags only when hosted exceptions or the micron EH configuration enable their guarded checks; bare freestanding calls return the computed result matrix without those checks. The exception/noexcept behavior of these entry points follows the configured exception support.

Aliases and categories

The primary traits<M> is declared without a definition; supported policy headers specialize it. point_t<M>, tangent_t<M>, scalar_t<M>, and category_t<M> alias point_type,tangent_type,scalar_type,category respectively. Embedded vector policies report ambient vector width, matrix policies report N*P or N², SO2 reports 1, SO3/SE2 report 9, SE3 reports 16, and generic SOn/SEn report stored matrix element count.

micron::math::manifolds::manifold

Defined in header <micron/math/manifolds/concepts.hpp>.

Checks the availability of traits type aliases and convertible dimension constants.

Concept family

manifold<M> requires point/tangent/scalar/category types and dim/ambient_dim convertible to usize. lie_group<M> additionally tests identity,compose,inverse,one-argument exp_map/log_map with exact result types. riemannian<M> tests inner(p,u,v) returning scalar_t<M>. It does not test norm, distance, transport, projection, or the mathematical validity of those operations.

euclidean satisfies lie_group structurally through its additive operations even though its category is euclidean_tag. A group satisfying lie_group need not satisfy riemannian, because SO/SE values do not expose the required inner method. Individual free wrappers instantiate only if the delegated method exists; manifold alone does not make every operation callable.

micron::math::manifolds::affine_invariant_metric

Defined in header <micron/math/manifolds/metrics.hpp>.

Names one compile-time metric/formula selection supported by the SPD policy.

Metric inventory

euclidean_metric, affine_invariant_metric, log_euclidean_metric, and bures_metric are empty structs. metric_tag accepts exactly those four types. spd_metric_tag accepts only affine_invariant_metric and log_euclidean_metric; the other declared tags do not select an implemented SPD arm. The default SPD metric is affine-invariant. Metric tags own no parameters, tolerance, or matrix data.

The free manifold wrappers use SPD's default metric. Select a different SPD metric through explicit static calls such as spd<F,N>::distance<log_euclidean_metric>(P,Q); changing a tag does not change the point representation.

micron::math::manifolds::euclidean

Defined in header <micron/math/manifolds/embedded/euclidean.hpp>.

Provides flat N-vector geometry and the additive group, with N=2 through 16.

Operations and cost

identity is zero, compose adds, inverse negates, and one-argument exp/log return their input. Base-point exp/retract add a tangent; log/inverse_retract subtract points. inner is the vector dot product, norm/distance the Euclidean norm, and squared_distance avoids its square root. Projection and both transports return the supplied value unchanged. Every operation/copy is O(N), allocation-free, and does not retain point state. value_type=F and length=N are metadata.

micron::math::manifolds::sphere

Defined in header <micron/math/manifolds/embedded/sphere.hpp>.

Provides unit-sphere geometry for N-component points and perpendicular N-component tangents.

Maps and validity

N=2..16, intrinsic dimension N-1. project/project_to_manifold call vector normalization; a zero/nonfinite vector has no separately reported valid-sphere result. project_to_tangent(p,v)=v-dot(p,v)*p assumes unit p. exp_map uses cos(norm(v))*p+sin(norm(v))/norm(v)*v and a normalized p+v fallback below default_eps. retract always normalizes p+v; inverse_retract projects q-p and is not the exact inverse of that normalization retraction.

log_map clamps dot(p,q), uses projected q-p for nearly equal points, and raises domain_error for dot<=-1+default_eps because an antipodal geodesic is not unique. Otherwise it uses acos and the spherical tangent factor. distance uses the smaller of sum/difference chord lengths and an asin half-angle formula to improve endpoint conditioning; points are assumed unit.

Metric, transport, and complexity

inner/norm are ambient Euclidean operations on tangents. parallel_transport uses v-dot(q,v)/(1+dot(p,q))*(p+q), falling back to tangent projection near an antipodal denominator. vector_transport is always projection at q. All formulas cost O(N) arithmetic plus a bounded number of transcendental operations and O(N) local/result storage. No point cache or dynamic allocation is used.

micron::math::manifolds::torus

Defined in header <micron/math/manifolds/embedded/torus.hpp>.

Provides a flat product of N circles represented by angle vectors, with N=2 through 16.

Coordinates and operations

canonical(angle)=atan2(sin(angle),cos(angle)) chooses the trigonometric principal angle; project_to_manifold applies it componentwise. exp/retract wraps p+v; log/inverse_retract wraps q-p. This is an angular coordinate representation, not an N-torus embedded as 2N Cartesian components. Inner/norm use the flat dot product, and distance is the norm of componentwise wrapped differences.

Tangents and both transports are unchanged vectors. Opposite angles retain the atan2 branch convention, without a uniqueness error. All operations cost O(N), including N trigonometric reductions when wrapping, and allocate nothing. No identity/compose/inverse group interface is defined for this policy despite the underlying product-group geometry.

micron::math::manifolds::hyperbolic

Defined in header <micron/math/manifolds/embedded/hyperbolic.hpp>.

Provides Lorentz-hyperboloid geometry in N+1 ambient coordinates, for intrinsic N=1 through 15.

Model and maps

minkowski(x,y)=-x[0]*y[0]+sum(x[i]*y[i],i>0). Valid points satisfy minkowski(p,p)=-1 and p[0]>0; valid tangents are Lorentz-orthogonal to p. Projection normalizes a future-timelike input and raises domain_error when its negative squared Lorentz norm or first coordinate is nonpositive. Tangent projection is v+minkowski(p,v)*p.

exp_map uses cosh/sinh of the tangent norm, clamps negative tangent squared norm to zero, and returns p+v below default_eps without renormalizing it. log_map uses acosh(-minkowski(p,q)) with a near-point projected-difference branch. retract projects p+v and can fail its timelike check; inverse_retract uses log_map. distance switches to an asinh chord formula for nearby points and uses acosh farther away.

Transport and cost

inner is the Lorentz product on supplied tangents; norm takes sqrt(max(inner(v,v),0)). parallel_transport adds minkowski(q,v)/(1-minkowski(p,q))*(p+q), with tangent-projection fallback for a tiny denominator. vector_transport always projects at q. Work/storage are O(N), plus bounded transcendental cost, with no heap or state retention. These guards do not comprehensively validate arbitrary nonfinite or off-manifold inputs.

micron::math::manifolds::stiefel

Defined in header <micron/math/manifolds/embedded/stiefel.hpp>.

Provides operations for orthonormal P-column frames in R^N, represented by full N-by-P matrices.

Actual algorithms

N>=P>=2. Tangent projection is V-X*sym(X^T*V), O(N*P²) work and O(P²+N*P) local storage. retract_qr uses modified Gram-Schmidt on X+V, O(N*P²); columns below default_eps are left unnormalized, so a rank-deficient input is not completed to a valid frame.

retract_polar and project_to_manifold form the thin polar factor U[:,0:P]*V^T from a full-U SVD. exp_map is exactly retract_polar, rather than a separate exact Stiefel exponential. log_map/inverse_retract project Y-X at X. Both parallel_transport and vector_transport project the input at Y. distance/squared_distance use the ambient Frobenius difference, rather than an intrinsic frame geodesic.

Metrics and complexity

inner is the Frobenius inner product, O(N*P). inner_canonical additionally subtracts half trace((U^T*X)*(X^T*V)), O(N*P²). norm uses the default Frobenius inner. Polar operations cost the SVD plus O(N*P²) reconstruction; the SVD performs at most 30 Jacobi sweeps, O(I*(N*P²+P³)+N²) work and O(N²+P²+N*P) inline storage. Its convergence/rank information is not returned here, and zero singular columns can leave an invalid orthonormal frame. The point/tangent matrix stores N*P values; intrinsic dimension is N*P-P*(P+1)/2.

micron::math::manifolds::grassmann

Defined in header <micron/math/manifolds/embedded/grassmann.hpp>.

Provides subspace geometry through an orthonormal N-by-P basis representation, with N>=P>=2.

Maps and metric

Tangent projection is V-X*(X^T*V); horizontal tangents satisfy X^T*V=0. exp_map computes an SVD of V and contracts cos/sin of its singular values with X, the right singular basis, and thin U columns. retract delegates to this exponential formula. log_map inverts X^T*Y, forms Y*(X^T*Y)^-1-X, and applies atan to its singular values; a singular cross-basis matrix falls back to the projected difference inverse_retract.

principal_angles computes singular values of X^T*Y, clamps them to [-1,1], and applies acos. distance is their Euclidean norm, so equivalent orthonormal bases represent the same subspace distance. inner/norm use the Frobenius product. Both transports project at the destination, without an exact parallel-transport construction. Projection to the manifold uses the same thin polar SVD factor as Stiefel and does not repair all rank-deficient cases.

Complexity and storage

Basic inner operations are O(N*P); tangent projection and cross-basis products are O(N*P²). Distances add a P-by-P SVD. exp/log/projection add an N-by-P SVD and O(N*P²) contractions; log also has a P-by-P inverse. SVD uses at most 30 sweeps with O(I*(N*P²+P³)+N²) work and full O(N²+P²+N*P) inline scratch. Decomposition convergence is discarded. Point/tangent storage is N*P, intrinsic dimension P*(N-P); no dynamic allocation is introduced.

micron::math::manifolds::spd

Defined in header <micron/math/manifolds/embedded/spd.hpp>.

Provides symmetric-positive-definite N-by-N matrix geometry with two implemented metric/formula policies.

Projection and spectral helpers

N>=2; points are SPD matrices and tangents symmetric matrices. project_to_tangent symmetrizes V. project_to_manifold symmetrizes its input, eigendecomposes it, and floors eigenvalues at default_eps before reconstruction. sqrt_pd takes raw eigenvalue square roots; inv_sqrt_pd and inverse_pd floor their denominators. sqrt_pair_pd shares one eigensystem and returns an owned nested sqrt_pair with root and inverse_root matrices. A negative eigenvalue can make root nonfinite even while its inverse-root arm is clamped.

The symmetric eigensolver has at most 50 Jacobi sweeps, O(I*N³) work and O(N²) inline storage; reconstruction is O(N³). The helper discards eigensolver diagnostics and does not make arbitrary NaN inputs valid. Copies and tangent symmetrization cost O(N²).

Metric arms

MetricMaps / inner product
affine_invariant_metric (default)Whiten V or Q by P^-1/2, use matrix exp/log, and conjugate back by P^1/2; inner=trace(P^-1*U*P^-1*V)
log_euclidean_metricexp(log(P)+sym(V)), log(Q)-log(P), and Frobenius norm of log differences; inner is Frobenius on supplied tangent coordinates

Retraction, transport, and cost

retract forms P+sym(V)+.5*sym(V)*P^-1*sym(V), then projects it back to the SPD cone. inverse_retract always uses the affine-invariant log. parallel_transport/vector_transport form E=sqrtm(Q*P^-1) and return E*V*E^T, without a metric template parameter.

Dense products are O(N³), expm uses fixed order-13 Pade with at most 60 squarings, and logm/sqrtm use Schur/block-Parlett routines with bounded iterative work. A Schur step costs O(N²) with at most 30*N+30 steps; logm additionally permits up to 60 roots and a 20-term series. Together these operations use O(N²) inline matrices and bounded multiples of cubic work, plus spectral helpers where invoked. Returned matrix-function existence/convergence flags are discarded. No per-call tolerance, status result, or heap workspace is provided.

micron::math::manifolds::lie::SO2

Defined in header <micron/math/manifolds/lie/so2.hpp>.

Owns one angle theta for planar rotations, with a scalar Lie-algebra coordinate.

Operations and branch convention

identity returns theta=0, compose adds angles, inverse negates, and between subtracts. exp_map/log_map store/return the angle unchanged. No canonical wrapping is applied, so equivalent rotations can have different stored logs. interpolate linearly blends those stored angles and can take multiple turns; it does not choose the shortest wrapped rotation.

to_matrix and rotate use sincos; from_matrix uses atan2(R[1,0],R[0,0]) without orthogonality validation. act is rotate; inverse_rotate uses the negated angle. adjoint is scalar one. All methods cost O(1), with no allocator or retained pointers. Only the group/action interface is supplied, without inner/norm/distance methods.

micron::math::manifolds::lie::SO3

Defined in header <micron/math/manifolds/lie/so3.hpp>.

Owns a vector-first quaternion q for spatial rotations and uses a three-vector Lie-algebra coordinate.

Validity and operations

identity is (0,0,0,1). from_quat copies without normalization; from_quat_normalized and normalized request quaternion normalization. compose uses the Hamilton product, inverse uses conjugation, and between=a^-1*b. These inverse/rotation formulas require a unit quaternion; composition does not automatically renormalize accumulated drift. from_matrix delegates quaternion extraction and does not project an arbitrary matrix onto SO3.

exp_map interprets omega as axis times angle. For theta²<.01 it uses fixed polynomial approximations to sin(theta/2)/theta and cos(theta/2); otherwise it uses sincos. log_map flips a negative scalar quaternion sign, then uses a small-vector rational-polynomial atan expansion or 2*atan2, selecting the unit-quaternion principal rotation branch. Zero/nonunit data can divide by zero or lose the intended angle semantics.

Action, distance, and complexity

rotate/act and inverse_rotate use quaternion cross-product rotation, with compile-time f32/f64 kernels and constant-evaluation fallback. to_matrix/adjoint return a copied 3x3 rotation. squared_distance is the squared norm of log(a^-1*b); distance/angle take its square root. interpolate=a*exp(t*log(a^-1*b)). All scalar-group operations cost O(1), allocate nothing, and leave inputs unchanged. traits report dim=3 and ambient_dim=9, distinct from four-coefficient owned storage.

micron::math::manifolds::lie::SE2

Defined in header <micron/math/manifolds/lie/se2.hpp>.

Owns an SO2 rotation and a two-vector translation for planar rigid transforms.

Coordinates and operations

The tangent order is [vx,vy,omega]. Composition returns (Ra*Rb,ta+Ra*tb); inverse applies inverse rotation to -t; act includes translation and act_vector omits it. from_rt/from_matrix and to_matrix copy the expected blocks without full invariant checks. adjoint/adjoint_apply mix translational velocity with rotation, and coadjoint_apply maps force/torque coordinates.

exp_map uses a 2x2 left-Jacobian action on translational velocity, with fixed polynomials for omega²<.01 and sine/cosine formulas otherwise. log_map first reduces the stored angle by a nearest-turn calculation using i64, then inverts that Jacobian; finite angles whose turn count fits i64 are required. This principal reduction differs from SO2's unwrapped log. interpolate uses the relative exp/log path. Operations/copy are O(1), with no allocation; no standalone SE2 distance or inner method is supplied.

micron::math::manifolds::lie::SE3

Defined in header <micron/math/manifolds/lie/se3.hpp>.

Owns an SO3 rotation and a three-vector translation for spatial rigid transforms.

Coordinates and operations

Tangent order is [vx,vy,vz,wx,wy,wz], translation first. from_rt/from_quat_translation/from_matrix copy input components; quaternion inputs are not automatically normalized. normalized adjusts only R. Composition, inverse, between, point/vector action, and inverse actions use the SO3 formulas, so unit rotation remains an invariant.

exp_map shares the rotation half-angle computation with the left-Jacobian translational action, using fixed theta²<.01 polynomials; log_map chooses the quaternion principal sign/angle and applies an inverse left Jacobian to t. adjoint has blocks [R,[t]x*R;0,R], coadjoint [R,0;[t]x*R,R], with direct apply variants avoiding matrix construction. Wrench order is force then torque.

Distance and selection

squared_distance sums the six squared coordinates of log(a^-1*b); distance takes its square root. This combines angular and translational coordinates without user weights or units conversion. interpolate follows a*exp(t*log(a^-1*b)), with no t clamping. All methods cost O(1) and use embedded/local fixed storage. traits report dim=6,ambient_dim=16 while owned members are quaternion plus padded three-vector.

micron::math::manifolds::lie::SOn

Defined in header <micron/math/manifolds/lie/so_n.hpp>.

Owns an N-by-N rotation matrix and represents its Lie algebra by an N-by-N matrix, for N>=2.

Algorithms and costs

from_matrix copies R without enforcing determinant one or orthogonality; inverse transposes R, requiring those invariants. compose is dense multiplication O(N³), act/rotate O(N²), and copy/to_matrix/inverse O(N²). exp_map/log_map use the general algebra_exp/algebra_log wrappers; the caller supplies a skew matrix for a rotation exponential. Their cost follows fixed matrix exp/log routines, with O(N²) inline work storage and no dynamic allocation.

distance computes the Frobenius norm of log(a^-1*b), without the 1/sqrt(2) normalization often used for skew-matrix angle coordinates. It therefore need not match SO3's rotation-vector angle distance. interpolate composes a relative matrix exponential/logarithm, with their exception/configuration behavior. No projection, adjoint, or riemannian inner interface is supplied.

micron::math::manifolds::lie::SEn

Defined in header <micron/math/manifolds/lie/se_n.hpp>.

Owns an (N+1)-square homogeneous matrix for generic N-dimensional rigid transforms, with N>=2.

Layout and operations

H=N+1; the leading N-square block is rotation, the last column translation, and the last row must be [0,...,0,1]. from_matrix copies without validation. inverse transposes the leading block and computes -R^T*t; composition uses full homogeneous multiplication, O(H³), without exploiting block structure. Point/vector actions cost O(N²); act_vector omits translation. Copies/inverse use O(H²) storage/work.

Tangent type is a full H-square algebra matrix. exp/log use generic matrix functions, interpolate uses the relative exp/log construction, and no compact tangent packing or dedicated metric/distance method is supplied. Use SE2/SE3 for their compact coordinates and specialized formulas when those dimensions apply.

micron::math::manifolds::lie::vec3_soa_view

Defined in header <micron/math/manifolds/lie/batch.hpp>.

Borrows three separate coordinate arrays for a batch of spatial vectors, without storing an extent.

View family and operations

vec3_soa_view<F> holds writable x,y,z pointers and converts by value to vec3_soa_const_view<F>, whose pointers are const. Neither view copies elements, allocates, validates nullness, stores length, or extends lifetime. Each array must contain n elements for the operation, and output coordinate arrays must remain distinct.

rotate_many/inverse_rotate_many operate on arrays of actual vec<F,3> values; transform_many/inverse_transform_many additionally translate points. Corresponding *_soa variants use the three-array views. One fixed SO3/SE3 value is reused across the batch. Exact matching input/output arrays are supported by loading each local vector/chunk before stores; arbitrary partial or cross-coordinate overlap is unsuitable. Packed three-scalar memory must not be cast to the padded vec array layout.

Complexity and backend

All batch methods cost O(n), with O(1) SIMD/local scratch and no allocation. Optimized f32 kernels process four vectors on SSE/NEON; x86 SoA can process eight with AVX2/FMA, and f64 has AVX2/FMA or arm64 two-wide paths, otherwise scalar fallback. They rely on the unit quaternion invariant and the actual vec alignment/layout. Batch output writes can change padding lanes; only the three logical coordinates are geometric data. Shared immutable group state is reusable concurrently with disjoint buffers.
