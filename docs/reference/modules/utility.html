Functions, tuples, and sum types

From micron reference
micron reference › Language support

Callable wrappers, tuples, sum types, matching, and control-flow utilities.

Overview

micron::pair<A, B>Stores two values as members a and b.
micron::tupleStores a heterogeneous sequence of values whose element types are template arguments.
micron::option<T, F>Stores one of two alternatives. is_first() identifies the first alternative, and is_second() identifies the second; cast<U>() accesses a selected alternative.

Interface notes

micron::pair<A, B>

micron::option<T, F>

Stores one of two alternatives. is_first() identifies the first alternative, and is_second() identifies the second; cast<U>() accesses a selected alternative.
