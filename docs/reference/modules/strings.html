Strings

From micron reference
micron reference › Containers and strings

Character sequences, string views, formatting, and numeric conversions.

Overview

micron::stringA mutable character string. Construct it from a character sequence and use size() and c_str() to inspect it.
micron::sstr<N>A character string with capacity selected by the template argument N.
micron::string_view<S>A view over a string of type S. The referenced string must remain valid while its elements are accessed.
string::find(character)Returns the position of a matching character, or micron::npos when no match is found.
micron::int_to_string<I>(value)Converts the integer value of type I to a string.

Example

#include <micron/string/strings.hpp>

int main()
{
  micron::string text("hello");
  text += ", micron";
  return text.size() == 13 && text.find(',') == 5 ? 0 : 1;
}
