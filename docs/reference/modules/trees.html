Trees

From micron reference
micron reference › Containers and strings

Tree containers include B-trees, red-black trees, and radix-based structures. The selected type determines key ownership and traversal order.

Overview

micron::artAn adaptive radix tree with insertion, lookup, update, and erasure operations.
art::find(key)Looks up key in the tree.
art::insert(key, value)Adds a key and associated value to the tree.
