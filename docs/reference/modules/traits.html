Type traits and concepts

From micron reference
micron reference › Language support

Compile-time type predicates, transformations, expression constraints, and container dispatch tags. Traits describe types; concepts select overloads using the requirements listed below.

Trait forms

A Boolean trait class exposes a static value and inherits the integral_constant interface. A corresponding _v variable template provides its Boolean value. A transformation class exposes a nested type; its _t alias names the result directly. There is no per-element runtime storage or allocation for these compile-time queries.

Many construction, destruction, layout, and invocation trait classes assert that their arguments are complete or otherwise permitted by the trait. The directly implemented _v forms can omit those explicit assertions. Compiler intrinsics implement most primitive properties; neither a well-formed declaration nor a true trait generally instantiates every dependent function body.

The emulated uint128_t and int128_t on 32-bit targets are classes and are not listed as built-in integral types. Concepts requiring integral therefore need not accept the same short alias on every target.

micron::integral_constant

Defined in header <micron/type_traits.hpp>.

Wraps a compile-time value V of type T as a type.

Member types and operations

value_type is T; type names the specialization itself; static value is V. Conversion to value_type and the nullary call operator return V. bool_constant<B> specializes this pattern for bool; true_type and false_type are the true and false specializations.

Defines type = T only when the Boolean condition is true. Its enable_if_t alias selects that member for substitution constraints.

micron::conjunction

Defined in header <micron/type_traits.hpp>.

Combines Boolean trait types, selecting the first false operand or the final operand when all are true.

Related templates

conjunction<> is true; disjunction<> is false. disjunction<Bs...> selects the first true operand or the final operand when all are false. negation<B> negates bool(B::value). _v forms expose the Boolean result. The class templates select through the pack rather than evaluating every later operand's value unconditionally.

micron::rank

Defined in header <micron/type_traits.hpp>.

Reports the number of built-in array dimensions. The size-property traits return unsigned compile-time values.

Related templates

rank<T> and rank_v<T> count built-in array dimensions. extent<T,I> and extent_v<T,I> report dimension I, or zero for a non-array, unknown bound, or absent dimension. alignment_of<T> and alignment_of_v<T> report alignof(T); T must meet the completeness requirements.

micron::aligned_storage

Defined in header <micron/type_traits.hpp>.

Supplies an aligned byte-storage type without constructing an object in it.

Storage templates

aligned_storage<Len,Align>::type contains unsigned char[Len] aligned to Align; the default alignment comes from the compiler's maximally aligned empty helper. aligned_union<Len,Ts...>::type uses the greatest alignment of Ts... and a length at least Len and the largest sizeof(Ts). The union form requires at least one type and exposes alignment_value. _t aliases select the storage types. Object lifetime and destruction remain the caller's responsibility.

micron::invoke_result

Defined in header <micron/type_traits.hpp>.

Names the result of invoking Fn with Args... through a nested type, when that invocation is valid.

Callable traits

Invocation handling distinguishes ordinary callables, pointers to member functions, and pointers to data members, with direct and dereferenced object forms. invoke_result_t selects type. The deprecated result_of<Fn(Args...)> and result_of_t expose the older signature form.

is_invocable tests availability; is_invocable_r<R,...> additionally tests result conversion to R. The is_nothrow_invocable and is_nothrow_invocable_r forms include exception specifications and result conversion. A declaration of reference_wrapper supports trait unwrapping, but type_traits.hpp does not define that wrapper class. declval<T>() supplies a type expression for unevaluated operands and is deliberately ill-formed if evaluated.

micron::index_sequence

Defined in header <micron/type_traits.hpp>.

Represents a compile-time pack of unsigned indices. size() returns the number of indices.

Sequence construction

make_index_sequence<N> produces indices 0 through N-1; index_sequence_for<Ts...> uses sizeof...(Ts) as the count. The implementation recursively splits the count into halves. concat_index_sequence<A,B>::type appends the indices in B after adding the length of A to each of them; it is an offset concatenation. make_index_sequence_impl<N> is the named construction helper; its nested type is the public alias result.

micron::arg_type

Defined in header <micron/type_traits.hpp>.

Extracts the single parameter type of a supported unary function signature.

Supported forms

Specializations accept unary free functions, function pointers, and unary member functions with or without const. Pointer and reference wrappers are stripped recursively. arg_type_t<F> selects the nested type. The primary template has no definition; general callable classes, overloaded call operators, multiple parameters, and additional member qualifiers have no general extraction path.

micron::option_traits

Defined in header <micron/concepts.hpp>.

Extracts value and error types from a type declaring first_type and second_type.

Related traits

The primary option_traits<T> is empty. Its constrained specialization defines value_type = T::first_type and error_type = T::second_type. option_value_t<T> and option_error_t<T> remove cv/reference qualification before selecting those members. This extraction requires more than the is_option concept's two query expressions.

is_string_tt<T> is the substitution-based trait equivalent of the is_string expression protocol; is_string_v<T> exposes its value. string_len(t) prefers len() when available and otherwise uses size(), converting the result to usize. The size_of<T,N> variable template tests sizeof(T) == N.

micron::Safe

Defined in header <micron/container_safety.hpp>.

Alias of unsigned char used as a type-selected safety policy. Unsafe is an alias of double.

Policy tests

is_safe<T> and is_unsafe<T> test exact type identity with these aliases. The function safe(value) tests whether the deduced by-value argument type is Safe; it does not inspect the numeric value. These policies are separate from containers that use a Boolean safety template argument.

micron::compare::partial_ordering

Defined in header <micron/__special/compare>.

Alias of the comparison category used for less, equivalent, greater, and unordered results.

Comparison categories

compare.hpp provides micron::compare::{partial_ordering,weak_ordering,strong_ordering} as aliases of the corresponding std category types. A hosted build with an available <compare> uses that implementation. Otherwise the header supplies the compiler-required categories in std itself; micron::compare::self_hosted identifies that case.

weak_ordering has less, equivalent, and greater results and converts to partial ordering. strong_ordering also distinguishes its named equal result and converts to weak or partial ordering. Category objects support comparison with literal zero. The supplied std::common_comparison_category<Ts...> selects the weakest applicable category, or void for other types. The selected category does not implement a comparator for a user type.

micron::iter_diff_t

Defined in header <micron/bits/__iter_concepts.hpp>.

Iterator difference alias using I::difference_type when present and ssize_t otherwise.

Associated types and constraints

iter_ref_t is decltype(*declval<I&>()); iter_value_of_t removes its cv/ref qualifiers and can therefore describe a proxy object rather than an independently stored element type. Pointers always use ssize_t as their difference type.

These concepts test a deliberately reduced expression set. indirectly_readable tests non-void dereference; weakly_incrementable tests prefix increment returning I&. sentinel_for tests equality convertible to bool. input_iterator combines dereference/increment, forward_iterator adds copying and self equality, bidirectional_iterator adds prefix decrement, and random_access_iterator adds +=, addition, difference, indexing, and less-than expressions. They do not establish every standard iterator semantic or complexity requirement.

contiguous_iterator is exactly the pointer-type predicate. A user-defined iterator wrapping contiguous storage does not satisfy it merely by advertising a category. No runtime state or work is introduced by these aliases and constraints.
