Reflection

From micron reference
micron reference › Language support

Compile-time reflection vocabulary and queries in micron::meta, with field, enum, tuple, comparison, and hashing helpers in micron::reflect.

Availability and layers

Both public headers are gated by __micron_reflection, derived from a C++26 language mode and the compiler's reflection feature macro. Including them without that gate exposes none of their reflection interfaces. A C++23 build can include the guarded headers but cannot use their declarations.

meta.hpp wraps the corresponding std::meta queries as immediate functions and adapts strings and lists to micron vocabulary. reflect.hpp uses reflection and template expansion to generate ordinary field operations. Runtime objects do not carry a virtual reflection interface, and runtime code does not construct meta::info values.

The compiler bridge in __special/meta supplies the names the compiler requires when the corresponding standard-library types have not already been declared. It provides a small list container and range hooks for constant evaluation. If selected libstdc++ vector/allocator/range headers are already present, the bridge defers to <meta>. meta::self_hosted reports which branch was selected. The self-hosted bridge is not a complete replacement for every standard reflection facility.

Query families

These queries have category-specific compiler preconditions. The wrappers forward those conditions; they do not provide a runtime error-result layer. Compiler reflection declarations without a body in this checkout are implemented by compiler support rather than by a micron runtime algorithm.

Structural operations

reflect::members<T> enumerates nonstatic data members in declaration order using an unchecked access context; bases<T> enumerates bases. field_count and base_count are compile-time counts. Querying metadata does not make every generated access expression valid for every type, bit-field, or union state.

for_each_field<T>(fn) supplies each reflection as a non-type template argument to fn. The object overload calls fn(name,value); its indexed form adds the declaration index. Names are compile-time fixed strings. get_field<I> returns the selected field expression by reference; it does not retain the lifetime of a temporary object. field_type<I,T>, field_name<I,T>, and field_offset<I,T> provide declaration type, name, and byte offset; the offset helper drops a bit-field's separate bit offset.

index_of<T>(identifier) searches names and returns usize(-1) on absence; has_field tests that result. Enum helpers enumerate declarations, materialize values, find the first declaration matching a runtime enum value, or parse a matching name into an output parameter. An unmatched name leaves the output unchanged; an unmatched value gives an empty identifier. Enum lookup is linear in the number of declared enumerators and name comparison also examines characters.

to_tuple constructs a tuple of declared field types, copying values where those types are values. tie_fields constructs a tuple of field references. Their references remain tied to the original object. Field iteration and tuple construction expand work per field, with the corresponding callback/copy cost and no separate runtime reflection lookup.

reflect::equal compares bases and fields, recursively reflecting a class member that has no equality operation. reflect::hash recursively mixes bases and class members with an FNV-style accumulator; scalars use value bits or object bytes, with floating zero normalized. These helpers are noexcept even when user comparisons could throw. Raw representations and non-reflected scalar-like object bytes do not establish a portable persistent hash format. Reading all reflected union members does not validate which member is active.

micron::meta::info

Defined in header <micron/meta.hpp>.

Alias of the compiler's reflection-value type, std::meta::info.

Use

A reflection represents a type, declaration, object, constant, namespace, or other compiler entity according to its category. Use a matching query or splice operation. It is a compile-time value, not an owned runtime descriptor or a pointer to an object. The compiler determines valid reflection operands and diagnostics.

micron::meta::identifier

Defined in header <micron/meta.hpp>.

Non-owning character range returned by name and display queries. Stores a pointer and explicit length.

Operations and lifetime

data, size, empty, begin, and end inspect the range; indexing is unchecked. Equality compares lengths and then characters, taking O(length) work on an equal-length match. Construction from a pointer and length does not allocate, copy, or add a null terminator. Names returned by compiler reflection refer to the corresponding static text; a manually constructed identifier depends on its supplied storage lifetime.

micron::meta::consteval_list

Defined in header <micron/meta.hpp>.

Small owning list for transient constant-evaluation results. info_list is consteval_list<info>.

Storage and operations

Construction from a sized range allocates exactly its size and copies elements. Copy construction and copy assignment allocate and copy the complete list; there is no separate move operation, reserve, growth, or insertion API. Destruction deletes the array. value_type is T, size_type is usize, and const_iterator is const T*.

Size and emptiness are constant-time; iteration is through const pointers. Indexing is unchecked and returns T by value. List allocation is for transient constant evaluation and must obey constant-expression lifetime rules. Use define_static_array to obtain the compiler-backed static representation needed for a persistent metadata table.

reflection_range<R> requires begin/end and a dereferenced element whose cv/reference-stripped type is exactly info. It does not require a separate standard range concept.

micron::meta::access_context

Defined in header <micron/meta.hpp>.

Alias of std::meta::access_context, identifying the scope and designating class used by reflection access checks.

Context selection

The self-hosted definition deletes default construction. current() and via(info) are compiler-supported context operations; unprivileged() identifies the global unprivileged context, while unchecked() supplies empty scope/designating-class reflections. Copy/move are immediate operations. scope() and designating_class() inspect those components. Query APIs accepting this context use it for metadata accessibility, not for storing a runtime access permission.

micron::meta::member_offset

Defined in header <micron/meta.hpp>.

Alias of a member-layout displacement with separate signed byte and bit components.

Members

The compiler bridge defines ptrdiff_t bytes and ptrdiff_t bits; total_bits() computes bytes*__CHAR_BIT__ + bits. Comparison is defaulted. Retain the bit component when interpreting a bit-field location; reflect::field_offset reports only bytes. This record describes layout and does not itself permit pointer arithmetic to an otherwise inaccessible or inactive subobject.

micron::meta::operators

Defined in header <micron/meta.hpp>.

Alias of the enumeration identifying reflected overloadable operators.

Operator categories

The supplied enumeration covers scalar/array new/delete, co_await, calls and subscripts, arrow/member-arrow, unary and binary arithmetic/bitwise/logical operators, assignments and compound assignments, comparisons including spaceship, shifts, increment/decrement, and comma. operator_of(info) identifies an operator declaration and symbol_of(operators) returns its spelling as an identifier. The enum is metadata, without an evaluator for the represented operation.

micron::reflect::reflectable

Defined in header <micron/reflect.hpp>.

Concept accepting a class or union after removing cv/reference qualification.

Related constraints and aliases

reflectable_enum accepts an enumeration; reflectable_aggregate additionally requires an aggregate class/union. The broad reflectable test does not prove that every field operation, copy, equality comparison, or union access is valid.

member_type<M> splices the reflected declaration's type. field_type<I,T> obtains the declared type of the Ith reflected nonstatic data member. These are declared types, including references or qualifiers where present, rather than runtime type-erased wrappers.

std::meta::exception

Defined in header <micron/__special/meta>.

Minimal immediate diagnostic record used by the self-hosted compiler-reflection bridge.

Members

Stores a borrowed message pointer and originating info. Its constructor, copy/move constructors, what(), and from() are consteval. This is distinct from the runtime classes in micron::except; it is not a general runtime exception object. The bridge declares other compiler reflection entry points whose effects are supplied by the compiler, and omits broader standard-library-dependent facilities such as aggregate-definition support.

std::vector

Defined in header <micron/__special/meta>.

Minimal transient list declared solely for the self-hosted reflection compiler bridge. It is separate from micron::vector.

Available interface

The bridge provides default/list/copy construction, copy assignment, destruction, size/empty, const begin/end, and unchecked const indexing. It owns an exactly sized new[] allocation and performs linear copying, with no growth or ordinary vector modifiers. It exists because compiler reflection looks up these std names directly. A translation unit using a real standard-library vector must establish the corresponding standard-library branch before including this bridge.
