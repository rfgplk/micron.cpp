Sparse matrices

From micron reference
micron reference › Numerics and mathematics

Owned compressed sparse row/column matrices and indexed sparse vectors, with real-valued products, norms, conversions, and triangular solves. Public arrays represent stored entries; explicit zeros and duplicate indices are not automatically removed.

Storage and selection

TypeLayoutUse
csr<T,I>outer[rows+1], inner[nnz] columns, values[nnz]Row traversal and sparse matrix-vector dot products
csc<T,I>outer[cols+1], inner[nnz] rows, values[nnz]Column traversal, scatter products, triangular solves and sparse matrix multiplication
sparse_vec<T,I>Logical length n, idx[nnz], values[nnz]Indexed vector storage and merge/dense-index dot products

Invariants and ownership

T must satisfy arith_scalar and I integral, with u32 the default index type. Numerical kernels further require ieee754_floating. Each index/value array is a vector with allocator_serial and checks disabled. Copies own independent arrays; moves transfer vector storage. Reallocation, assignment, destruction, or direct array replacement invalidates borrowed pointers. Shapes, offsets, and vectors are public and no insertion/assembly abstraction preserves their consistency automatically.

Valid compressed storage has a monotone outer array beginning at zero and ending at the stored-entry count, equally sized inner/values arrays, and in-range nonnegative inner indices. Every dimension, offset and count must fit the selected I. nnz() is values.size(), including explicit zeros. Only selected helpers guard malformed indices or nonmonotone intervals; those guards do not establish validity of arbitrary compressed arrays. Ordinary arithmetic performs no shape or buffer bounds validation.

Sorted unique sparse-vector indices are required for dot(a,b)'s two-pointer interpretation. Duplicate entries in matrices are preserved and contribute independently to products; stored-value Frobenius norms sum their squares without first combining duplicate coordinates. A stored representation with duplicates can consequently have a different norm from its assembled dense matrix.

Results and implementation notes

Conversions skip out-of-range inner indices while counting/scattering, but allocate inner/values to the input nnz rather than the valid-entry total. Malformed input can therefore leave a zero-initialized tail not covered by outer.back(); conversion is not a repair/validation API. from_triplets_sorted filters invalid columns before sizing output but does not validate row indices; despite its name and source sorting precondition, its bucket loop accepts column encounter order without sorting rows.

spmv requires x/y large enough for the logical product and valid index targets. beta==0 initializes only the output dimension without reading old y; alpha==0 then returns. CSC skips columns whose x value is exactly zero. Inputs and mutable outputs must respect restricted-pointer/nonaliasing requirements. spgemm skips invalid contraction/row indices, merges contributions at each active output row, sorts those rows, and emits even cancellation-to-zero values. Its result count is not a promise of mathematical nonzero count.

Triangular solve inspects only rows below/above each diagonal. A nonunit tag finds the first diagonal and rejects exactly zero or absent values; other diagonal duplicates are not accumulated. Unit mode assumes one and ignores stored diagonal coefficients. The API does not verify a square shape, RHS length, finite coefficients, or the triangular structure. Sparse kernels do not provide a general status object or transactional rollback. Their noexcept declarations do not add a recoverable allocator-error channel to allocating operations.

micron::math::sparse::csr

Defined in header <micron/math/sparse/csr.hpp>.

Owned row-compressed matrix with public rows, cols, outer, inner, and values.

Members

value_type=T, index_type=I, vec_i and vec_v select unchecked serial-allocator vectors. The shape constructor creates rows+1 zero offsets and no entries; default construction leaves all vectors empty. nnz is O(1), row_begin/end read offsets, and row_nnz returns zero for a decreasing offset pair. These accessors do not check the row index. No automatic resizing/normalization follows direct shape or array edits.

micron::math::sparse::csc

Defined in header <micron/math/sparse/csc.hpp>.

Owned column-compressed matrix with public rows, cols, outer, inner, and values.

Members

value_type=T, index_type=I, vec_i/vec_v are serial-allocator vectors with checks disabled. The shape constructor creates cols+1 zero offsets; default construction has empty arrays. col_begin/end and col_nnz mirror CSR row access, including a zero result for a decreasing pair. from_triplets_sorted returns a new bucketed representation, preserving row encounter order and duplicate/zero entries rather than sorting or coalescing them.

micron::math::sparse::sparse_vec

Defined in header <micron/math/sparse/sparse_vec.hpp>.

Owned indexed vector storing logical length n separately from idx and values arrays.

Members and use

value_type=T and index_type=I; vec_i/vec_v select unchecked serial-allocator vectors. Construction with a logical length creates empty index/value arrays; nnz reports values.size(). Direct array editing is the assembly interface. Index/value sizes and bounds are caller-maintained; sparse-sparse dot additionally assumes ordered unique indices. Default copy/move semantics follow the owned vectors.

micron::math::sparse::triangular_tag::lower_unit

Defined in header <micron/math/sparse/triangular.hpp>.

Empty tag selecting the assumed-unit diagonal branch of solve_lower.

Related tags

lower_non_unit makes solve_lower search/divide by each stored diagonal. upper_unit and upper_non_unit serve solve_upper analogously. The function templates do not constrain Diag to these tags: only the exact corresponding non_unit type selects explicit diagonal division, and other types take the assumed-unit branch. Tags carry no matrix or runtime state.
