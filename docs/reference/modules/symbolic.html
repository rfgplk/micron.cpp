Symbolic expressions

From micron reference
micron reference › Numerics and mathematics

Arena-owned symbolic expression DAGs with exact rational constants, declared assumptions, local simplification, differentiation, limited integration/substitution, and S-expression output.

Representation and selection

An arena owns append-only node, rational, symbol, name-text, and interning-table storage through reserved_vector. node_id is an arena-local u32 index; invalid_node is its all-ones sentinel. Nodes refer to child IDs and payload indices. Repeated structural nodes are interned through an open-addressed table; add/multiply canonicalize their two child IDs, but the system does not flatten arbitrary associative sums/products or provide a complete algebraic normal form.

Use arena while constructing and rewriting related expressions. expression transfers an arena and one root into a move-only owner for retaining/serializing the result. The implementation provides exact structural manipulation and output, rather than a general numerical evaluator or parser. An ID from another arena can be in range yet denote an unrelated node; IDs carry no owner identity.

Operations and assumptions

positive implies real, nonzero, and nonnegative. nonnegative plus nonzero implies positive. Identities such as x/x and exp(log(x)) require the corresponding nonzero/positive facts. Unknown mathematical conditions are not proved by runtime testing. A successful result can be an unevaluated calculus node; inspect its kind if closed-form evaluation is required.

OperationImplemented behavior
constant/integer/symbolIntern exact rationals and symbol names. Reusing a name with different closed assumptions reports assumption_conflict.
add/multiply/negate/subtract/divide/powerFold rational arithmetic and selected identities, combine equal operands, and propagate conservative real/sign/nonzero facts.
functionBuild sin/cos/exp/log/sqrt/abs with selected literal and assumption-dependent simplifications; reject known rational domain errors.
differentiateMemoized sum/product/quotient/power/chain rules and selected elementary derivatives; retain an unevaluated derivative node when unsupported.
integrateHandle variable-independent terms and recognized univariate rational-coefficient polynomials; retain an unevaluated integral for unrecognized forms.
substituteMemoized replacement preserving required assumptions; reject substitution through derivative/integral binding nodes.
clone_toDeep-copy arena storage with the same node IDs, replacing the destination only after the copy succeeds.
write_csexpWrite prefix forms through a synchronous sink with bounded scratch/output/rewrite work.

Complexity and storage

Construction reserves capacities from limits and initializes an interning table whose power-of-two size is at least twice max_nodes. Node addresses do not relocate during ordinary append growth. Rational coefficient objects can allocate their own limb storage. Node/name/coefficient views borrow the arena and remain valid during additions; destruction, replacing an arena, or retaining an expression's old owner reference across move requires separate lifetime care.

Interning computes a structural hash and linearly probes; expected short-probe behavior depends on hash distribution, with O(number of stored nodes) worst-case probes. Rational hashing/comparison also scans limbs. Symbol lookup scans previous names, taking O(symbol count × compared name length) in the worst case. Simple arithmetic node construction includes these costs, rather than always being constant-time.

Differentiation/substitution allocate memo storage proportional to the arena size at operation start. Traversal is memoized for existing successful subresults, but emitted-node interning and exact rational work add their own costs. Polynomial multiplication uses nested coefficient loops, O(ab) rational operations for lengths a and b; recognition can revisit shared subgraphs and allocate coefficient buffers. max_rewrites limits selected traversal/rewrite steps, not every limb operation or allocation byte.

Output traverses expression occurrences recursively, so a shared DAG can expand to much larger text than its node count. The sink must consume each span before returning and signal acceptance with true. Failure can leave an emitted prefix. The default writer uses a 256-byte local numeric buffer and can allocate bounded overflow scratch; the explicit-scratch overload allocates no overflow buffer and reports output_limit when it is too small. Neither writer owns the destination.

micron::math::symbolic::arena

Defined in header <micron/math/symbolic.hpp>.

Move-only owner of an expression DAG and its exact coefficients, symbol records, copied names, and interning table.

Validity and mutation

Construction checks limits and attempts all reservations; status() reports invalid_limits/allocation rather than throwing an explicit setup exception. get(id), coefficient(id), and symbol_name(id) return null/empty for an inappropriate ID. size() is the current node count. Read status before using a newly constructed arena.

Operations return result with a node ID and error code. Failed rewrites can leave successfully created intermediate nodes in the arena; there is no transactional node rollback for the complete operation. Mutation is not synchronized. clone_to copies the entire arena, including unused reachable-by-no-root nodes and capacity policy, rather than collecting one expression's reachable subgraph.

micron::math::symbolic::expression

Defined in header <micron/math/symbolic.hpp>.

Move-only arena owner with a selected root ID.

Lifetime

Default construction is invalid without allocating a normal arena. Construction from arena&& and root transfers storage without validating the root first; valid() checks that the root resolves. owner() returns a const borrowed arena reference and root() returns its local index. clone_to deeply duplicates all owned arena state and preserves the root ID. write_csexp delegates to the owner. Returned node/name/coefficient views do not retain this owner.

micron::math::symbolic::limits

Defined in header <micron/math/symbolic.hpp>.

Capacity and work limits for nodes, symbols, text, depth, rewrites, polynomial degree, and rational limb/exponent operations.

Defaults and validation

Defaults are 65536 nodes, 4096 symbols, 1048576 text bytes, depth 256, 131072 rewrite steps, and polynomial degree 256, plus rational_limits defaults. Construction requires positive principal capacities, nodes at most 2^28, depth at most 512, polynomial degree at most 4096, and compatible rational work limits. These are resource/work budgets, not an accuracy tolerance. Reaching a limit is reported in the operation result.

micron::math::symbolic::result

Defined in header <micron/math/symbolic.hpp>.

Arena-local node ID and symbolic error code, with explicit Boolean success testing.

Status

Boolean conversion requires code==error::none and id!=invalid_node. error names invalid limits/nodes/variables/symbols, conflicting assumptions, node/symbol/text/depth/rewrite/polynomial/limb/exponent/output limits, domain errors, and allocation failure. Results do not carry an arena pointer or retain storage. Use a successful ID only with the originating arena.

micron::math::symbolic::node

Defined in header <micron/math/symbolic.hpp>.

Compact structural record with kind, left/right child IDs, integer exponent, payload index, depth, and proven assumptions.

Kinds and assumptions

kind distinguishes rational, symbol, add, multiply, divide, power, sin, cos, exp, log, sqrt, abs, derivative, and integral. Rational/symbol payloads index arena-owned tables; powers store an i64 exponent and unary operand; unevaluated calculus nodes carry an expression and variable ID. assumptions is a bitmask of none/real/nonzero/nonnegative/positive. Public node aggregates do not enforce arena invariants independently; get exposes const nodes.

micron::math::symbolic::text_view

Defined in header <micron/math/symbolic.hpp>.

Borrowed character pointer and explicit length used for symbol input and name observation.

Ownership

symbol copies accepted input bytes into its arena; the input need only survive that call. symbol_name returns a span into copied arena text without adding a null terminator. Empty names and embedded nulls are rejected. Name views must not be passed as ordinary null-terminated strings without a separate bounded conversion.
