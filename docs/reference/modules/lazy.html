Lazy algorithms

From micron reference
micron reference › Algorithms

Pull-based views in micron::lz compose with operator|. A view chain is evaluated when a terminal consumes it.

Overview

lz::filter(predicate)Produces a view of elements for which predicate is true.
lz::fmap(function)Produces a view that applies function to each element requested by the consumer.
lz::take(n)Produces a view containing at most n elements from its input.
lz::collect<C>()Consumes a bounded input view and constructs a container of type C containing its elements.
lz::sum(), lz::count()Consume the input and return a scalar sum or element count, respectively.
lz::head()Returns an option containing the first value or an error alternative when the input is empty.

Interface notes

lz::filter(predicate)

Produces a view of elements for which predicate is true.

Defined in header <micron/algorithm/lazy/filter.hpp>.

Parameters

predicateA callable determining whether an input element is included.

Return value

A view adaptor. The predicate is evaluated as elements are requested from the resulting view.

Notes

The input range must remain valid while a view referring to it is consumed.

lz::fmap(function)

Produces a view that applies function to each element requested by the consumer.

Defined in header <micron/algorithm/lazy/transform.hpp>.

Parameters

functionA callable applied to an input element.

Return value

A view adaptor that transforms elements on demand.

lz::take(n)

Produces a view containing at most n elements from its input.

Defined in header <micron/algorithm/lazy/take.hpp>.

Parameters

nMaximum number of elements to produce.

Return value

A view adaptor that stops after at most n elements.

lz::collect<C>()

Consumes a bounded input view and constructs a container of type C containing its elements.

Defined in header <micron/algorithm/lazy/collect.hpp>.

Parameters

CThe output container type.

Return value

A container of type C populated from the input view.

Notes

The input must be bounded. Use an adaptor such as take before collecting an unbounded source.

lz::sum(), lz::count()

Consume the input and return a scalar sum or element count, respectively.

lz::head()

Returns an option containing the first value or an error alternative when the input is empty.

Example

#include <micron/lz.hpp>
#include <micron/vector/vector.hpp>

int main()
{
  namespace lz = micron::lz;
  micron::vector<int> values({ 1, 2, 3, 4, 5 });
  auto result = values | lz::filter([](int x) { return x % 2 != 0; })
                       | lz::fmap([](int x) { return x * 10; })
                       | lz::take(2) | lz::collect<micron::vector<int>>();
  return result.size() == 2 && result[0] == 10 && result[1] == 30 ? 0 : 1;
}
