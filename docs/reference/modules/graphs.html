micron::math::graphs::bfs(graph, start)

Traverses the graph from start in breadth-first order and returns a traversal result.

Defined in header <micron/math/graph/traversal.hpp>.

Parameters

graphThe graph to traverse.
startThe starting vertex identifier.

Return value

A traversal result containing an order sequence and associated traversal information.

micron::math::graphs::shortest_path(graph, from, to)

Computes a path result between the selected vertices. Inspect its status before using the result.

Example

#include <micron/math/graph.hpp>

int main()
{
  micron::math::graph<int> graph;
  auto a = graph.add_vertex(1);
  auto b = graph.add_vertex(2);
  (void)graph.add_edge(a, b);
  auto traversal = micron::math::graphs::bfs(graph, a);
  return traversal.order.size() == 2 ? 0 : 1;
}
