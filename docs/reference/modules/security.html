Security

From micron reference
micron reference › System interfaces

Security policies and Linux security interfaces, including seccomp, namespaces, Landlock, and SELinux helpers. Kernel support and process privileges determine which operations are available.

Overview

micron::sec::seccomp::allowAdds an allow rule to a seccomp policy.
micron::sec::seccomp::deny_allAdds a default denial rule to a seccomp policy.
