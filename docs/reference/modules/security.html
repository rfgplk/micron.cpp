Security

From micron reference
micron reference › System interfaces

Linux seccomp filter construction, Landlock rulesets, namespace handles, SELinux labels, and child-process setup with explicit policy/result types.

Results and scope

sec::result<T> is option<T,error_t>: test is_first()/is_second(), since both alternatives count as values. unit_t is tuple<> and error_t aliases io::error_t. to_unit turns a negative result into the error alternative and a nonnegative result into unit. Direct subsystem operations generally return zero or negative errno; notification installation returns an owned listener descriptor on success.

These interfaces describe Linux mechanisms available to the calling process. Kernel feature support, credentials, namespace state, and existing restrictions determine actual success. Applying a policy changes process/thread state and is not reversed by destroying its C++ builder. No constructors here imply that an unrelated thread or already-open resource has been confined.

Seccomp construction and installation

Rules are emitted in order and the first matching return action wins. A later deny cannot override an earlier unconditional allow for the same syscall. Start with require_native_arch(), emit rules, and seal a default action. On amd64 the native gate additionally rejects the x32 syscall-number range. require_arch and require_native_arch_raw provide weaker explicit gates; valid() is a structural builder check rather than proof of the complete intended policy.

Argument predicates compare unsigned register values. Full-width comparisons read both halves of the 64-bit seccomp argument; arg_eq32/arg_masked32/arg_no_bits32 compare the low 32 bits for selectors that the kernel narrows. Pointer values and genuinely full-width flags require the full-width forms. BPF cannot dereference pointer arguments such as clone3's argument structure.

load installs on the calling thread, load_tsync requests thread-group synchronization and maps a positive unsynchronized TID result to a negative error, and load_notif returns a listener descriptor. No-new-privileges is enabled by default before loading and can already be set when a later validation/install step fails. Raw loading checks only selected structural properties unless unchecked is explicitly requested. Seccomp filters do not inspect operations subsequently submitted through an allowed io_uring interface.

Landlock rights and ABI selection

Handled rights are the operations the ruleset will restrict; allow/allow_fd/allow_port grant subsets within that handled set. Rights omitted from the handled set remain outside this ruleset's restriction. The default ruleset constructor and try_ruleset narrow requested rights to those supported by the probed ABI. try_ruleset with abi_policy::strict instead rejects unsupported requests, and dropped_fs/net/scope report omitted bits.

Path rules currently open directories with O_PATH and O_DIRECTORY. allow rejects symlinks through openat2 when available; its older fallback refuses only a terminal symlink. allow_following deliberately follows paths. allow_fd borrows an already-open descriptor only during the add-rule call. restrict_self sets no-new-privileges, then applies the ruleset to the calling thread; closing the descriptor does not remove the restriction.

Child setup and failure reporting

sandbox stores configuration until spawn/run. It records the first capacity/configuration fault and refuses launch before forking when that fault exists. In the child, stages are namespace setup, filesystem shaping, limits, stdio, extra-descriptor closure, Landlock, capability preparation, seccomp, no-new-privileges/dumpability, credentials, capability clearing, signal-mask clearing, then exec/body. Partial child-stage failure is reported through a close-on-exec pipe and the failed child is reaped.

Defaults close extra descriptors, drop capabilities where supported by the child's authority, set no-new-privileges, and disable dumpability. Filesystem namespace selection and root changes remain explicit. PID namespace setup forks an inner child and returns a supervisor PID; signaled inner termination is translated to a supervisor exit code. parent_death_signal arms SIGKILL early and rejects PID-namespace or explicit credential-transition combinations.

Builders borrow path/option strings, filter instructions, stdio/keep descriptors, and pinned Landlock descriptors until launch completes. seccomp rejects a temporary builder to avoid a dangling instruction array. Retained directory descriptors are explicitly distinguished by keep_dir_fd; keep_fd rejects a descriptor recognized as a directory. A filter must still permit later credential, signal-mask, and exec/body operations that its chosen child setup requires.

Complexity and storage

Policy emission is linear in emitted instructions and fixed rule lists; a filter occupies O(N) inline storage and executes its ordered BPF ladder until an action returns. Kernel verification and syscall costs are additional. Namespace/ruleset handles use constant user-space storage; kernel work is not bounded by the C++ wrapper's constant operation count.

sandbox holds at most 12 mounts, 12 Landlock rules, eight kept descriptors, and eight rlimits. Descriptor closing prefers close_range; the fallback loops up to a bounded descriptor ceiling and fails above 2^20. Launch includes fork, blocking setup/fault reporting, and optional waiting, so it has no fixed latency bound. SELinux text operations are linear in bounded label length and use stack/inline storage.

micron::sec::result

Defined in header <micron/sec/bits.hpp>.

Two-alternative value/error result alias used by the security porcelain.

Aliases

error_t is io::error_t and unit_t is tuple<>. is_first selects success and is_second selects error; Boolean conversion of a general option is not a replacement for alternative selection. The contained value's own ownership rules still apply.

micron::sec::seccomp::arch

Defined in header <micron/sec/seccomp.hpp>.

Linux audit architecture identifiers for filter gates.

Selection

native_arch selects amd64, i386, ARMv7, or AArch64 at compile time. The enum also names several other ABIs for explicit data/gate construction; that does not add their syscall wrapper implementations. x32 syscall entry shares the amd64 audit architecture in practice, so the native builder gate also checks its syscall-number range.

micron::sec::seccomp::arg_cmp_t

Defined in header <micron/sec/seccomp.hpp>.

Argument index, unsigned comparison kind, comparison value, and optional mask.

Comparison kinds

cmp provides ne, lt, le, eq, ge, gt, and masked_eq. datum_a is the value and datum_b is the mask for masked_eq. Indices must identify arguments 0..5; the record and builder do not independently validate that range. arg_no_bits expresses masked equality with zero, rather than an any-bit-set predicate.

micron::sec::seccomp::filter_builder

Defined in header <micron/sec/seccomp.hpp>.

Fixed-capacity inline instruction array and state for a classic-BPF syscall filter.

State and modifiers

Max must be positive and no greater than the BPF instruction limit. count selects the live instruction prefix. Rule insertion reserves a slot for the default return; capacity failure marks overflowed and makes valid() false. Architecture gating must precede rules; upgrading an already weaker gate through require_native_arch is rejected. Ordinary rules after sealing do nothing.

allow/deny/deny_errno/trap_syscall emit individual actions; allow_batch emits a compact shared-return ladder; allow_range/deny_range use unsigned number comparisons. action_if and its wrappers add one argument predicate. default_* seals an action and finalize supplies default kill if needed. prog() can finalize but cannot retrofit a missing architecture gate; its fprog_t borrows insns.

Public array/state mutation bypasses builder invariants. valid() requires arch_ok, no overflow, nonempty sealed output, an initial architecture load, and a final return. It does not symbolically verify every jump/action or prove that the native x32 guard exists. Preserve the builder's lifetime until an install or sandbox launch has consumed its program.

Marker for named static syscall-number arrays used by policy composition.

Named groups

Each group exposes policy_tag, calls, and count; is_syscall_group checks that protocol. Lists are architecture-dependent and do not inspect syscall arguments or deduplicate overlapping groups. Names such as readonly or network describe a grouping, not a complete filesystem or network authorization model.

micron::sec::seccomp_policy_n

Defined in header <micron/sec/policy.hpp>.

Type-composed seccomp rules with an explicit instruction capacity.

Policy forms

Rules emit in template order after a native architecture gate. seccomp_policy_n::build(default_action) seals the caller's action; apply uses EPERM as the default and TSYNC. seccomp_strict_policy_n builds a default process-kill action. seccomp_policy and seccomp_strict_policy alias capacity 1024. apply_this_thread_only explicitly chooses local-thread installation.

allow<Groups...> emits allows, deny<Groups...> emits EPERM actions, allow_calls<Nrs...> emits listed calls, and errno_call<Nr,Err> emits one error action. no_new_namespaces permits clone only without namespace bits then denies clone/clone3/unshare/setns; put it before broader allows. no_tty_injection and no_raw_socket_families emit narrowed selector denials. These compile-time types contain no installed kernel resource.

micron::sec::landlock::access_fs

Defined in header <micron/sec/landlock.hpp>.

Bitmask of filesystem access rights handled or granted by a Landlock ruleset.

Related masks

access_net supplies bind_tcp/connect_tcp; scope supplies abstract_unix_socket/signal isolation. OR/AND/complement and any/bits operate on masks. read_only/read_execute/read_write/make_any/full_dir are supplied composites, whose names do not imply all supported rights. abi_policy selects narrowing or strict rejection of unavailable bits.

micron::sec::landlock::ruleset

Defined in header <micron/sec/landlock.hpp>.

Move-only owner of a Landlock ruleset descriptor and the ABI/handled-rights snapshot used to construct it.

Lifetime and errors

The ordinary constructor reports setup failures through exceptions. try_ruleset returns either a valid owner or an invalid owner carrying negative error state; valid()/error() inspect it. close/destruction close only the descriptor. Move transfers it and invalidates the source. fd() is borrowed and must not be independently closed while still owned.

allow_fd intersects requested grants with handled rights and rejects an empty intersection; allow_port behaves similarly. restrict_self applies the kernel policy but leaves the descriptor owned. Changing or destroying the ruleset object afterward does not undo the installed domain. No same-object synchronization is provided.

micron::sec::ns::ns_kind

Defined in header <micron/sec/namespaces.hpp>.

Bitmask selecting mount, cgroup, UTS, IPC, user, PID, network, or time namespaces.

Use

none requests no change. name_of accepts one kind and returns its proc namespace component; combined masks do not name one descriptor. unshare passes flags to the kernel; unshare_user_as_root creates a user namespace, denies setgroups, maps the current outer UID/GID to inner zero, then unshares extra kinds. Failure can follow a partial state change. PID unshare affects subsequent children rather than moving the caller into that PID namespace.

micron::sec::ns::ns_handle

Defined in header <micron/sec/namespaces.hpp>.

Move-only owner of an open namespace descriptor and its kind.

Operations

open_of/open_self produce an owner or an invalid handle carrying a negative error. fd(), kind(), type(), inode(), and owner_uid inspect it; parent() and owning_userns() obtain new owned descriptors. enter calls setns using the stored kind. close/destruction release the descriptor without leaving an entered namespace. is_host compares the inode against a compiled initial-namespace inode constant, rather than comparing against a retained caller-selected host descriptor.

micron::sec::ns::enter_scope

Defined in header <micron/sec/namespaces.hpp>.

Noncopyable namespace-entry attempt holding a saved namespace handle for restoration.

Restoration

Construction saves the caller's current namespace then attempts target.enter(). ok() reports entry only; restorable() separately reports whether a saved handle exists. restore() returns the restoration result and permits another attempt after failure. Destruction attempts restoration and records a negative result in thread-local last_restore_error. It cannot guarantee restoration when permissions or namespace semantics disallow it. A scope object does not reverse unrelated setup changes.

micron::sec::selinux::mode

Defined in header <micron/sec/selinux.hpp>.

Enumeration disabled, permissive, or enforcing used by a SELinux status snapshot.

Status

status_t contains present/state/policyvers/mls/deny_unknown; enforcing() tests the state. status() reads fixed selinuxfs paths. If reading enforce fails, it returns the default absent/disabled snapshot, so absent can also mean an unreadable interface. boolean and policy_capability instead use value/error results.

micron::sec::selinux::context

Defined in header <micron/sec/selinux.hpp>.

Inline SELinux label text with capacity 512 bytes and parsed user/role/type/range separators.

Parsing and access

parse strips terminal nulls/newlines, rejects input of 512 bytes or more with truncated=true, and stores shorter input. valid() requires nonempty text and at least two separators; it is a structural check, not a policy validity query. Additional colons belong to the range. user/role/type/range return part records borrowing the object's buffer. Copying the context copies storage; an existing part still points at the old object.

Invalid contexts never compare equal, including to themselves. Label reads can return a successful but structurally invalid context; inspect valid() as well as the result alternative. Overlong labels become errors through read wrappers. set_label includes a null terminator in security.selinux; process attribute setters write the stored character count. These operations do not allocate label storage.

micron::sec::selinux::attr

Defined in header <micron/sec/selinux.hpp>.

Process-label attribute selector: current, exec, fscreate, keycreate, sockcreate, or prev.

Operations

get_attr/self read /proc/self/attr; set_attr/clear_attr change that attribute through the same interface. set_exec and set_fscreate are named conveniences. label_of follows a terminal symlink, label_of_link uses lgetxattr, and label_of_fd uses an existing descriptor. Filesystem policy/credentials determine allowed changes.

micron::sec::sandbox

Defined in header <micron/sec/sandbox.hpp>.

Fixed-capacity configuration for applying child security/setup stages before program execution or a function body.

Launch results

spawn takes path/argv/envp; run takes i32(*)(). A successful child result means setup completed far enough to close the reporting pipe, not that the program/body later succeeded. child stores pid and fault; ok() requires a positive PID with no fault. run_to_completion also waits and returns result<exit_status>; ordinary spawn/run leave reaping to the caller.

exit_status stores the raw wait status. exited/signaled select the interpretation before code/signal; raw returns the original word. fault_t pairs stage and negative errno; its Boolean conversion tests stage, and stage_name returns a static name. Configurations retain their recorded first fault; configured() and config_fault() expose it. No child ownership or automatic cancellation is attached to the returned PID.

micron::sec::mount_spec

Defined in header <micron/sec/sandbox.hpp>.

Borrowed source/target/type/options strings with mount flags, readonly selection, and mount attributes.

Application

recursive() tests MS_REC; needs_remount() checks readonly/attribute changes. Sandbox bind defaults to recursive nosuid/nodev hardening. Recursive attributes use mount_setattr; nonrecursive bind attributes use remount. The builder does not create mount points or own the string storage.

micron::sec::capability_policy

Defined in header <micron/sec/policy.hpp>.

Type policy retaining the listed capabilities through pre/post-UID stages.

Related variants

Pre-UID setup requests keepcaps and drops unlisted bounding bits; post-UID setup assigns the listed capability set and attempts ambient raises. Some keepcaps/ambient results are intentionally not propagated by this implementation. capability_policy_none drops known bounding/ambient and active sets; capability_policy_keep_all performs no work. Operations can partly change credentials before reporting a later error.

micron::sec::rlimit_policy

Defined in header <micron/sec/policy.hpp>.

Compile-time sequence of resource-limit assignments.

Directives

limit<Resource,Soft,Hard=Soft> carries a resource selector and u64 soft/hard values. apply visits every directive and returns the first failure while continuing later assignments. rlimit_policy_none does nothing. Work is O(number of directives) wrapper calls; already-applied limits are not rolled back.

micron::sec::filesystem_policy

Defined in header <micron/sec/policy.hpp>.

Ordered type-level filesystem directives, stopping at the first failure.

Directives

Strings are fixed_string template values. filesystem_policy_none does nothing. These directives do not first create a mount namespace; apply an appropriate namespace policy when isolation is intended. Work is linear in directive count plus kernel/path operations, with no rollback.

micron::sec::namespace_policy

Defined in header <micron/sec/policy.hpp>.

Compile-time namespace-kind mask with optional current-user-to-inner-root setup.

Limits

has_user selects unshare_user_as_root; otherwise apply directly unshares the mask. PID kind is rejected by static assertion because this type does not create the child needed to enter it. namespace_policy_none has an empty mask and does nothing. Namespace operation results can reflect a partial sequence.

micron::sec::landlock_policy

Defined in header <micron/sec/policy.hpp>.

Type-level path grants applied through a temporary Landlock ruleset.

Rights selection

beneath<Path,Access> adds one path grant. handled is the union of the grants' rights, so rights outside that union are not restricted by this policy. apply checks availability, creates a narrowing ruleset, adds rules, and restricts the caller. landlock_policy_none performs no work. The pipe confine/beneath/port/enforce adaptors use similar runtime ruleset operations and return value/error results; destroying the temporary owner does not undo enforcement.
