Queues

From micron reference
micron reference › Containers and strings

FIFO containers and concurrent queues, including single-producer/single-consumer and multi-producer/multi-consumer forms.

Overview

micron::queue<T, N>A FIFO container of elements of type T.
micron::spsc_queue<T, N>A bounded queue intended for one producer and one consumer.
spsc_queue::push(value)Attempts to enqueue value; returns whether the insertion succeeded.
spsc_queue::pop(out)Attempts to remove an element into out; returns whether an element was obtained.

Interface notes

micron::queue<T, N>

A FIFO container of elements of type T.

micron::spsc_queue<T, N>

A bounded queue intended for one producer and one consumer.

spsc_queue::push(value)

Attempts to enqueue value; returns whether the insertion succeeded.

Defined in header <micron/queue/spsc_queue.hpp>.

Parameters

valueThe element to enqueue.

Return value

True if the element was enqueued, or false if the queue was full.

spsc_queue::pop(out)

Attempts to remove an element into out; returns whether an element was obtained.

Defined in header <micron/queue/spsc_queue.hpp>.

Parameters

outReceives the removed element on success.

Return value

True if an element was removed, or false if the queue was empty.

Example

#include <micron/queue/spsc_queue.hpp>

int main()
{
  micron::spsc_queue<int, 16> values;
  int input = 7;
  int output = 0;
  return values.push(micron::move(input)) && values.pop(output) && output == 7 ? 0 : 1;
}
