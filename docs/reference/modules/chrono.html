Date and time

From micron reference
micron reference › System interfaces

Clocks, durations, calendar calculations, parsing, formatting, and time-zone facilities.

Overview

micron::chrono::is_leap(year)Tests whether year is a leap year.
micron::chrono::days_in_month(year, month)Returns the number of days in the selected month.
micron::chrono::days_from_civil(year, month, day)Converts a civil date to its day count.

Interface notes

micron::chrono::is_leap(year)

Tests whether year is a leap year.

micron::chrono::days_in_month(year, month)

Returns the number of days in the selected month.

Defined in header <micron/chrono/calendar.hpp>.

constexpr u32 days_in_month(i32 year, u32 month) noexcept;

Parameters

yearThe civil year.
monthThe month number, from 1 through 12.

Return value

The number of days in the month, accounting for leap years, or zero for an invalid month.

micron::chrono::days_from_civil(year, month, day)

Converts a civil date to its day count.

Example

#include <micron/chrono/calendar.hpp>

int main()
{
  return micron::chrono::is_leap(2024) && micron::chrono::days_in_month(2024, 2) == 29 ? 0 : 1;
}
