Atomic operations

From micron reference
micron reference › Concurrency

Atomic values, operations, and memory-order selections for synchronization between execution contexts.

Overview

micron::atomic_token<T>Stores an atomic value of type T and provides operations including loads, stores, and compare-and-swap.
atomic_token::get(order)Loads the value using the selected memory order.
atomic_token::store(value, order)Stores value using the selected memory order.

Interface notes

micron::atomic_token<T>

Stores an atomic value of type T and provides operations including loads, stores, and compare-and-swap.

atomic_token::get(order)

Loads the value using the selected memory order.

atomic_token::store(value, order)

Stores value using the selected memory order.

Example

#include <micron/atomic/atomic.hpp>

int main()
{
  micron::atomic_token<int> value(2);
  value.fetch_add(3, micron::memory_order_relaxed);
  return value.get(micron::memory_order_relaxed) == 5 ? 0 : 1;
}
