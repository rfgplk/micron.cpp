Files and filesystem

From micron reference
micron reference › Input and output

File handles, paths, directory traversal, filesystem operations, and whole-file helpers.

Overview

micron::io::fileA file handle with read, write, seek, and line-processing operations.
micron::io::open_file(path, mode)Opens path with the selected mode and returns a file object. Inspect valid() and raw_fd() to determine whether opening succeeded.
micron::io::file_size(path)Returns the file size in bytes, or -1 when the metadata query fails.
micron::io::read_file<T>(path)Reads a file into T and returns option<T, io::error_t>. The first alternative is the value; the second is an error.
micron::io::basic_filesystemManages a collection of file handles with open, close, lookup, and synchronization operations.

Interface notes

micron::io::file

A file handle with read, write, seek, and line-processing operations.

micron::io::open_file(path, mode)

Opens path with the selected mode and returns a file object. Inspect valid() and raw_fd() to determine whether opening succeeded.

micron::io::file_size(path)

Returns the file size in bytes, or -1 when the metadata query fails.

Defined in header <micron/io/fsys.hpp>.

posix::off64_t file_size(const io::path_t& path);

Parameters

pathPath of the file to inspect.

Return value

The size reported by the filesystem in bytes, or -1 if the metadata query fails.

micron::io::read_file<T>(path)

Reads a file into T and returns option<T, io::error_t>. The first alternative is the value; the second is an error.

Defined in header <micron/io/fsys.hpp>.

Parameters

TThe string or contiguous container type used for the result; its elements must be one byte.
pathPath of the file to read.

Return value

An option<T, io::error_t>. The first alternative holds the data; the second holds an error.

Notes

Use is_first() to test for a value before calling cast<T>().

micron::io::basic_filesystem

Manages a collection of file handles with open, close, lookup, and synchronization operations.

Example

#include <micron/io/fsys.hpp>

int main()
{
  micron::io::path_t path("/proc/self/status");
  return micron::io::file_size(path) >= 0 ? 0 : 1;
}
