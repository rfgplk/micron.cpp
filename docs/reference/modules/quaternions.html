micron::math::quaternions::conjugate(q)

Returns the conjugate of quaternion q.

Defined in header <micron/math/quaternions/algebra.hpp>.

Parameters

qThe quaternion to conjugate.

Return value

A quaternion with the vector components negated and the scalar component unchanged.

micron::math::quaternions::normalize(q)

Returns a normalized quaternion.

Defined in header <micron/math/quaternions/algebra.hpp>.

Parameters

qThe quaternion to normalize.

Return value

A quaternion representing the normalized value of q.

Notes

A non-finite input or an input whose squared norm is too small produces a NaN-tagged quaternion.

Example

#include <micron/math/quaternions/algebra.hpp>

int main()
{
  namespace q = micron::math::quaternions;
  q::quaternion<double> value(0, 0, 0, 2);
  auto unit = q::normalize(value);
  auto conjugate = q::conjugate(unit);
  return conjugate.w > 0.999 && conjugate.w < 1.001 ? 0 : 1;
}
