Asynchronous file I/O

From micron reference
micron reference › Input and output

The micron::io::flash interfaces use io_uring for file operations. The available operation tier depends on kernel capabilities and successful ring initialization.

Overview

micron::io::flash::engineOwns an io_uring-backed engine and provides initialization, submission, and shutdown operations.
micron::io::flash::tierIdentifies the available operation tier: none, plumbing, basic, or fixed.
engine::live()Reports whether the engine is live.
engine::level()Returns the selected capability tier.
