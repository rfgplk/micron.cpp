Interface notes

micron::math::fft::rfft(input, n)

Transforms n real input samples and returns the frequency-domain result.

Defined in header <micron/math/fft.hpp>.

Parameters

inputPointer to real input samples.
nNumber of input samples.

Return value

The frequency-domain result. Pass its data and the original length to irfft for the inverse transform.

micron::math::fft::irfft(input, n)

Reconstructs n real samples from the frequency-domain input.

micron::math::fft::descriptor<T>

Describes a transform's dimensions, domain, and layouts.

micron::math::fft::plan<T>

Constructs a reusable transform plan from a descriptor.

micron::math::fft::workspace<T>

Provides scratch storage for a transform plan.

Example

#include <micron/math/fft.hpp>

int main()
{
  double samples[4]{ 1, 0, 0, 0 };
  auto spectrum = micron::math::fft::rfft(samples, 4);
  auto restored = micron::math::fft::irfft(spectrum.data(), 4);
  return restored[0] > 0.999 && restored[0] < 1.001 ? 0 : 1;
}
