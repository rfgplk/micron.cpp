Memory operations

From micron reference
micron reference › Memory management

Memory copying, movement, filling, comparison, and address utilities. Select the overload according to whether its count is expressed in elements or bytes.

Overview

micron::memcpy(destination, source, count)Copies count elements for the typed overload and returns destination. The source and destination ranges must not overlap.
micron::memmove(destination, source, count)Moves the selected range and permits overlap.
micron::memset(destination, value, count)Fills count bytes at destination with the byte value value and returns destination.
micron::memcmp(left, right, count)Compares the selected memory ranges and returns an ordering result.

Interface notes

micron::memcpy(destination, source, count)

Copies count elements for the typed overload and returns destination. The source and destination ranges must not overlap.

Defined in header <micron/memory/cmemory/memcpy.hpp>.

template<typename F, typename D>
constexpr F* memcpy(F* destination, const D* source, u64 count) noexcept;

Parameters

destinationPointer to the first destination element.
sourcePointer to the first source element.
countNumber of elements to copy for this typed overload.

Return value

destination.

Notes

The source and destination ranges must not overlap. A separate void* overload takes its count in bytes.

micron::memmove(destination, source, count)

Moves the selected range and permits overlap.

Defined in header <micron/memory/cmemory/memmove.hpp>.

template<typename F, typename D>
F* memmove(F* destination, D* source, u64 count) noexcept;

Parameters

destination, sourcePointers to the destination and source ranges.
countNumber of elements for this typed overload.

Return value

destination.

Notes

The ranges may overlap. A separate void* overload takes its count in bytes.

micron::memset(destination, value, count)

Fills count bytes at destination with the byte value value and returns destination.

Defined in header <micron/memory/cmemory/memset.hpp>.

template<typename F>
F* memset(F* destination, byte value, u64 count) noexcept;

Parameters

destinationAddress of the first destination byte.
valueByte value to write.
countNumber of bytes to write.

Return value

destination.

micron::memcmp(left, right, count)

Compares the selected memory ranges and returns an ordering result.

Example

#include <micron/allocator.hpp>
#include <micron/memory/memory.hpp>

int main()
{
  micron::chunk<byte> memory = micron::allocator_serial<>::create(32);
  micron::memset(memory.ptr, 42, 32);
  bool ok = memory.ptr[0] == 42 && memory.ptr[31] == 42;
  micron::allocator_serial<>::destroy(memory);
  return ok ? 0 : 1;
}
