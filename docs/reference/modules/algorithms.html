Algorithms

From micron reference
micron reference › Algorithms

Algorithms operate on iterator ranges or containers, depending on the overload. The lazy algorithms have a separate section.

Overview

micron::find(first, last, value)Searches the half-open range [first, last) for value and returns a pointer to the first match, or a null pointer when no match is found.
micron::find_if(first, last, predicate)Returns the first element satisfying predicate, or a null pointer if none does. Available overloads accept predicates on values or pointers.
micron::count(first, last, value)Returns the number of elements equal to value in the range.
micron::equal(first, last, other)Tests whether the elements in the first range equal the corresponding elements beginning at other.
micron::fpContains functional algorithms that produce results from containers and functions.

Interface notes

micron::find(first, last, value)

Searches the half-open range [first, last) for value and returns a pointer to the first match, or a null pointer when no match is found.

Defined in header <micron/algorithm/find.hpp>.

template<typename T, class P>
constexpr T* find(T* first, T* last, const P& value) noexcept;
template<typename T, class P>
constexpr const T* find(const T* first, const T* last, const P& value) noexcept;

Parameters

first, lastPointers delimiting the half-open range to inspect.
valueThe value to find.

Return value

A pointer to the first matching element, or a null pointer when no match is found.

Notes

The pointer overload requires the element type and search value to satisfy its conversion constraint. Container overloads are also available.

micron::find_if(first, last, predicate)

Returns the first element satisfying predicate, or a null pointer if none does. Available overloads accept predicates on values or pointers.

Defined in header <micron/algorithm/find.hpp>.

Parameters

first, lastPointers delimiting the half-open range to inspect.
predicateA callable tested on each element or element pointer, according to the selected overload.

Return value

A pointer to the first element for which the predicate is true, or a null pointer when none matches.

micron::count(first, last, value)

Returns the number of elements equal to value in the range.

micron::equal(first, last, other)

Tests whether the elements in the first range equal the corresponding elements beginning at other.

micron::fp

Contains functional algorithms that produce results from containers and functions.

Example

#include <micron/algorithm/find.hpp>
#include <micron/sort/quick.hpp>
#include <micron/vector/vector.hpp>

int main()
{
  micron::vector<int> values({ 4, 1, 3 });
  micron::sort::quick(values);
  const int *found = micron::find(values.cbegin(), values.cend(), 3);
  const int *missing = micron::find(values.cbegin(), values.cend(), 9);
  return found && *found == 3 && missing == nullptr && values[0] == 1 ? 0 : 1;
}
