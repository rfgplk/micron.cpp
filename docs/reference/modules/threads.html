Interface notes

micron::auto_thread<>(function, args...)

Starts a thread that invokes function with the supplied arguments.

Defined in header <micron/thread/thread_types/auto_thread.hpp>.

Parameters

functionA callable invoked by the new thread.
argsArguments supplied to the callable.

Notes

The object is neither copyable nor movable. Its destructor joins a live thread. The worker stack is allocated separately; Stack_Size selects its size.

auto_thread::result<T>()

Retrieves the thread function's result as type T.

Defined in header <micron/thread/thread_types/auto_thread.hpp>.

template<typename R>
  requires (micron::is_trivially_copyable_v<R> && sizeof(R) <= sizeof(byte*))
R result();

Parameters

RThe result type. It must be trivially copyable and no larger than a pointer.

Return value

The stored literal result after waiting for completion; a value-initialized R if the payload is not a literal result.

Notes

Retrieve the result before joining: joining releases the thread payload.

auto_thread::join()

Waits for a joinable thread to complete and joins it.

Defined in header <micron/thread/thread_types/auto_thread.hpp>.

int join();

Return value

0 after joining and releasing a thread, or 1 if it was already joined or released.

micron::solo::spawn(function, args...)

Creates an independent thread object and returns an owning pointer to it.

micron::solo::join(thread)

Joins the specified thread. The pointer overload clears its owning pointer after joining.

Example

#define MICRON_ABC_MT 1
#include <micron/thread/thread_types/auto_thread.hpp>

int main()
{
  micron::auto_thread<> worker([](int value) { return value * 2; }, 21);
  int result = worker.result<int>();
  worker.join();
  return result == 42 ? 0 : 1;
}
