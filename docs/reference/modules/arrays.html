Arrays

From micron reference
micron reference › Containers and strings

Fixed-size and specialized array containers, including mutable, immutable, persistent, and multidimensional forms.

Overview

micron::array<T, N>Stores N elements of T in the array object. N must be positive and the total storage must satisfy the class constraint.
array::array()Constructs the elements from T{}.
array::array(initializer_list)Constructs from the supplied elements and value-initializes the remainder. An initializer list larger than N reports a runtime error.
array::size(), array::data()Return the number of elements and a pointer to the first element, respectively.
array::begin(), array::end()Return iterators delimiting the elements.

Interface notes

micron::array<T, N>

Stores N elements of T in the array object. N must be positive and the total storage must satisfy the class constraint.

Defined in header <micron/array/array.hpp>.

template<is_regular_object T, usize N = 64>
  requires (N > 0 and ((N * sizeof(T)) < (1 << 22)))
class array;

Parameters

TThe element type. It must satisfy is_regular_object.
NThe number of elements. It must be positive and the object's element storage must be less than 2²² bytes.

Notes

The elements are stored in the array object. Destruction destroys its elements. The initializer-list constructor fills omitted elements with T{} and reports an error if the list is too large.

array::array()

Constructs the elements from T{}.

array::array(initializer_list)

Constructs from the supplied elements and value-initializes the remainder. An initializer list larger than N reports a runtime error.

array::size(), array::data()

Return the number of elements and a pointer to the first element, respectively.

array::begin(), array::end()

Return iterators delimiting the elements.

Example

#include <micron/array/array.hpp>

int main()
{
  micron::array<int, 4> values({ 2, 4, 6, 8 });
  values[1] = 5;
  return values.size() == 4 && values[1] == 5 ? 0 : 1;
}
