Build configuration

From micron reference
micron reference › Language support

Preprocessor definitions and build modes select library facilities at compile time. Define a configuration macro consistently before including the headers that use it.

Overview

__micron_freestandingSelects freestanding runtime paths, including the freestanding thread backend where available.
MICRON_ABC_MTEnables the multithreaded abcmalloc paths. In a freestanding thread-using translation unit, define it before allocator configuration is included.
MICRON_NO_ZZZ_HASHDisables the zzz hash selection used by the default hashing configuration.
MICRON_MEM_NT_THRESHOLDSets the default threshold, in bytes, used by the memory operation tuning code.
MICRON_ENABLE_ATTACHEnables attachment support in code that provides an attach-capable host.
__micron_reflectionIs defined when the selected C++ language mode and compiler expose reflection support. It gates the reflection interfaces.
