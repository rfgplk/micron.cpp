Input devices

From micron reference
micron reference › Input and output

Input-device abstractions, event decoding, key mapping, polling, virtual devices, and Wayland input sources. Availability depends on the host environment.

Overview

micron::uxin::device_tRepresents an input device in the input subsystem.
micron::uxin::basic_wayland_sourceProvides a Wayland input source with bind, polling, and release operations.

Interface notes
