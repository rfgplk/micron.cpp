Pointer utilities

From micron reference
micron reference › Memory management

Ownership and observation wrappers for dynamically managed objects.

Overview

micron::ptr<T>A unique ownership pointer. Construction can forward arguments to the managed object; moving transfers ownership.
micron::sptr<T>A shared ownership pointer. Copying a shared pointer retains a reference to its managed object.
micron::wptr<T>A non-owning observer associated with a shared pointer.
micron::atom_ptr<T>An ownership pointer with atomic pointer operations.

Interface notes

micron::ptr<T>

A unique ownership pointer. Construction can forward arguments to the managed object; moving transfers ownership.

micron::sptr<T>

A shared ownership pointer. Copying a shared pointer retains a reference to its managed object.

micron::wptr<T>

A non-owning observer associated with a shared pointer.

micron::atom_ptr<T>

An ownership pointer with atomic pointer operations.

Example

#include <micron/pointer.hpp>

struct value {
  int number;
  explicit value(int n) : number(n) { }
};

int main()
{
  micron::ptr<value> owner(42);
  return owner->number == 42 ? 0 : 1;
}
