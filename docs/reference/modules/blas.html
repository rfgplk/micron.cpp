Vector and matrix operations in micron::math::blas, including level 1, 2, and 3 operations and supported dispatch variants.

Overview

Interface notes

micron::math::blas::level1::axpy

Adds a scaled input vector to an output vector.

Defined in header <micron/math/blas/level1.hpp>.

template<typename T>
constexpr void axpy(T alpha, const T* x, const T* x_end, T* y) noexcept;

Parameters

alphaScale factor for the input values.
x, x_endThe half-open input range.
yOutput range with at least x_end - x elements.

Return value

None. For each element, assigns y[i] + alpha * x[i] to y[i].

Notes

The pointer parameters are restricted; use non-overlapping input and output ranges.

micron::math::blas::level1::scal

Scales the selected vector.

micron::math::blas::level3::gemm

Performs a general matrix multiplication with the selected operands and scaling parameters.

Example

#include <micron/math/blas/level1.hpp>

int main()
{
  const double x[]{ 1, 2, 3 };
  double y[]{ 10, 20, 30 };
  micron::math::blas::level1::axpy(2.0, x, x + 3, y);
  return y[0] == 12 && y[1] == 24 && y[2] == 36 ? 0 : 1;
}
