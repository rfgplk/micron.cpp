Vectors

From micron reference
micron reference › Containers and strings

Dynamically sized and fixed-capacity sequence containers. The vector family includes mutable, immutable, persistent, concurrent, and segmented variants.

Overview

micron::vector<T, Alloc, Sf>Owns a contiguous sequence of T. Alloc selects the allocator and Sf controls the container checks; checks are enabled by default.
vector::vector(n, value)Constructs n elements initialized from value. The one-argument size constructor value-initializes its elements.
vector::size(), vector::max_size()Return the number of constructed elements and the current allocated capacity, respectively.
vector::reserve(n)Ensures space for at least n elements. It does not change the number of elements. Reallocation can invalidate pointers and iterators.
vector::push_back(value), vector::emplace_back(args...)Append an element by copying or moving value, or by constructing it from args.
vector::insert(position, value), vector::erase(position)Insert or erase at an index or iterator accepted by the selected overload; subsequent elements may move.
vector::clear()Destroys the constructed elements and sets the size to zero.
vector::find(value)Returns a pointer to a matching element, or a null pointer when no element matches.

Interface notes

micron::vector<T, Alloc, Sf>

Owns a contiguous sequence of T. Alloc selects the allocator and Sf controls the container checks; checks are enabled by default.

Defined in header <micron/vector/vector.hpp>.

template<typename T, class Alloc = micron::allocator_serial<>, bool Sf = true>
class vector;

Parameters

TThe element type.
AllocThe allocator type used for the element storage.
SfEnables the container's checks when true.

Notes

The vector owns its element storage. Operations that expand storage can invalidate pointers, references, and iterators. Copy and move availability depends on the element type.

vector::vector(n, value)

Constructs n elements initialized from value. The one-argument size constructor value-initializes its elements.

vector::size(), vector::max_size()

Return the number of constructed elements and the current allocated capacity, respectively.

Defined in header <micron/vector/vector.hpp>.

size_type size() const;
size_type max_size() const;

Return value

size() returns the number of constructed elements. max_size() returns the current allocation capacity in elements.

vector::reserve(n)

Ensures space for at least n elements. It does not change the number of elements. Reallocation can invalidate pointers and iterators.

Defined in header <micron/vector/vector.hpp>.

void reserve(size_type n);

Parameters

nMinimum requested capacity, in elements.

Return value

None.

Notes

If n does not exceed the current capacity, no expansion is performed. On expansion, existing pointers, references, and iterators can be invalidated. The number of elements is unchanged.

Parameters

Return value

Example

#include <micron/vector/vector.hpp>

int main()
{
  micron::vector<int> values;
  values.reserve(4);
  values.push_back(3);
  values.push_back(7);
  values.insert(1, 5);
  values.erase(usize(0));
  return values.size() == 2 && values[0] == 5 && values[1] == 7 && values.find(99) == nullptr ? 0 : 1;
}
