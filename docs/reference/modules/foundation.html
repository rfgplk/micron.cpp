Types and language support

From micron reference
micron reference › Language support

Fundamental types, configuration definitions, byte order, and the foundation header. Include the specific facility needed by a translation unit.

Overview

usizeAn unsigned integer type used for sizes and indices. Its width follows the target address width.
u8, u16, u32, u64Unsigned integer aliases with the indicated widths. Signed counterparts are named i8, i16, i32, and i64.
byteAn unsigned byte type used by the memory and binary I/O interfaces.
<micron/std.hpp>Includes common types, traits, allocation, errors, and other foundation facilities. Individual modules may require additional headers.
