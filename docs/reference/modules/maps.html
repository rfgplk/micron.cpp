Maps

From micron reference
micron reference › Containers and strings

Associative containers for keys and values, including Robin Hood, hopscotch, Swiss, persistent, and tree-backed forms.

Overview

micron::robin_map<K, V>Stores keys of type K with mapped values of type V using open addressing.
robin_map::insert(key, value)Inserts a key and its associated value into the map.
robin_map::find(key)Returns a pointer to the mapped value, or a null pointer if the key is absent.
robin_map::contains(key), robin_map::erase(key)Test for a key and remove a key, respectively.
micron::stack_swiss_map<K, V, N>A fixed-capacity Swiss-style table with its storage in the object.

Interface notes

micron::robin_map<K, V>

Stores keys of type K with mapped values of type V using open addressing.

robin_map::insert(key, value)

Inserts a key and its associated value into the map.

Defined in header <micron/maps/robin.hpp>.

Parameters

keyThe key to insert.
valueThe mapped value to insert.

Return value

A pointer to the mapped value. The available overloads determine whether the arguments are copied or moved.

Notes

Insertion can report a library error when the table cannot accommodate the probe sequence.

A fixed-capacity Swiss-style table with its storage in the object.

Example

#include <micron/map.hpp>

int main()
{
  micron::robin_map<int, int> values;
  values.insert(2, 20);
  int *found = values.find(2);
  return found && *found == 20 && values.find(3) == nullptr ? 0 : 1;
}
