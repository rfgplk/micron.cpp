Synchronization

From micron reference
micron reference › Concurrency

Synchronization utilities include semaphores, futures, channels, latches, and yield operations.

Overview

micron::basic_semaphore(initial)Constructs a semaphore with an initial permit count.
basic_semaphore::wait()Waits for a permit and consumes it. An unexpected futex error can also cause it to return; this function does not return an error code.
basic_semaphore::try_wait()Attempts to consume a permit without waiting; returns true if one was obtained.
basic_semaphore::flag()Adds a permit and wakes a waiter when required.

Interface notes

micron::basic_semaphore(initial)

Constructs a semaphore with an initial permit count.

basic_semaphore::wait()

Waits for a permit and consumes it. An unexpected futex error can also cause it to return; this function does not return an error code.

basic_semaphore::try_wait()

Attempts to consume a permit without waiting; returns true if one was obtained.

Defined in header <micron/sync/semaphore.hpp>.

bool try_wait() noexcept;

Return value

True if a permit was available and consumed; false otherwise. The call does not wait.

basic_semaphore::flag()

Adds a permit and wakes a waiter when required.

Example

#include <micron/mutex/mutex.hpp>
#include <micron/mutex/locks.hpp>
#include <micron/sync/semaphore.hpp>

int main()
{
  micron::mutex lock;
  int value = 0;
  {
    micron::lock_guard<micron::mutex> guard(lock);
    value = 7;
  }
  micron::basic_semaphore permits(1);
  bool acquired = permits.try_wait();
  return value == 7 && acquired && !permits.try_wait() ? 0 : 1;
}
