Interface notes

micron::regex(pattern)

Constructs an expression from pattern. valid() reports whether the pattern was accepted.

regex::match(input), regex::search(input)

Search input for a match and return an rmatch describing it.

Defined in header <micron/regex/regex.hpp>.

template<class S> rmatch match(const S& input) const noexcept;
template<class S> rmatch search(const S& input) const noexcept;

Parameters

inputThe character sequence to search.

Return value

An rmatch. Check has_match() before using its captures.

Notes

Both operations perform an unanchored search. Captured spans refer to the input, so the input must remain valid while those spans are used.

regex::has_match(input)

Returns true if a match is found.

regex::search_n(data, length)

Searches length characters starting at data; embedded null characters are included.

rmatch::group_start(i), rmatch::group_end(i)

Return the start and end offsets of capture i, or -1 when the capture is absent.

Defined in header <micron/regex/regex.hpp>.

i64 group_start(usize i) const noexcept;
i64 group_end(usize i) const noexcept;

Parameters

iCapture index; zero identifies the whole match.

Return value

The offset from the start of the input, or -1 if there is no corresponding capture. The end offset is exclusive.

Example

#include <micron/regex.hpp>

int main()
{
  micron::regex expression("b+");
  micron::rmatch result = expression.search("aabbbcc");
  return expression.valid() && result.has_match() && result.group_start(0) == 2
         && result.group_end(0) == 5 ? 0 : 1;
}
