Allocation

From micron reference
micron reference › Memory management

Allocation interfaces expose byte chunks, allocators, memory resources, and the abcmalloc allocator. A chunk describes an address and length; it does not release the allocation on destruction.

Overview

micron::allocator_serial<>::create(bytes)Allocates storage for at least the requested number of bytes and returns a chunk<byte> with ptr and len members.
micron::allocator_serial<>::grow(chunk, bytes)Resizes the allocation described by chunk and returns the resulting chunk. The original address can be invalidated.
micron::allocator_serial<>::destroy(chunk)Releases the allocation represented by chunk using the same allocator.
micron::arena_resourceManages a region for allocations. Marks, rewinds, resets, and release operate on the resource's storage; object lifetimes remain the caller's responsibility.
micron::allocator_traits<A>Provides a uniform interface to the supported allocation operations of allocator A.
allocator_traits::has_unsized_deallocate<Alignment>Evaluates to true when the allocator supplies one of the unsized deallocate or destroy operations tested by the trait, with or without an explicit alignment template argument.

Interface notes

micron::allocator_serial<>::create(bytes)

Allocates storage for at least the requested number of bytes and returns a chunk<byte> with ptr and len members.

Defined in header <micron/allocator.hpp>.

Parameters

bytesNumber of bytes requested.

Return value

A chunk<byte> containing a pointer and the allocation's reported length.

Notes

Release the result with the matching allocator's destroy operation. A chunk is a descriptor and does not free the allocation itself.

micron::allocator_serial<>::grow(chunk, bytes)

Resizes the allocation described by chunk and returns the resulting chunk. The original address can be invalidated.

micron::allocator_serial<>::destroy(chunk)

Releases the allocation represented by chunk using the same allocator.

micron::arena_resource

Manages a region for allocations. Marks, rewinds, resets, and release operate on the resource's storage; object lifetimes remain the caller's responsibility.

micron::allocator_traits<A>

Provides a uniform interface to the supported allocation operations of allocator A.

allocator_traits::has_unsized_deallocate<Alignment>

Evaluates to true when the allocator supplies one of the unsized deallocate or destroy operations tested by the trait, with or without an explicit alignment template argument.

Example

#include <micron/allocator.hpp>
#include <micron/memory/memory.hpp>

int main()
{
  micron::chunk<byte> memory = micron::allocator_serial<>::create(32);
  micron::memset(memory.ptr, 42, 32);
  bool ok = memory.ptr[0] == 42 && memory.ptr[31] == 42;
  micron::allocator_serial<>::destroy(memory);
  return ok ? 0 : 1;
}
