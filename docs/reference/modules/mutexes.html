Mutexes and locks

From micron reference
micron reference › Concurrency

Mutexes, guards, barriers, and other locking primitives.

Overview

micron::mutexA non-copyable spin mutex.
mutex::lock()Waits until the mutex is acquired and returns an unlock member-function handle.
mutex::try_lock()Attempts to acquire the mutex without waiting. Returns true on acquisition.
mutex::unlock()Releases the mutex.
micron::lock_guard<M>Acquires the supplied mutex on construction and releases it when the guard is destroyed.

Interface notes

micron::mutex

A non-copyable spin mutex.

mutex::lock()

Waits until the mutex is acquired and returns an unlock member-function handle.

Defined in header <micron/mutex/mutex.hpp>.

auto lock();

Return value

A member-function handle used by micron's lock wrappers to release this mutex.

Notes

The call waits until it acquires the mutex. The mutex must be released after the protected work completes.

mutex::try_lock()

Attempts to acquire the mutex without waiting. Returns true on acquisition.

Defined in header <micron/mutex/mutex.hpp>.

bool try_lock() noexcept;

Return value

True if the mutex was acquired; false if it was already held.

mutex::unlock()

Releases the mutex.

micron::lock_guard<M>

Acquires the supplied mutex on construction and releases it when the guard is destroyed.

Example

#include <micron/mutex/mutex.hpp>
#include <micron/mutex/locks.hpp>
#include <micron/sync/semaphore.hpp>

int main()
{
  micron::mutex lock;
  int value = 0;
  {
    micron::lock_guard<micron::mutex> guard(lock);
    value = 7;
  }
  micron::basic_semaphore permits(1);
  bool acquired = permits.try_wait();
  return value == 7 && acquired && !permits.try_wait() ? 0 : 1;
}
