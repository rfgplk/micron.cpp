Sorting

From micron reference
micron reference › Algorithms

Sorting and selection algorithms in micron::sort. Overloads accept containers or iterator ranges as specified by the algorithm.

Overview

micron::sort::quick(container)Reorders the container using quicksort.
micron::sort::insertion(container, comparator)Reorders the container using insertion sort and the supplied ordering predicate.
micron::sort::merge(container)Reorders the container using merge sort.
micron::sort::is_sorted(first, last)Tests whether the elements in the selected range are ordered.

Interface notes

Example

#include <micron/algorithm/find.hpp>
#include <micron/sort/quick.hpp>
#include <micron/vector/vector.hpp>

int main()
{
  micron::vector<int> values({ 4, 1, 3 });
  micron::sort::quick(values);
  const int *found = micron::find(values.cbegin(), values.cend(), 3);
  const int *missing = micron::find(values.cbegin(), values.cend(), 9);
  return found && *found == 3 && missing == nullptr && values[0] == 1 ? 0 : 1;
}
