62 // these two switches determine the number of *pages* to allocate on initialization, by default, it's 512 pages for the
63 // internal abcmalloc metabuffer, and a minimum of 16 per each new sheet allocation
64 //
65 // NOTE: every eager mapping below is rounded up to __sheet_align (2 MiB) by __va_carve, so trimming
66 // either of the next two knobs past ~512 KiB of request buys nothing, the granule is the floor
