3503 // vshlq_* must lower to the hardware SSHL/USHL (NOT the GCC vector `<<`):
3504 // a negative per-lane count is a RIGHT shift (arithmetic for signed, logical for
3505 // unsigned) and |count| >= lane width yields 0. The `<<` operator makes negative
