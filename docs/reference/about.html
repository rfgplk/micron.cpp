micron reference

This reference describes the micron project. The page layout and visual assets are adapted from the cppreference-doc offline package and its cppreference/MediaWiki skin. The source checkout used is revision 4f773b7 (release v20251201). The site-specific CSS was adjusted to use local images and local fonts.

Module and type descriptions

Handwritten guides describe storage, ownership, operations, complexity, invalidation, and implementation limits for 1004 type entries in 69 modules. Related aliases and supporting types are explained together. Their source-file coverage is recorded in the guide inventory.

Function coverage and source evidence

The function reference contains 35844 callable entries from 1260 source files. Definitions specify their effects through source-equivalent code; return expressions and explicit failure sites are shown with source locations. Constructors, destructors, conversion operators, defaulted and deleted members, macro-generated overloads, and conditional backend variants are included.

Declaration-only compiler and host entry points are marked as declarations. Their bodies are not present in the declaring source. The complete numbered source snapshots retain surrounding class definitions, macros, branches, and copyright notices.
