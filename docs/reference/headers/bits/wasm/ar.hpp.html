micron::ar::record

Defined in header <micron/bits/wasm/ar.hpp>.

Current-frame diagnostic record with sp/fp pointers and a null program counter on WebAssembly.

Frame inspection limits

here returns the compiler's current frame address for sp and fp and leaves pc null. has_native_frames is false, caller always returns false, and frame_address supports only level zero. Native return-address/program-counter queries, stack-pointer mutation, arbitrary stack calls, and TLS-base mutation are deleted.

thread_pointer returns the compiler TLS base only in the threaded profile and null otherwise. The record neither owns its pointers nor provides a walkable native call chain. Use it only while the referenced current-frame information remains valid.
