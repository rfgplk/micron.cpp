Type reference

std::exception

Defined in header <micron/bits/wasm/eh_std.hpp>.

Minimal compiler exception base with a virtual destructor and fixed what() diagnostic.

Exception class family

bad_cast and bad_typeid derive from exception and return their corresponding fixed diagnostic strings. These small ABI classes do not allocate or store an application message. The returned text has static storage; retaining that text does not retain a caught exception object.
