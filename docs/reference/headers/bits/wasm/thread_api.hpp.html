micron::wasm::thread_packet

Defined in header <micron/bits/wasm/thread_api.hpp>.

Base result storage for a heap-allocated invocation submitted by the C++ worker-thread wrapper.

Callable and argument ownership

invocation_packet<F,A...> stores the callable and tuple of arguments by value after decay in the wrapper. run invokes that tuple and, for a trivially copyable return value no larger than eight bytes, copies its representation into the base value word. Void and unsupported larger results do not acquire a general result object. destroy deletes the correctly typed derived packet.

The packet belongs to its micron::thread controller until join releases it. References or pointers stored inside decayed arguments still borrow their referents. Storing an invocation packet does not deep-copy pointed-to application data or synchronize access to it.

micron::thread

Defined in header <micron/bits/wasm/thread_api.hpp>.

Move-only WebAssembly thread controller that owns an invocation packet and joins its worker on destruction.

Operations and lifetime

Construction allocates the decayed callable/arguments and spawns a worker; unavailable pool capacity or spawn failure raises thread_error after releasing the packet. Copying is disabled. Moving transfers the handle, packet, cached result, and status; move assignment first joins its current thread. Destruction joins and panics if a live handle remains after a join failure.

join waits, caches the result/status, destroys the invocation packet, and releases the slot. dismiss also joins; it is not a detached-thread operation. result<R> accepts only trivially copyable R no larger than a pointer, which on wasm32 is four bytes, despite the packet's eight-byte internal result word. Reading the wrong result type is not checked against the callable's actual type.

Stack_Size is checked against MICRON_WASM_STACK_SIZE; it does not independently reserve a smaller per-object stack. auto_thread<N> aliases this controller. terminate/kill are deleted. Select this type for scoped worker ownership when the calling worker may wait; the native Linux controller has a different backend and its own contracts.
