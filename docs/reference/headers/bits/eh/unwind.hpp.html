Type reference

_Unwind_Exception

Defined in header <micron/bits/eh/unwind.hpp>.

Compiler exception-control header used by the selected native unwinder ABI.

Backend-specific representation

DWARF targets store exception class, cleanup callback, and private unwinder words in the aligned control header. ARM EHABI instead stores class bytes plus unwinder/barrier/cleanup/personality caches. _Unwind_Context is an opaque declaration here and has backend-specific register/frame metadata definitions.

Reason/action enums and callback aliases describe the compiler unwinding protocol. Application code normally throws/catches through language syntax and does not manufacture these control records. Cleanup callback and exception-object lifetimes belong to that protocol; copying its bytes does not duplicate a live exception.
