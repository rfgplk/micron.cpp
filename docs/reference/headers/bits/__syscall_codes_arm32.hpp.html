arm32_syscalls

Defined in header <micron/bits/__syscall_codes_arm32.hpp>.

Compile-time ARM32 number table with EABI/OABI base aliases and ARM-private SWI values.

Number table

arm32_eabi uses base zero and supplies the active SYS_* aliases; arm32_oabi uses base 0x900000. The template adjusts numeric constants only. Selecting the OABI alias does not replace the svc EABI calling sequence in the native syscall wrapper. Private cache/TLS/breakpoint numbers occupy the ARM-private range.
