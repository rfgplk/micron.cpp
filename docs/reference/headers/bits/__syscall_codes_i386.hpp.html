i386_syscalls

Defined in header <micron/bits/__syscall_codes_i386.hpp>.

Compile-time i386 syscall-number table with native, legacy, and time64 entry numbers.

Number table

i386_native selects base zero and SYS_* aliases use its nested nr constants, typed as int. Legacy setuid/getuid numbers differ from the explicit 32-bit-UID forms, and legacy mmap differs from mmap2. The typed wrappers select the appropriate call and record layout; the number alone does not perform conversion.
