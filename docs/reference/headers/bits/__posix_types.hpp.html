Type reference

micron::posix::time_t

Defined in header <micron/bits/__posix_types.hpp>.

Signed 64-bit time alias. The namespace contains Linux-facing time64, large-file, identifier, and system-call types.

Related types

The header also re-exports most of these names into micron. idtype_t, syscall_long_t, syscall_ulong_t, and daddr_t remain in micron::posix. These aliases do not determine the layout of a complete ABI structure; use the structure definition supplied for the operation.

Aliases in micron::posixRepresentation and purpose
time_t, suseconds_t, suseconds64_tSigned 64-bit time and subsecond fields on all supported targets.
off_t, off64_t, blkcnt_tSigned 64-bit offsets and block counts.
ino_t, ino64_t, dev_t, rlim_tUnsigned 64-bit inode, device, and resource-limit values.
idtype_t, id_t, uid_t, gid_t, mode_tUnsigned 32-bit identifier, user/group, and mode values.
pid_t, key_t, clockid_t, daddr_tSigned 32-bit process, IPC, clock, and address fields.
syscall_long_t, syscall_ulong_tSigned and unsigned system-call words.
clock_t, blksize_tSigned system-call word types, including on time64 targets.
nlink_tUnsigned system-call word on amd64; unsigned 32-bit on the other targets.
timer_tvoid*, rather than the int used by kernel_timer_t.
