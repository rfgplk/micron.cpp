micron::chrono::serial

Defined in header <micron/chrono/cycles.hpp>.

Compile-time counter serialization policy.

Policies

none applies a compiler barrier; lfence applies instruction serialization; mfence_lfence drains memory before serialization. x86 additionally supplies cpuid and rdtscp; serialize requires the corresponding build feature. ARM supplies isb. serial_supported<S> checks the build's policy set, not runtime permissions. CPU/node extraction from tick_aux uses the Linux TSC_AUX encoding assumption.

template<serial S>
[[gnu::always_inline]] inline void
__fence_before() noexcept
{
  if constexpr ( S == serial::none ) {
    fence_compiler();
