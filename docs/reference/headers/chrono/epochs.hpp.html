micron::chrono::epoch::gps_time

Defined in header <micron/chrono/epochs.hpp>.

Signed GPS week and time-of-week seconds record.

Epoch conversion

GPS conversions take an explicit TAI-minus-UTC parameter, defaulting to the fixed value 37. They do not consult a historical leap-second database. Week decomposition uses floor arithmetic. NTP helpers use the 1900 epoch, a 32-bit seconds field, and an explicit era argument for reconstruction; FILETIME helpers use 100 ns ticks from 1601. TAI helpers add/subtract the supplied offset. Julian/MJD helpers implement their stated integer arithmetic without range checks.

micron::chrono::epoch::dos_datetime

Defined in header <micron/chrono/epochs.hpp>.

Two u16 packed FAT/DOS date and time words.

Range and precision

dos_from_civil supports years 1980..2107, returning zero words outside that range. Seconds are stored at two-second resolution; subsecond and UTC offset information is discarded. Other fields are masked rather than validated. civil_from_dos unpacks fields without checking that the encoded month/day/time is valid.

inline constexpr dos_datetime
dos_from_civil(const civil &c) noexcept
{
  if ( c.y < 1980 || c.y > 2107 ) return dos_datetime{ 0, 0 };
