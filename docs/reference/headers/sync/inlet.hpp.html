micron::base_inlet_t

Defined in header <micron/sync/inlet.hpp>.

A polymorphic base exposing a guarded value cell's borrowed tag, observed lock state, and reset operation.

Interface

It has a virtual destructor and pure virtual tag, locked, and reset members. Construction is protected. It supplies no ownership or scheduling protocol by itself; the inlet specialization implements the value storage and mutex.

micron::inlet

Defined in header <micron/sync/inlet.hpp>.

An immovable inline value protected by a configurable mutex, with scoped retained-access handles.

Access and exceptions

Mtx defaults to mutex. Construction value-initializes or copies/moves T and retains a borrowed tag string. access() locks and returns a move-constructible, noncopyable handle_t; its destructor unlocks. try_access() returns the handle as the first alternative of option<handle_t, tuple<>>, or an empty tuple on failure. A handle must not outlive its inlet; its pointers and references are protected only while it is retained.

apply(fn) holds a local unlock guard and returns fn(value), including any returned reference. Such a reference escapes after unlocking and requires separate protection. reset, load, and store manually unlock after the element operation: an exception from construction, copy, or assignment can leave the mutex held. Calls back into the same nonrecursive inlet while holding its handle deadlock.

tag() returns the retained tag pointer and locked() samples the mutex. Storage and handle state are inline; operation cost is the element/callback cost plus mutex acquisition. No waiter fairness, value versioning, or lifetime extension is supplied.
