micron::basic_semaphore

Defined in header <micron/sync/semaphore.hpp>.

A native-thread permit counter with a separate futex wake-token count.

Permit operations

Default construction starts at zero permits. wait() acquire-decrements the signed counter; a nonnegative result consumes an available permit, otherwise it consumes a wake token or parks. flag() release-increments the count and, when waiters are represented by a nonpositive count, adds a wake token and wakes one. try_wait() only consumes a strictly positive permit and never parks.

value() returns the signed snapshot, including negative waiter reservations. An unexpected futex error returns from wait() without a permit-status result and without repairing that reservation. Permit arithmetic overflow is unchecked. reset(init) overwrites both counters and requires no concurrent users. Move uses the tokens' non-atomic move operations and likewise requires quiescence. Copying is deleted.

abort() writes a large positive permit count and wake-token count, waking all. It does not establish a permanent closed state or restore a normal count. Uncontended operations use constant atomic work; waiting and wake consumption can retry indefinitely.

micron::semaphore

Defined in header <micron/sync/semaphore.hpp>.

A compile-time callable gated by an embedded permit counter.

Call protocol

semaphore<Fn> starts with one permit. run(args...) waits and invokes Fn but does not return the permit afterwards; the caller or callback must arrange permit(). get_permit() returns the trigger member-function pointer. permit_ahead(n) issues n separate permit additions, taking linear work in n. Move requires exclusive access to the embedded semaphore; copying is deleted.

  wait(void) noexcept
  {
    if ( counter.sub_fetch(1, memory_order::acquire) >= 0 ) return;      // a permit was there for us

    for ( ;; ) {
      u32 w = wakeups.get(memory_order::acquire);
      while ( w > 0 ) {
        if ( wakeups.compare_exchange_weak(w, w - 1, memory_order::acquire, memory_order::relaxed) ) return;
      }
      auto r = micron::__futex(wakeups.ptr(), futex_wait | futex_private_flag, 0u, nullptr, nullptr, 0);
      if ( r < 0 and r != -11 and r != -4 ) return;      // not EAGAIN/EINTR
    }
