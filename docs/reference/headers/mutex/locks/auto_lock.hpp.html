Type reference

micron::auto_guard

Defined in header <micron/mutex/locks/auto_lock.hpp>.

An immovable scope owner that calls M::lock() and invokes the returned reset handle at destruction.

Requirements

M defaults to mutex and must satisfy the micron mutex constraint and the reset-member-function protocol used by this guard. The guard stores a reference, allocates no memory, and cannot outlive the lock. It supplies no deferred, adopted, or manual release operation.
