Type reference

micron::unique_lock

Defined in header <micron/mutex/locks/unique_lock.hpp>.

A movable scope owner with a compile-time initial acquisition policy.

Initial state and operations

The first template parameter is lock_starts: locked acquires, adopt retrieves a handle for an already held lock, defer and unlocked retain an unlocked mutex, and attempt performs one try_lock. M defaults to mutex. Constructors accept a pointer or reference. Copying is deleted; move transfers the pointer and ownership handle, clearing the source.

lock() does nothing when already held; try_lock() returns false when already held. unlock() releases only an owned lock. These operations report a library error when no mutex is associated. release() returns the associated mutex pointer, clears the guard, and does not unlock it; the recipient must release any retained ownership. Destruction and move assignment release current ownership. swap() exchanges state in constant time.

unique_lock &
  operator=(unique_lock &&o)
  {
    if ( this == &o ) return *this;         // self-move must not discard our own lock
