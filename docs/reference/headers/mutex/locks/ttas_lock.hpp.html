Type reference

micron::basic_ttas_lock

Defined in header <micron/mutex/locks/ttas_lock.hpp>.

A policy-parameterized test-and-test-and-set lock with optional contention statistics.

Policy and aliases

P defaults to spin_yield. ttas_lock selects spin_yield; ttas_spin_lock selects spin_only. Acquires use weak compare-exchange with acquire success and relaxed failure; unlock is release. try_lock() is a single attempt and does not increment this type's acquisition statistic. A policy reporting park does not by itself make this lock perform a futex wait.

Lifetime and complexity

The lock object must remain at a stable address until its holder and all waiters have finished. These locks are neither copyable nor movable. Except for the explicitly recursive lock, acquiring a lock already held by the same execution context is unsupported. Destruction does not release a held lock or wait for outstanding users.

An uncontended acquisition and release use a constant number of atomic operations. Waiting has no finite step bound; a successful acquire requires the previous holder to make progress. Queue order, where provided, does not bound scheduling delay. Observation functions return snapshots and do not grant ownership.

    }

    __counted_backoff<P> bo(st);
    for ( ;; ) {
      while ( tk.get(memory_order::relaxed) == ATOMIC_LOCKED ) bo.relax();
      if ( tk.compare_and_swap(ATOMIC_OPEN, ATOMIC_LOCKED, memory_order::acquire, memory_order::relaxed) ) break;
      bo.relax();      // lost the race to another spinner; back off rather than re-CAS immediately
    }
    st.note_acquire();
    return &basic_ttas_lock::reset;
  }
