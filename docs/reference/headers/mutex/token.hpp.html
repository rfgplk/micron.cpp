Type reference

micron::token

Defined in header <micron/mutex/token.hpp>.

A one-shot flag with a legacy mutex-shaped callback for subsequent calls.

Call protocol

token_function<R, Args...> is the corresponding function-pointer alias. Although template parameters expose callback object and member-function types, static assertions require T = mutex* and A = void (mutex::*)(). The object stores a callback, an internal mutex, and an atomic fired flag.

operator()() makes one weak compare-and-swap from false to true: success returns true without invoking the callback; subsequent or spurious-failure calls invoke the callback if present and return false. The callback receives the internal mutex pointer and an unlock handle, but the token does not acquire that mutex first. Concurrent callback invocations are not serialized. The object is neither copyable nor movable and does not implement cancellation or stop-token registration.
