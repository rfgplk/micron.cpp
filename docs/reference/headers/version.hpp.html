kernel_support

Defined in header <micron/version.hpp>.

Global integer enumeration naming kernel targets in version metadata.

Enumerators

The enumerators are kernel_linux = 0, kernel_darwin = 1, kernel_obsd, kernel_netbsd, kernel_freebsd, and kernel_none. MICRON_KERNEL_TYPE currently selects kernel_linux. Enumerating a target does not provide that target's operating-system implementation.
