micron::except::runtime_error

Defined in header <micron/except.hpp>.

Exception category storing a borrowed message pointer. The other ordinary exception categories have the same message and category-code interface.

Construction and members

Explicit construction takes const char*. what() returns that exact pointer and is noexcept; which() returns the category's u32 code. Copying the exception copies the pointer, without allocating or copying message text. The categories do not validate a domain-specific property when constructed; the reporting operation chooses the category.

Exception categories

Codes from domain through network occupy 0x7f01 through 0x7f14 in the declared sequence; critical uses 0x7fff. A process exit status retains only the low status bits supplied by the environment, so the full category code is not an independently preserved OS exit-status value.

micron::except::memory_error_new_scalar

Defined in header <micron/except.hpp>.

Distinct memory-error subtype for scalar allocation failure. The allocator variants inherit the message and code behavior of memory_error.

Memory-error variants

Each variant's constructor forwards the message to memory_error. All return memory_errno from which(); their distinct C++ types allow more specific catches. Availability of a type does not imply that every corresponding allocator path throws in every configuration.
