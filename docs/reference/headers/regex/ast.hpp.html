micron::rgx::nk

Defined in header <micron/regex/ast.hpp>.

AST node-kind enumeration for Empty, Char, Class, Any, Concat, Alt, Star, Plus, Quest, Repeat, Group, Bol, and Eol.

Operands

The active kind determines which node operand fields are meaningful. Character/class nodes use a; binary concatenation/alternation use a and b; unary repetition uses a; Repeat uses a as child, b as minimum, c as maximum; Group uses a as child and b as its one-based group number. kInf marks an unbounded repeat maximum.

micron::rgx::node

Defined in header <micron/regex/ast.hpp>.

Compact AST record containing a node kind and three u32 operands.

Ownership

Children/classes are represented by indices into externally supplied arrays. The record owns no nodes or character sets and performs no dynamic allocation. Default construction denotes Empty with zero operands. Operand interpretation is specified by nk.

micron::rgx::parser

Defined in header <micron/regex/ast.hpp>.

Constexpr recursive-descent parser writing nodes and byte classes into caller-provided bounded arrays.

State and failures

Stores pattern pointer/length/current position, node/class pointers with capacities and live counts, explicit-group count, and ok. Parse routines mutate that state. Node/class overflow or recognized syntax errors set ok false; parse() additionally requires complete pattern consumption. The caller owns all backing storage. Decimal interval accumulators are u32 and do not provide a separate overflow diagnostic.

  parse_interval(u32 atom) noexcept
  {
    pos++;      // '{'

constexpr u32
  parse_class(void) noexcept
  {
    pos++;
    charreach r;
    bool negate = false;
    if ( peek() == '^' ) {
      negate = true;
      pos++;
    }
    bool first = true;
    while ( ok ) {
      int ch = peek();
      if ( ch == -1 ) {
        ok = false;
        break;
      }
      if ( ch == ']' && !first ) {
        pos++;
        break;
      }
      first = false;
      if ( ch == '[' && peek(1) == ':' ) {
        usize start = pos + 2;
        usize i = start;
        while ( i < len && pat[i] != ':' ) ++i;
        if ( i + 1 < len && pat[i] == ':' && pat[i + 1] == ']' ) {
          if ( !posix_class(pat + start, i - start, r) ) ok = false;
          pos = i + 2;
          continue;
        }
      }
      int lo = advance();
      if ( lo == '\\' ) {
        int e = advance();
        if ( e == -1 ) {
          ok = false;
          break;
        }
        lo = e;
      }
      if ( peek() == '-' && peek(1) != ']' && peek(1) != -1 ) {
        pos++;
        int hi = advance();
        if ( hi == '\\' ) hi = advance();
        if ( hi == -1 ) {
          ok = false;
          break;
        }
        if ( (u8)lo <= (u8)hi )
          r.set_range((u8)lo, (u8)hi);
        else
          ok = false;
      } else {
        r.set((u8)lo);
      }
    }
    if ( negate ) r.flip();
    return mk(nk::Class, add_class(r));
  }
