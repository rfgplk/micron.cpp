micron::rgx::regex

Defined in header <micron/regex/regex.hpp>.

Move-only owner of a runtime-compiled byte regular expression, exported as micron::regex.

Members and use

Construct from a null-terminated pattern or has_cstr object, inspect valid(), then search repeatedly. Copy operations are deleted. Move construction/assignment transfer instruction/class/DFA allocations and invalidate the source's valid state. Destruction frees them. match and search, including their _n forms, have identical unanchored behavior; use anchors in the pattern when the subject boundary must be asserted. Boolean has-match can use a separate DFA path.

micron::rgx::rmatch

Defined in header <micron/regex/regex.hpp>.

Capture-result descriptor storing success, group count, subject base, and 66 signed offsets, exported as micron::rmatch.

Fields and access

matched records success; ng includes whole-match group zero; base borrows subject bytes; caps[2*i] and caps[2*i+1] are start/end offsets. has_match and explicit bool conversion inspect matched. Accessors validate success/group bounds and return -1 or an empty slice for absent captures. Default construction is unmatched even though its offset array is zero-initialized. Copying the descriptor does not copy subject bytes.

micron::rgx::subject_t

Defined in header <micron/regex/regex.hpp>.

Nonowning (const char* p, usize n) byte-range descriptor used to normalize search input.

Normalization

as_subject(const char*) scans a nonnull C string and treats nullptr as a zero-length subject. The has_cstr overload copies c_str() and size() without rescanning or changing units. The descriptor owns no data and does not extend an object's lifetime.

template<fixed_string P, class S>
constexpr rmatch
cmatch(const S &input) noexcept
{
  constexpr usize n = P.size();
  constexpr usize maxn = n * 4 + 8;
  constexpr usize maxc = n + 4;
  constexpr usize maxi = n * 8 + 16;
  constexpr usize maxg = (n < kMaxGroups ? n : kMaxGroups);
  constexpr usize maxslots = 2 * (maxg + 1);

  rmatch r;

  node nodes[maxn]{};
  charreach cls[maxc]{};
  inst code[maxi]{};
  usize ncode = 0, ncls = 0;
  u32 ngroups = 0;
  if ( !compile_regex(P.data(), n, nodes, maxn, cls, maxc, code, maxi, ncode, ncls, ngroups) ) return r;
  if ( ngroups > maxg ) return r;

  usize nslots = 2 * (ngroups + 1);

  u32 a_pc[maxi]{};
  u32 b_pc[maxi]{};
  i64 a_sav[maxi * maxslots]{};
  i64 b_sav[maxi * maxslots]{};
  u32 seen[maxi]{};
  i64 work[maxslots]{};
  i64 mcaps[maxslots]{};

  subject_t sub = as_subject(input);

  vm m;
  m.pv = prog_view{ code, ncode, cls, ncls, ngroups };
  m.nslots = nslots;
  m.cap = ncode;
  m.in = sub.p;
  m.n = sub.n;
  m.a_pc = a_pc;
  m.a_sav = a_sav;
  m.b_pc = b_pc;
  m.b_sav = b_sav;
  m.seen = seen;
  m.gen = 0;
  m.work = work;
  m.mcaps = mcaps;

  finish_match(r, m, sub.p, ngroups);
  return r;
}
