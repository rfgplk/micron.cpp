Type reference

micron::memory_block

Defined in header <micron/memory_block.hpp>.

An owning contiguous byte buffer parameterized by a chunk allocator. Its size() and max_size() both report the allocator's current granted byte length.

Storage and special members

Default construction is deleted. Construction with n requests at least n bytes using 64-byte alignment; the returned grant can be larger according to the allocator policy. Every granted byte is part of the exposed range; there is no separate constructed-element count.

Copy construction allocates and copies the complete old grant. Copy assignment reuses equal-length storage or replaces it when grant lengths differ. Move construction and assignment transfer the allocator base and descriptor and clear the source descriptor. Move assignment first releases the destination's old allocation. Destruction returns the grant to the matching allocator.

The constructor taking chunk<byte>&& adopts the descriptor directly. It does not clear the caller's plain chunk, validate provenance, or verify that the allocation used the required allocator/alignment. The caller must perform an actual exclusive ownership transfer.

Complexity and iterator invalidation

Observers and checked access are constant time. Filling and copying are linear in granted bytes. Growth has backend resize cost and can copy the old grant. recreate, a replacing assignment, destruction, and any relocating resize invalidate old pointers, iterators, and references. A descriptor reference continues to refer to the owner's descriptor object, whose contents can change.

Use it for owning byte storage with allocator-selected capacity. It does not supply object construction, typed element alignment beyond the allocation request, or synchronization between readers and writers.
