micron::io::coro::async_readable

Defined in header <micron/io/coroutine/concepts.hpp>.

Checks for a read_some operation whose await result is convertible to max_t.

Concept family

ConceptRequired expression
async_readable<T>t.read_some(void*,usize) is recognized as an I/O awaitable
async_writable<T>t.write_some(const void*,usize) is recognized as an I/O awaitable
async_stream<T>Both async_readable and async_writable
async_seekable<T>async_readable plus t.read_at(u64,void*,usize) with the same result condition

Scope of checking

Recognition accepts direct await_ready/await_resume members or a member operator co_await, and checks conversion of await_resume to max_t. It does not inspect await_suspend, ADL operator co_await, ownership, retry behavior, cancellation, actual seekability, or a writable-position operation. The static assertions classify file as readable/writable/seekable and fd_io as a stream. A concept is compile-time expression metadata, not runtime I/O validation.
