micron::io::serialize::canonical::writer

Defined in header <micron/io/canonical.hpp>.

A non-owning bounded cursor that appends explicitly encoded fields to a mutable byte span.

Storage and operations

Construction retains a pointer and capacity; a null pointer with nonzero capacity is normalized to zero usable capacity. position() counts bytes successfully written and remaining() is capacity minus position. The writer allocates nothing and does not own or extend buffer lifetime. Copying copies cursor position and the borrowed pointer, not bytes.

MemberDescription
put_u8, put_u16, put_u32, put_u64Write unsigned values in little-endian order. The constrained generic put_unsigned accepts u16/u32/u64 only.
put_i64Converts to u64 and writes the resulting 64-bit representation.
put_f64Bit-casts f64 to u64 and writes its representation; no decimal or range conversion occurs.
put_bytes(source, count)Copies exactly count bytes without a length prefix. Rejects a null nonempty source or insufficient remaining space.

Failure and complexity

Each put returns bool. Insufficient space returns false without advancing position or writing that field; prior fields remain. Scalar puts take constant work, bytes take linear work in count. Constant evaluation uses byte loops; runtime uses representation copies and byte swaps on a big-endian host. Source/destination byte spans must satisfy the underlying non-overlapping copy contract. Concurrent copied writers sharing one buffer require external coordination.

micron::io::serialize::canonical::reader

Defined in header <micron/io/canonical.hpp>.

A non-owning bounded cursor decoding little-endian fields from a constant byte span.

Reads and views

Construction normalizes a null nonempty span to zero size. get_u8/u16/u32/u64 decode scalar fields, get_i64 bit-casts decoded u64 bits, and get_f64 bit-casts them to f64. A failed scalar read returns false without advancing the cursor or changing the destination value. All complete representations are accepted; no numeric/schema validation is added.

get_bytes(count, view) advances and returns a borrowed byte_view rather than copying bytes or reading an encoded count. On insufficient bytes it leaves the cursor and view unchanged. A zero-byte view can have null data for an empty/null source. Copying the reader copies its current position; copies can independently traverse the same immutable bytes.

Complexity and lifetime

Scalar operations and forming a byte view take constant work; no allocation occurs. Position/remaining count bytes. Views and readers must not outlive their source span or access it during conflicting mutation. The cursor provides no rewind, variable-integer decoding, string conversion, or automatic field schema.

micron::io::serialize::canonical::byte_view

Defined in header <micron/io/canonical.hpp>.

A borrowed constant byte span described by data and byte size.

Canonical byte frames

byte_frame_overhead is 16: an exact eight-byte MFR1 header followed by a little-endian u64 byte count. byte_frame_size(count) validates signed-result/size bounds and returns total bytes or negative invalid-argument. frame_bytes validates the complete destination/source spans before writing and returns that total; it allocates nothing.

unframe_bytes(source, count, view, maximum_bytes) requires the exact canonical header, checks encoded count against both the supplied maximum and available bytes, and returns consumed frame bytes while assigning a view into source + 16. Trailing bytes are allowed. Failure leaves the caller's view unchanged. Unlike generic MFR1 decoding, this interface is explicitly little-endian on every host and copies no payload during decoding.

Lifetime

A view owns no bytes. Copying it copies the pointer/count. Mutating, reallocating, unmapping, or destroying its source affects all views; the caller retains the source until the last use. Forming/decoding a view takes constant work; encoding copies a linear number of payload bytes.

    __builtin_memcpy(&expected, magic, sizeof(expected));
    if ( observed != expected ) return -error::invalid_arg;
  }
  reader in(source + 8, count - 8);
  u64 bytes = 0;
  in.get_u64(bytes);
  if ( bytes > maximum_bytes || bytes > static_cast<u64>(count - byte_frame_overhead) ) return -error::invalid_arg;
  const max_t consumed = byte_frame_size(static_cast<usize>(bytes));
  if ( consumed < 0 ) return consumed;
  value = { source + byte_frame_overhead, static_cast<usize>(bytes) };
  return consumed;
}
