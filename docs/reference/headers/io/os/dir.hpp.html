micron::io::dir

Defined in header <micron/io/os/dir.hpp>.

A directory descriptor owner with a per-object read cursor and an allocated cache of entry values.

Opening and traversal

Path construction performs existence/type probes then opens O_DIRECTORY|O_CLOEXEC and throws on failure. try_open avoids pre-probes and returns an invalid negative-error handle, with no runtime read until requested. It is noexcept although assigning an overlong fixed name can invoke the string's failure policy. Copy dup's fd and deep-copies cached entries while resetting cursor state; copies still share kernel offset. Move transfers fd/cache/cursor. Destruction closes through os_file.

next reads through the object's 8192-byte readdir_ctx and includes dot entries; it conflates end/error. rewind seeks to zero and resets that cursor. get_children lazily populates _entries only while empty; an actually empty directory is therefore reread on each call. list/refresh clear and rebuild from offset zero, skipping . and ... begin/end/count/empty/operator[] access only the current cache and do not trigger a fill. for_each opens another scoped traversal by stored pathname; for_each_entry/while/fold use the cached values.

Entry type predicates use d_type, so DT_UNKNOWN is not automatically repaired by stat. match_stat only considers entries already marked regular and queries each selected child size. Name/extension matches are case-sensitive byte tests. Cached entry values can become stale after outside mutations. A successful child create/remove/rename/link/symlink calls refresh, invalidating every previous cache reference/iterator. Do not perform those mutating operations from a cache traversal callback; collect names first.

Child operations and invalidation

open_child and *at metadata/mutation helpers use the pinned directory fd; their name arguments are not restricted to one safe component and can contain .. or absolute paths. Up/down/root navigation returns newly opened directories from recorded path text. create/create_all ignore mkdir status then open, so they can succeed on an existing directory. Child chmod/chown forward their status without a cache rebuild. chdir changes global cwd.

Cache growth/rebuild/clear/assignment/move/destruction invalidate references as dictated by vector; a copied entry value owns its fixed name. Per-object next state avoids ordinary readdir's global cursor but remains unsynchronized. Reading/building a cache takes linear entry/byte work and allocation; matching is linear in cached entries plus predicate/stat costs, while contains/name operations additionally compare name bytes. A refresh can be partial after a read error and supplies no separate enumeration status.

Constraints and complexity

entry_predicate requires an exact bool result for const directory-entry input. The provided predicates own their name text and can be copied independently of the directory. Extent/failure follows their fixed string types; raw text pointers must be valid, with pred_ext reading its first character. Exact/extension work is linear in relevant name length; naive substring matching is worst-case O(name_length*needle_length); type tests are constant. No filesystem call is made by the predicate itself.

micron::io::pred_size_eq

Defined in header <micron/io/os/dir.hpp>.

A numeric file-size predicate used by stat-assisted directory matching.

Related predicates

pred_size_eq, pred_size_gt, and pred_size_lt compare an off_t argument with one owned off_t value. pred_size_between stores low/high and tests the inclusive interval without reordering invalid endpoints. Builders are by_size/by_size_gt/by_size_lt/by_size_between. size_predicate requires an exact bool result from an off_t input. Comparisons take constant work and allocate nothing; obtaining the size is the directory algorithm's separate stat operation.
