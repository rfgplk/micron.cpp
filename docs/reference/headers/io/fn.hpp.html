micron::io::fn_like

Defined in header <micron/io/fn.hpp>.

Structural callable detection used to distinguish processing callbacks from other template arguments.

Callable and callback protocols

fn_like recognizes function/function-pointer/member-function forms, a detectable operator(), certain nonfinal class call operators, and nullary invocability. A final class with only overloaded or generic non-nullary operator() is not uniformly detected. fn_deducible is narrower: its call operator/function signature must be unambiguous for function_traits. Neither concept executes the callback.

chunk_fnfn(const byte*, usize) is well-formed; no return type required. The span is borrowed and the count is bytes.

Result conversion

to_option(count) places a nonnegative max_t in the first alternative and a negative result's error magnitude in io::error_t in the second. Option conversion to bool identifies the alternative according to option's own protocol; use is_first before retrieving a success value.
