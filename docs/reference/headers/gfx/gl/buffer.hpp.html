micron::gfx::gl::buffer

Defined in header <micron/gfx/gl/buffer.hpp>.

Owns a GL buffer name and records its binding target.

Creation and operations

Default construction is empty; target construction generates a name. buffer_target selects array, element, uniform, shader-storage, copy-read/write or pixel-pack/unpack binding. buffer_usage supplies stream/static/dynamic draw/read/copy hints to the driver. The hints do not reserve a C++ buffer or enforce an access policy.

data and sub_data bind this buffer and forward byte counts, offsets and caller data. map uses MapBufferRange and returns a driver pointer or null when the entry point is absent; unmap returns false when unavailable or when native unmapping reports failure. Byte ranges, access flags, current-context compatibility and GPU synchronization are caller requirements.

Lifetime and state

The wrapper is move-only, transfers its name and zeros the source. reset/destruction deletes the name when its entry point is present and then clears it; it does not retain or restore prior bindings. Mapped pointers are borrowed and cease to be valid after unmapping, storage replacement or deletion according to the native operation. Fixed wrapper work is O(1); allocation, transfer and mapping cost belongs to the driver.
