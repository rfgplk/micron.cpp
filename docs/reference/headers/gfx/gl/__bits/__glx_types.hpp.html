Type reference

micron::gfx::gl::GLXContext

Defined in header <micron/gfx/gl/__bits/__glx_types.hpp>.

Represents a borrowed native GLX context in the local X11 integration ABI.

Related native types

GLXContext and GLXFBConfig are opaque pointers. GLXDrawable, GLXWindow, GLXPbuffer and GLXPixmap are X11 identifier carriers. PFN_glX aliases describe procedure resolution, configuration/visual queries, context create/destroy/current binding, swap control and pbuffer operations. None of these aliases owns a library, display, context or drawable.

The GLX_* constants express framebuffer/context attributes and query selectors used by the wrapper. Direct calls require the matching live X display, correct current-thread context state and available extension entry points.
