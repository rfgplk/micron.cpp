Type reference

micron::gfx::gl::EGLDisplay

Defined in header <micron/gfx/gl/__bits/__egl_types.hpp>.

Represents an opaque EGL display handle in the local EGL ABI family.

Related native types

EGLContext, EGLSurface, EGLConfig, EGLClientBuffer, EGLSync and EGLImage are opaque pointer handles. EGLBoolean/EGLenum are unsigned 32-bit carriers, EGLint is signed 32-bit and EGLAttrib is pointer-sized. EGLTime, EGLuint64KHR and EGLnsecsANDROID carry 64-bit time/value fields. EGLNativeDisplayType, EGLNativeWindowType and EGLNativePixmapType carry backend-native borrowed objects or identifiers as declared.

PFN_egl aliases cover display acquisition/initialization, configuration queries, desktop-client binding, context/surface creation and destruction, current-context changes, swapping, procedure lookup and error queries. The EGL_* constants are attribute/result values, not capability probes. Copying a raw handle supplies no ownership or initialization reference count.
