micron::gfx::gl::vao

Defined in header <micron/gfx/gl/vao.hpp>.

Owns a GL vertex-array object name and configures selected vertex attribute bindings.

Operations and dependencies

Default construction generates a vertex array. Attribute helpers bind the VAO and supplied buffer, issue floating/normalized or integer vertex-pointer setup, and enable the attribute. The supplied buffer must use the appropriate array target; byte offsets, component counts, types, stride and attribute index are forwarded without bounds or compatibility checks. Several subordinate GL entry points are used without individual null checks.

The owner is move-only and does not retain the C++ buffer object. Native attribute bindings refer to GL buffer state, whose usability must be maintained for later draws. Binding/configuration leaves current VAO and buffer state changed. O(1) wrapper work excludes native validation and draw processing.
