micron::gfx::gl::context_hints

Defined in header <micron/gfx/gl/hints.hpp>.

Specifies requested GL context attributes and framebuffer preferences.

Members

MembersDefaults and effect
major, minor; core_profile, forward_compat4.6; core and forward compatible requested when the selected native creation path supports them
depth_bits, stencil_bits, ms_samples24, 8, 0; forwarded into native framebuffer configuration selection
color_bits, srgb32, false; present in the record but not used by the high-level window/context paths
double_buffertrue; used by GLX framebuffer selection; not applied by the EGL high-level path
debug; share_withfalse and null; request a debug context/callback and optionally borrow a compatible existing context for sharing

Constraints

Hints express requests, not a verified context capability report. GLX can fall back to legacy creation without preserving the requested version/profile. Sharing requires a compatible live native context. The hint record owns no context or strings and performs no allocation.
