micron::gfx::vk::descriptor_set_layout

Defined in header <micron/gfx/vk/descriptor_set_layout.hpp>.

Owns a Vulkan descriptor-set layout created from bindings or a raw create-info record.

Parameters and lifetime

The binding convenience path forwards caller binding descriptions. The raw overload preserves caller flags and pNext data. Binding uniqueness, descriptor counts, stage visibility, immutable-sampler dependencies and enabled feature constraints are not checked by the wrapper.

This move-only owner stores a raw device and handle and destroys the layout on reset without a GPU wait. It retains no binding array or sampler owners. Allocation and compatibility checks belong to the native API beyond constant local bookkeeping.
