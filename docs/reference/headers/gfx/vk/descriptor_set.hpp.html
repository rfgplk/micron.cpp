Type reference

micron::gfx::vk::descriptor_set

Defined in header <micron/gfx/vk/descriptor_set.hpp>.

Borrows a descriptor-set handle and device and forwards selected descriptor writes.

Updates and lifetime

Single-buffer and single-image helpers build temporary VkDescriptorBufferInfo or VkDescriptorImageInfo records and issue one UpdateDescriptorSets call. update_many forwards caller-supplied write/copy arrays. The wrapper does not own referenced buffers, image views, samplers, layouts or the pool from which the set was allocated.

The set is copyable and its destruction performs no free. Pool reset/destruction or explicit free invalidates all copies without changing their stored handles. Descriptor type, binding/array range, image layout, buffer alignment, update synchronization and descriptor indexing rules are caller requirements. Local fixed-write work is O(1); bulk update passes counts to the driver without a local ownership graph.
