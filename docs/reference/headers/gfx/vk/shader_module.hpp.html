micron::gfx::vk::shader_module

Defined in header <micron/gfx/vk/shader_module.hpp>.

Owns a Vulkan shader module created from SPIR-V words or a raw create-info record.

Parameters and results

The word-pointer constructor takes a byte size, not a word count. The pointer must satisfy the native SPIR-V alignment, length and content requirements; the wrapper does not validate or compile GLSL/source text. The raw overload forwards the supplied record. Required creation entries are checked and strict check_vk handles returned results.

The move-only owner stores no source/code container or pipeline ownership. Its device must outlive destruction. Native shader/pipeline compilation and storage costs are not described by a bound on the constant handle bookkeeping.
