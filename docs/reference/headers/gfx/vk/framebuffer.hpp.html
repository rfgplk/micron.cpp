micron::gfx::vk::framebuffer

Defined in header <micron/gfx/vk/framebuffer.hpp>.

Owns a Vulkan framebuffer and caches its extent.

Parameters and dependencies

Construction accepts a complete create-info or a render-pass handle, image-view array/count, width, height and layer count, default one layer. The wrapper does not own those attachments or the render pass, validate compatible formats/layers or resize image storage.

The owner is move-only and borrows its device. Destroy/recreate it when required by attachment/swapchain changes after outstanding use has completed. reset/destruction performs no wait. Extent access and handle bookkeeping are O(1); driver creation/destruction has native costs.
