micron::gfx::vk::query_pool

Defined in header <micron/gfx/vk/query_pool.hpp>.

Owns a Vulkan query pool and records its query type and count.

Queries and results

Creation specifies query type/count and optional pipeline-statistic flags. reset_range uses the host query-reset entry when present and requires applicable hostQueryReset feature support. Command-buffer query reset is a distinct recorded operation. Range bounds and pending-use rules are not checked locally.

get_results forwards destination byte size, stride, range and result flags and returns raw VkResult; a missing entry returns INITIALIZATION_FAILED. The flags determine 32/64-bit result width, waiting, partial results and availability data. Destination layout, alignment and capacity are caller requirements, and no result vector is allocated.

Lifetime and cost

The move-only owner destroys its pool without a completion wait. Recorded commands and result reads borrow it. Fixed wrapper work is O(1); query completion waits, native result copying and GPU execution supply the remaining cost.
