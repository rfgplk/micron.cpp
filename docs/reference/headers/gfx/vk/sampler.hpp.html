micron::gfx::vk::sampler

Defined in header <micron/gfx/vk/sampler.hpp>.

Owns a Vulkan sampler created from explicit sampling parameters or a raw record.

sampler_request defaults

sampler_request defaults to linear magnification/minification and mipmap filtering, repeat addressing on U/V/W, zero LOD bias, anisotropy disabled with maxAnisotropy=1, comparison disabled with NEVER, minLod=0, maxLod=VK_LOD_CLAMP_NONE, float opaque-black border and normalized coordinates. The enable Booleans are explicit; a larger maxAnisotropy alone does not enable anisotropy.

The wrapper forwards these fields without checking enabled samplerAnisotropy, device limits, format filtering support or unnormalized-coordinate restrictions. It owns no image/view or descriptor set. Move/reset follow the device-child lifetime rules, with constant local work plus native sampler costs.
