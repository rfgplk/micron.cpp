micron::gfx::vk::messenger

Defined in header <micron/gfx/vk/debug.hpp>.

Owns an optional debug-utils messenger while borrowing its Vulkan instance.

Callbacks and helpers

Default creation selects warning/error severity and general/validation/performance message types. The default callback writes the supplied message and a newline to diagnostic descriptor 2 and returns VK_FALSE. A raw create-info overload accepts a custom callback and user data; that data must outlive every possible callback invocation.

Object naming and queue/command-buffer label helpers use optional debug-utils entries and do not retain names, colors or object owners. Label colors copy four supplied floats or use zero values for a null color pointer. Object-name result codes are not exposed as checked success. These helpers require matching enabled extension support and correct queue/recording state.

Lifetime

The move-only messenger destroys its native handle before the instance must be released. Callback messages and arrays are borrowed for the callback's native lifetime. No application-wide debug serialization, filtering store or persistent message collection is supplied.

default_debug_messenger_callback(VkDebugUtilsMessageSeverityFlagBitsEXT /*severity*/, VkDebugUtilsMessageTypeFlagsEXT /*types*/,
                                 const VkDebugUtilsMessengerCallbackDataEXT *data, void * /*user*/) noexcept
{
  if ( !data || !data->pMessage ) return VK_FALSE;
  const char *m = data->pMessage;
  usize n = micron::strlen(m);
  micron::syscall(SYS_write, 2, m, n);
  const char nl = '\n';
  micron::syscall(SYS_write, 2, &nl, 1);
  return VK_FALSE;
}
