micron::gfx::platform::wl_interface

Defined in header <micron/gfx/platform/__bits/__wayland_types.hpp>.

Describes a Wayland protocol interface for the local proxy marshaller.

Protocol ABI families

FamilyPurpose
wl_interface, wl_messageInterface name/version and request/event counts; message names, wire signatures and referenced interface arrays
wl_argumentUnion of signed/unsigned/fixed scalars, strings, objects, new identifiers, arrays and descriptors used by array marshalling; the protocol signature selects the member
wl_display, wl_registry, wl_compositor, wl_surface, wl_proxy, wl_callback, wl_event_queueOpaque connection, global discovery, surface, proxy and dispatch objects
wl_seat, wl_pointer, wl_keyboard, wl_touch, wl_output, wl_shm, wl_region, wl_egl_windowOpaque native input/output, shared-memory, region and EGL window types; declarations do not create high-level input or shared-memory wrappers
xdg_wm_base, xdg_surface, xdg_toplevel, xdg_popup, xdg_positionerOpaque xdg-shell objects; the current window wrapper creates the first three
PFN_wl_display_*Connection, descriptor, dispatch, prepare/read/cancel, flush, registry and round-trip function signatures
PFN_wl_proxy_*; PFN_wl_egl_window_*Proxy marshalling/listener/user-data/lifetime signatures and native EGL window create/resize/destroy signatures

Lifetime

Metadata arrays and function pointers are borrowed. Protocol event arguments are valid for the callback's applicable native lifetime and are not retained by the ABI records. wl_argument does not tag or own its active payload. Correct opcode, signature, version and proxy identity remain caller requirements for direct marshalling.
