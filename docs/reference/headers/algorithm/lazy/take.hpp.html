micron::lz::take_view

Defined in header <micron/algorithm/lazy/take.hpp>.

View of at most the first n elements of a source.

Iterator and size

Exact random-access input uses its original iterator and a clamped end. Other inputs use counting_it, stopping at the count or source end. Exact input remains exact; other kinds become bounded with n as an upper bound. The counting cursor avoids advancing upstream after its final requested output. Runtime n removes compile-time extent.

Related types and selection guide.

micron::lz::drop_view

Defined in header <micron/algorithm/lazy/take.hpp>.

View omitting the first n source elements or all elements if the source is shorter.

Effects and complexity

Begin jumps in O(1) for exact random-access sources; otherwise it advances up to n times on every begin call. End forwards the base sentinel. Exact size decreases by the clamped skipped count; other metadata is preserved. No copied element buffer is created.

Related types and selection guide.

micron::lz::take_while_view

Defined in header <micron/algorithm/lazy/take.hpp>.

View of the initial source prefix satisfying a predicate.

Effects and termination

Sentinel comparison tests both source exhaustion and the predicate on the current element. Repeated comparisons can repeat predicate evaluation. No failing element is emitted. Exact input becomes bounded and endless input becomes unknown; termination of an endless source requires eventual predicate failure.

Related types and selection guide.

micron::lz::drop_while_view

Defined in header <micron/algorithm/lazy/take.hpp>.

View omitting the maximal initial prefix satisfying a predicate.

Effects and complexity

Begin performs the prefix scan each time and then returns the base iterator, leaving later elements untested. Exact size becomes bounded; endless input stays endless. An endless all-accepted prefix never produces a first element. No element buffer is used.

Related types and selection guide.

micron::lz::init_view

Defined in header <micron/algorithm/lazy/take.hpp>.

View of every source element except its final element, using one-element lookahead.

Cursor state and lifetime

The cursor copies a current element into its own held value and advances upstream to establish that another element exists. Dereference returns const value_type& into that cursor; increment replaces it. Empty and singleton finite inputs produce no outputs. Exact count is max(n-1,0), and retained state requires default construction and assignment of the element type.
