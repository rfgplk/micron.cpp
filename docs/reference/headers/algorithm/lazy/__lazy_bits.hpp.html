micron::lz::size_kind

Defined in header <micron/algorithm/lazy/__lazy_bits.hpp>.

Enumeration describing the size information available before traversal.

Enumerators

exact=0 denotes a known count; bounded=1 an upper bound; unknown=2 no guaranteed count; endless=3 no intrinsic end. degrade(exact) produces bounded; bound_endless(endless) produces unknown for predicate-limited traversal. These transformations do not themselves examine input.
