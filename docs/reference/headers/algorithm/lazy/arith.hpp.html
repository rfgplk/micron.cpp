micron::lz::zip_arith_view

Defined in header <micron/algorithm/lazy/arith.hpp>.

Pairwise arithmetic view advancing two sources together and stopping when either ends.

Results and constraints

Dereference invokes the stored binary operation and can return a promoted arithmetic type. Scalar division is unchecked; divide_zip_each<A,B> selects a binary callable returning a division-error option per element. Both exact operands yield exact minimum size; other pairs are classified bounded. Two endless operands do not automatically become endless metadata, so establish a finite take bound before complete traversal.
