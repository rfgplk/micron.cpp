Type reference

micron::lz::filter_view

Defined in header <micron/algorithm/lazy/filter.hpp>.

View of elements accepted by a stored predicate, preserving source order.

Effects and complexity

Begin and increment seek the next accepted element; dereference forwards the current base reference. Exact size degrades to an upper bound; no static extent is retained. One full traversal performs O(n) predicate tests with O(1) cursor state. A rejected endless source can make seeking fail to return. reject wraps this view with a negated predicate.
