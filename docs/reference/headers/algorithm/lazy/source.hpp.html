micron::lz::ptr_view

Defined in header <micron/algorithm/lazy/source.hpp>.

Borrowed exact view of a contiguous half-open range of const T elements.

Storage and operations

Stores two pointers, with O(1) construction, begin/end, exact size, and reserve hint. Owns no elements. Its source allocation and live elements must remain valid; source reallocation invalidates the view. Used by of for ordinary contiguous lvalues and as the element type of window/group views.

Related types and selection guide.

micron::lz::ref_view

Defined in header <micron/algorithm/lazy/source.hpp>.

Borrowed view retaining a pointer to an existing range object.

Storage and operations

Begin/end forward to the referenced range. Cheaply sized ranges receive exact size metadata; others remain unknown. Small unrollable fixed containers preserve their static extent. The range object and its iterator storage must outlive use. Const access to the view does not add constness to a mutable referenced range.

Related types and selection guide.

micron::lz::owning_view

Defined in header <micron/algorithm/lazy/source.hpp>.

Move-only view that owns an rvalue container and exposes its const iteration.

Storage and operations

Construction moves C into the view; copying is deleted and move construction is defaulted. Exact/static metadata follows the container's traits. Destruction releases C normally, invalidating borrowed iterators/subviews. Used to retain temporary source containers throughout a named pipeline.

__as_view(R &&__r)

  using B = micron::remove_cvref_t<R>;
  if constexpr ( micron::ranges::view<B> ) {

    if constexpr ( micron::is_lvalue_reference_v<R> )
      return (__r);
    else

  } else if constexpr ( micron::is_lvalue_reference_v<R> ) {

    } else {

    }

  }
