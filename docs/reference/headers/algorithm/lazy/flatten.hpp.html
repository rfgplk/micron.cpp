micron::lz::flatten_view

Defined in header <micron/algorithm/lazy/flatten.hpp>.

View concatenating nested ranges while skipping empty inner ranges.

Ownership and iteration

Lvalue inner ranges are traversed directly. A prvalue inner range is constructed in a single manual-lifetime slot held by the parent view until the next inner range replaces it. Iterators and references into that produced inner range then expire. Concurrent cursors over the by-value case share the slot and are not independent. Work is linear in visited outer ranges and emitted elements, plus inner-range construction; output count is unknown unless the outer range is endless. flat_map composes transformation with this view.

micron::lz::concat_view

Defined in header <micron/algorithm/lazy/flatten.hpp>.

View traversing all of a first range followed by a second range.

Results

Both sources are retained by value as views. Identical source reference types are preserved; differing reference types are converted to the first range's value type. Exact lengths add; either endless operand makes the concatenation endless. The second range is never reached if the first is endless. merge is an alias of this concatenation.
