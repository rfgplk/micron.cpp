micron::fp::division_by_zero_error

Defined in header <micron/algorithm/fperrors.hpp>.

Empty error alternative identifying a checked zero-divisor failure.

Members

what() const noexcept returns a static diagnostic string. The tag owns no dynamic data; it is also re-exported as micron::division_by_zero_error.

Related types and selection guide.

micron::fp::empty_container_error

Defined in header <micron/algorithm/fperrors.hpp>.

Empty error alternative for empty aggregates, missing optional sequence/search results, and selected invalid dimensions.

Members

what() const noexcept returns a static diagnostic string. A nonempty input with no matching element can produce this same tag. It is also re-exported in micron.

Related types and selection guide.

micron::fp::index_out_of_bounds_error

Defined in header <micron/algorithm/fperrors.hpp>.

Empty error alternative returned by checked functional element access when the requested index is outside the sequence.

Members

what() const noexcept returns a static diagnostic string. Indices are unsigned usize values. The tag is also re-exported in micron.

Related types and selection guide.

micron::fp::bad_zip_error

Defined in header <micron/algorithm/fperrors.hpp>.

Empty error alternative for incompatible pairwise sequence sizes or ragged matrix rows.

Members

what() const noexcept returns a static diagnostic string. Used by strict zip/application, checked inner product, and transpose. It is also re-exported in micron.

Related types and selection guide.

micron::fp::traverse_error

Defined in header <micron/algorithm/fperrors.hpp>.

Declared empty traversal-error tag with a static what() diagnostic.

Notes

The traversal implementations propagate the inner option's second_type; they do not automatically translate every failure into this tag. It can be selected as the inner callable's error type and is also re-exported in micron.

Related types and selection guide.
