micron::hashes::xxhash64_stream

Defined in header <micron/hash/xx.hpp>.

Copyable bounded-state incremental XXH64 accumulator with constexpr update and digest operations.

Construction and operations

Construction calls reset(seed), initializing total length, buffered count, and four lane accumulators. update(bytes,n) consumes complete 32-byte stripes and copies fewer than 32 trailing bytes into the internal tail; caller storage can be released after the call. digest() const finalizes a copy of the logical state without consuming or resetting it, allowing more updates afterward. Repeated digest calls with unchanged state return the same value.

Members and complexity

total is the cumulative byte count; seed the selected initial seed; lanes[4] are bulk accumulators; tail[32] stores a partial stripe; buffered is its live byte count. These public fields must retain the invariants established by reset/update. Update is O(n), digest is O(1) because at most 31 tail bytes remain, and storage is constant. stripe is the low-level complete-block operation and does not maintain length/buffer counters on its own. rotate, round, and load are exposed kernels. Copying the state makes an independent checkpoint without retaining input pointers.

micron::hashes::xxhash64_state

Defined in header <micron/hash/xx.hpp>.

Legacy raw XXH64 state record retained alongside the complete xxhash64_stream API.

Fields and limitations

Contains len, four lane words v, four buffered words mem64, memsize, and padding fields. xstate aliases this record. init_seed<seed>() initializes only v; length, buffer size, buffered words, and padding are left uninitialized. No matching public update/digest protocol is implemented for this record. Use xxhash64_stream for incremental hashing rather than treating init_seed as a fully initialized stream.
