Type reference

micron::math::manifolds::lie::SO3

Defined in header <micron/math/manifolds/lie/so3.hpp>.

Owns a vector-first quaternion q for spatial rotations and uses a three-vector Lie-algebra coordinate.

Validity and operations

identity is (0,0,0,1). from_quat copies without normalization; from_quat_normalized and normalized request quaternion normalization. compose uses the Hamilton product, inverse uses conjugation, and between=a^-1*b. These inverse/rotation formulas require a unit quaternion; composition does not automatically renormalize accumulated drift. from_matrix delegates quaternion extraction and does not project an arbitrary matrix onto SO3.

exp_map interprets omega as axis times angle. For theta²<.01 it uses fixed polynomial approximations to sin(theta/2)/theta and cos(theta/2); otherwise it uses sincos. log_map flips a negative scalar quaternion sign, then uses a small-vector rational-polynomial atan expansion or 2*atan2, selecting the unit-quaternion principal rotation branch. Zero/nonunit data can divide by zero or lose the intended angle semantics.

Action, distance, and complexity

rotate/act and inverse_rotate use quaternion cross-product rotation, with compile-time f32/f64 kernels and constant-evaluation fallback. to_matrix/adjoint return a copied 3x3 rotation. squared_distance is the squared norm of log(a^-1*b); distance/angle take its square root. interpolate=a*exp(t*log(a^-1*b)). All scalar-group operations cost O(1), allocate nothing, and leave inputs unchanged. traits report dim=3 and ambient_dim=9, distinct from four-coefficient owned storage.

[[nodiscard, gnu::flatten]] static constexpr SO3
  exp_map(const vec<F, 3> &omega) noexcept
  {
    const F wx = omega.data[0], wy = omega.data[1], wz = omega.data[2];
    const F theta_sq = wx * wx + wy * wy + wz * wz;
    F scalar;
    F c_half;
    if ( theta_sq < __so3_impl::small_angle_threshold_sq<F>() ) {
      scalar = __so3_impl::sinc_half_over_theta<F>(theta_sq);
      c_half = __so3_impl::cos_half<F>(theta_sq);
    } else {
      const F theta = math::fsqrt(theta_sq);
      const F half = theta * F(0.5);
      F s_half;
      math::sincos<F>(half, s_half, c_half);
      scalar = s_half / theta;
    }
    return SO3{ quat<F>{ wx * scalar, wy * scalar, wz * scalar, c_half } };
  }

[[nodiscard, gnu::flatten]] static constexpr vec<F, 3>
  log_map(const SO3 &g) noexcept
  {
    F qx = g.q.data[0], qy = g.q.data[1], qz = g.q.data[2], qw = g.q.data[3];
    if ( qw < F(0) ) {
      qx = -qx;
      qy = -qy;
      qz = -qz;
      qw = -qw;
    }
    const F xyz_sq = qx * qx + qy * qy + qz * qz;
    F k;
    if ( xyz_sq < __so3_impl::small_angle_threshold_sq<F>() ) {
      const F y2 = xyz_sq / (qw * qw);
      F p = F(-1) / F(11);
      p = p * y2 + F(1) / F(9);
      p = p * y2 - F(1) / F(7);
      p = p * y2 + F(1) / F(5);
      p = p * y2 - F(1) / F(3);
      p = p * y2 + F(1);
      k = F(2) * p / qw;
    } else {
      const F xyz_norm = math::fsqrt(xyz_sq);
      const F angle = F(2) * math::atan2<F>(xyz_norm, qw);
      k = angle / xyz_norm;
    }
    return vec<F, 3>{ qx * k, qy * k, qz * k };
  }
