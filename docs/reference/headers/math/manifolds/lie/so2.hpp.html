Type reference

micron::math::manifolds::lie::SO2

Defined in header <micron/math/manifolds/lie/so2.hpp>.

Owns one angle theta for planar rotations, with a scalar Lie-algebra coordinate.

Operations and branch convention

identity returns theta=0, compose adds angles, inverse negates, and between subtracts. exp_map/log_map store/return the angle unchanged. No canonical wrapping is applied, so equivalent rotations can have different stored logs. interpolate linearly blends those stored angles and can take multiple turns; it does not choose the shortest wrapped rotation.

to_matrix and rotate use sincos; from_matrix uses atan2(R[1,0],R[0,0]) without orthogonality validation. act is rotate; inverse_rotate uses the negated angle. adjoint is scalar one. All methods cost O(1), with no allocator or retained pointers. Only the group/action interface is supplied, without inner/norm/distance methods.
