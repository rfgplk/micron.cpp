Type reference

micron::math::manifolds::traits

Defined in header <micron/math/manifolds/tags.hpp>.

Maps a supported manifold policy or Lie-group value to point, tangent, scalar, category, and dimension metadata.

Aliases and categories

The primary traits<M> is declared without a definition; supported policy headers specialize it. point_t<M>, tangent_t<M>, scalar_t<M>, and category_t<M> alias point_type,tangent_type,scalar_type,category respectively. Embedded vector policies report ambient vector width, matrix policies report N*P or N², SO2 reports 1, SO3/SE2 report 9, SE3 reports 16, and generic SOn/SEn report stored matrix element count.

TagCategory
manifold_tagEmpty base marker
euclidean_tagFlat vector policy
lie_group_tagSO2/SO3/SE2/SE3/SOn/SEn specializations
sphere_tag; torus_tag; hyperbolic_tagCorresponding embedded vector geometry
stiefel_tag; grassmann_tag; spd_tagCorresponding embedded matrix geometry

Storage

Tags are empty marker structs derived from manifold_tag, without numeric state or runtime dispatch. Traits do not construct a point, enforce its invariant, or encode ownership of external data.
