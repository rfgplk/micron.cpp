micron::math::integrate::quad_options

Defined in header <micron/math/integrate/quad.hpp>.

Stores adaptive scalar/vector quadrature tolerances, finite resource limits, rule choice, breakpoints, and accumulation policy.

Members and defaults

abs_tol/atol and rel_tol/rtol default to 100*default_eps<F>(). max_evals/max_func_evals=0 means no point budget. max_intervals/limit=128 is clamped to the workspace capacity; zero means its full capacity. max_depth=64. rule defaults to gk21. accumulation defaults to fast.

breakpoints/points borrows n_breakpoints/n_points finite values. They need not be sorted; each starting interval scans the whole array for the next interior point. Duplicates/outside points add no interval. The array must remain readable throughout the call. Infinite-bound transformations discard breakpoints.

Rule choice

gauss_kronrod_rule has gk15=15 and gk21=21, embedded with Gauss 7 and 10 points respectively. The scalar abs_tol/rel_tol overload selects gk15, uses 128 intervals, and caps its max_depth argument at 64; options-based calls retain the specified depth. Negative tolerances, zero depth, a null nonempty breakpoint array, and nonfinite breakpoints are checked. NaN/infinite tolerances are not comprehensively rejected.

micron::math::integrate::quad_result

Defined in header <micron/math/integrate/quad.hpp>.

Stores a scalar adaptive estimate and diagnostics, independently of the workspace that produced it.

Members

value and abs_err are the estimate and estimated absolute error. n_evals counts sampled points, not batch function invocations. status records termination. resabs estimates the integral of abs(f); resasc estimates weighted absolute deviation within rules. n_intervals, n_splits, and n_roundoff count active intervals, performed splits, and the scalar non-improvement heuristic.

Scalar quad supports reversed and infinite bounds using rational half-line or tangent whole-line substitutions. NaN bounds return invalid_input. Initial nonfinite callback failure returns zero accumulated fields and clears the heap; later failure retains the previous accepted mesh. Exhaustion during breakpoint initialization can return only the initialized part of the domain. Inspect status before treating value as a full-domain result.

micron::math::integrate::quad_workspace

Defined in header <micron/math/integrate/quad.hpp>.

Owns Capacity scalar interval records arranged as a maximum-error binary heap.

Storage and algorithm

quad_workspace<F,Capacity> requires Capacity>0 and embeds heap[Capacity], size, and a static capacity. quad_interval<F> contains a,b,value,error,resabs,resasc,depth. reset() changes size to zero without clearing records. Copies are O(Capacity); reset is O(1). A no-workspace quad overload creates Capacity=128 on the stack.

An initial rule uses r=15 or 21 samples. Each accepted split evaluates two new rules, removes the parent contribution, and pushes both children. S splits cost O((B+1+2S)*r) callback points, O(S*log(Capacity)) heap work, and O(B²) worst-case initial breakpoint scanning for B distinct interior points. Scalar callback cost multiplies the sample count. Storage is O(Capacity); it does not grow.

Batch overload

quad_batch with finite bounds sends a complete rule's points to one callback; an infinite-bound call adapts through single-point batch invocations. Its finite dispatch does not reproduce scalar quad's explicit NaN-bound rejection. Reusing the workspace overwrites its mesh. The error estimate has a 50*machine_epsilon*resabs floor; scalar quad also stops after 20 roundoff indications or a large late error-growth heuristic.

micron::math::integrate::quad_vec_workspace

Defined in header <micron/math/integrate/quad.hpp>.

Owns a shared adaptive interval mesh for an M-component integrand, where 2<=M<=16.

Related records

TypeMembers / role
quad_vec_interval<M,F>a,b, vector value/error, scalar priority, depth
quad_vec_result<M,F>vector value/abs_err, n_evals, status, error_norm, n_intervals
quad_error_normmaximum=0 chooses largest absolute component; l2=1 takes Euclidean norm

Complexity and overloads

The vector workspace embeds Capacity interval records, O(Capacity*M) storage/copy, and reset() clears only size. Each rule evaluates f(x) once per point and processes all M components. Splitting uses the norm of interval errors as heap priority; the target uses the norm of accumulated component errors. Work is O(M*r) arithmetic per rule plus callback work and O(M*log(Capacity)) record movement per heap update.

The overload taking scalar quad_workspace instead runs M independent scalar adaptive integrations. It reevaluates the entire returned vector for every component's mesh and sums their evaluation counts; it does not enforce a combined norm tolerance. Shared-mesh quad_vec supports the scalar bound substitutions but does not implement scalar quad's repeated-roundoff/divergence heuristics.
