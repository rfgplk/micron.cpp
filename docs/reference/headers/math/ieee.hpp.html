micron::math::ieee::traits

Defined in header <micron/math/ieee.hpp>.

Format metadata selected by the size of a floating-point type. The ordinary implementations describe four-byte binary32 and eight-byte binary64.

Member types and constants

traits_n<Size> is the size-specific template and traits<F> inherits traits_n<sizeof(F)>. A wasm build additionally includes its binary128 specialization. The ieee754_floating concept itself only tests is_floating_point_v; that test alone does not establish that traits<F> supplies the members an operation needs.

MemberMeaning
uint_typeUnsigned integer representation: u32 for four bytes or u64 for eight bytes.
bits, mant_bits, exp_bits, exp_biasFormat width, explicit fraction width, exponent width, and exponent bias.
sign_mask, exp_mask, mant_maskMasks for the sign, exponent, and explicit fraction fields.
implicit_one, quiet_nan_bitImplicit leading fraction bit and quiet-NaN bit.

Operations and notes

The associated functions extract or construct bit patterns, classify values, compute adjacent representations and ULP distance, and inspect raw sign/exponent/fraction fields. pack masks the supplied fields without validating a numerical exponent range. exponent_of subtracts the bias even for a zero exponent field; it is not a complete decomposition of zero or subnormal values.

Classification of four-byte and eight-byte values uses integer bit tests. Several other floating classifications fall back to compiler built-ins, while representation-based functions require a supported traits specialization. Most non-wasm 16-byte long double representations therefore cannot use the size-based bit API. These functions perform fixed work without allocating storage.

template<ieee754_floating F>
[[nodiscard]] inline constexpr i64
ulp_distance(F a, F b) noexcept
{
  using T = traits<F>;
  using U = typename T::uint_type;
  // WARNING: NaN test must come first; under -ffinite-math-only gcc is told NaN cannot occur, so
  // it is free to compile a == b into an ordered compare that answers true for NaN
  if ( is_nan(a) || is_nan(b) ) return -1;
  if ( a == b ) return 0;
  // monotone total order mapped onto a *biased* unsigned axis
  // full distance must fits in an u64
  auto ord = [](F v) -> U {
    U u = to_bits(v);
    // fold below the zero point (descending magnitude) for negs
    if ( u & T::sign_mask ) return T::sign_mask - (u & ~T::sign_mask);
    return u | T::sign_mask;
  };
  U oa = ord(a);
  U ob = ord(b);
  U d = (oa >= ob) ? U(oa - ob) : U(ob - oa);
  constexpr U i64_max = U(0x7fffffffffffffffULL);
  return i64(d > i64_max ? i64_max : d);
}

[[nodiscard, gnu::always_inline]] inline constexpr F
next_down(F x) noexcept
{
  using T = traits<F>;
  using U = typename T::uint_type;
  if ( is_nan(x) || inf_sign(x) < 0 ) return x;
  U u = to_bits(x);
  if ( u == 0 ) return from_bits<F>(T::sign_mask | U(1));
  if ( u & T::sign_mask ) return from_bits<F>(u + 1);
  return from_bits<F>(u - 1);
}
