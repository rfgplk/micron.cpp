micron::math::graphs::matrix_conversion_result

Defined in header <micron/math/graph/matrix.hpp>.

An owning matrix and descriptor correspondence for a graph-to-matrix conversion.

Conversion inventory

dense_to_vertex maps matrix rows to original vertices; vertex_to_dense maps original slots to row numbers, with the descriptor sentinel for holes. dense_to_edge is populated for incidence columns. Matrix-only to_adjacency_matrix discards these maps.

ConversionImplemented matrix meaning
adjacency_matrixBinary presence; parallel edges collapse
weighted_adjacency_matrixStored weights; the last enumerated parallel edge overwrites earlier values
degree_matrixDiagonal graph.degree; directed degree includes incoming and outgoing
laplacian_matrixD-A from binary adjacency and row sums; parallel multiplicity is discarded and loops cancel on the diagonal
incidence_matrixOne column per live edge; directed -1/+1 gives a zero loop column, undirected +1/+1 gives loop entry two
sparse_adjacency_matrix, sparse_weighted_adjacency_matrix, sparse_adjacency_matrix_cscOne stored entry per enumerated adjacency incidence, retaining parallel entries; undirected loops are recorded once
from_adjacency_matrix, sparse inverse conversionsNonzero entries become edges, using the upper triangle for undirected input; insertion failures are not propagated

Complexity and limits

Dense adjacency/degree/Laplacian output needs O(V²) initialization plus graph scans; incidence needs O(V*E) cells. Sparse output uses O(V+E) storage and traversal work, plus any CSR/CSC conversion. Inverse construction pays target insertion costs. Dense inverse conversion uses the leading min(rows,columns) square. Sparse conversion checks selected shape/offset conditions but silently skips zero/out-of-range columns; a weighted zero edge is lost on inversion.

template<arith_scalar T = i64, graph_model G>
[[nodiscard]] matrix_conversion_result<dynmat<T>, typename G::index_type>
incidence_matrix(const G &graph)
{
  using I = typename G::index_type;
  auto mapping = __dense_vertex_mapping(graph);
  const usize n = graph.vertices_count();
  const usize m = graph.edges_count();
  matrix_conversion_result<dynmat<T>, I> result{
    dynmat<T>(n, m, T(0)), micron::move(mapping.dense_to_vertex), micron::move(mapping.vertex_to_dense), {}
  };
  result.dense_to_edge.reserve(m);
  usize column = 0;
  for ( auto edge : graph.edges() ) {
    const usize u = static_cast<usize>(result.vertex_to_dense.data()[static_cast<usize>(edge.source.value)]);
    const usize v = static_cast<usize>(result.vertex_to_dense.data()[static_cast<usize>(edge.target.value)]);
    if constexpr ( G::is_directed ) {
      result.value.at(u, column) -= T(1);
      result.value.at(v, column) += T(1);
    } else {
      result.value.at(u, column) += T(1);
      result.value.at(v, column) += T(1);
    }
    result.dense_to_edge.push_back(edge.id);
    ++column;
  }
  return result;
}

from_sparse_adjacency_matrix(const sparse::csr<T, I> &matrix)
{
  G result;

  (void)result.add_vertices(n);
  if ( matrix.outer.size() < matrix.rows + 1 || matrix.inner.size() != matrix.values.size() ) return result;
  for ( usize row = 0; row < n; ++row ) {
    usize begin = static_cast<usize>(matrix.outer.data()[row]);
