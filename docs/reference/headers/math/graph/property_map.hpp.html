micron::math::graphs::container_property_map

Defined in header <micron/math/graph/property_map.hpp>.

A borrowed container adapter indexing property values by vertex or edge descriptor slots.

Property-map inventory

container_property_map<Container,I>; property_map<I>(container)Container pointer; operator[] uses id.value without a slot/membership check
pointer_property_map<T,I>T* data and size; unchecked operator[], nullable try_get validating sentinel and size
projection_property_map<Fn>; project_property(fn)Owned decayed callable; indexing invokes it with the key

readable_property_map, writable_property_mapSyntactic [] and assignment concepts; no lifetime or bounds guarantee

Constness, cost, and lifetime

A const map object does not necessarily give const underlying elements: container/pointer maps retain the mutability of their stored pointer. Choose a const Container or const element type for a read-only map. Matrix adapters use the matrix's at contract.

Adapter creation/copy and indexed address calculation cost O(1), excluding callable copying/invocation or backing-container access. Borrowed maps do not retain storage, validate graph membership, or resize after graph growth. The backing container/matrix must outlive each use, and slot-indexed arrays must cover the graph's high-water marks.
