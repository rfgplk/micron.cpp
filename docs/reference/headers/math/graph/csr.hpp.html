micron::math::basic_csr_graph

Defined in header <micron/math/graph/csr.hpp>.

An owning compressed-row graph with fixed topology, densely numbered properties, sorted outgoing arcs, and optional incoming indexes.

Variants and construction

csr_graph selects csr_t; bidirectional_csr_graph selects bidirectional_csr_t and defaults to directed topology. The full class also accepts vertex/edge/graph properties, Index, direction, multiplicity, loop, allocator, and storage policies. Construction from a compatible graph copies live properties, compacts descriptor slots, records mappings, and sorts each row by neighbor then edge ID.

Topology mutation is absent. Mutable property access is still provided through try/unchecked property functions, so frozen means fixed topology rather than deeply immutable properties. Arrays own their storage; copies are independent. Construction writes dense_to_vertex, vertex_remap, and edge_remap into caller-supplied vectors; freeze retains these in its representation_result, rather than in the CSR object.

Complexity and invalidation

Graph storage is O(V+E) properties, arcs, and offsets; caller-held conversion maps add O(S+T). Build work includes old-slot scans and sum(degree*log degree) row sorting. find_edge binary-searches a row in O(log(outdegree+1)); out_degree is O(1). Undirected or bidirectional incoming degree/traversal is indexed. Plain directed CSR incoming enumeration is O(E), including each in_degree query.

Property references and borrowed ranges remain tied to the CSR object until replacement, movement, or destruction. There is no topology growth to reallocate them. Choose bidirectional CSR for reverse searches, SCC, or algorithms repeatedly requesting incoming adjacency.
