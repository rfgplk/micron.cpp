micron::math::graphs::undirected_t

Defined in header <micron/math/graph/tags.hpp>.

An empty compile-time direction policy selecting undirected graph topology.

Policy and concept inventory

The complete policy and capability families are listed in the module policy table. These empty tags carry no graph state, allocation, or runtime switching. Policy concepts recognize the exact supported tag types; graph capability concepts test selected members/flags and do not establish every algorithm precondition.

graph_model does not require all of in_neighbors, degree, property access, pair-endpoint lookup, and allocator/policy aliases. An operation constrained by graph_model can therefore have additional instantiation requirements. Read each algorithm's graph operations when adapting a custom graph.
