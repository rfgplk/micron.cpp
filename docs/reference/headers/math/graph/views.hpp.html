micron::math::graphs::reverse_graph_view

Defined in header <micron/math/graph/views.hpp>.

A non-owning const graph adapter that swaps source/target and incoming/outgoing adjacency.

Operations and lifetime

reverse(graph) and transpose(graph) return the same view type. The adapter stores a const G pointer, preserves numeric descriptor slots, delegates vertex/property access, and reverses edge proxy endpoints. Undirected orientation is also swapped, without changing undirected connectivity.

The nested edge_reference, edge_iterator, and edge_range adapt edge enumeration; all other delegated ranges retain the underlying graph. No topology or property copy occurs. Creating/copying the view is O(1); each operation adds O(1) adaptation to the underlying query. A range whose iterator stores the view pointer must not outlive the view object itself. The underlying graph's invalidation rules continue to apply.

micron::math::graphs::filtered_graph_view

Defined in header <micron/math/graph/views.hpp>.

A borrowed const graph and owned predicates selecting visible vertices and edges without renumbering descriptors.

Selection and traversal

filtered(graph,vpred,epred) owns decayed predicate values; induced_subgraph(graph,vpred) supplies accept_all as the edge predicate. An edge is visible only if its predicate and both endpoint predicates accept. Predicates are invoked as predicate(graph,id) when supported, otherwise predicate(id). accept_all is a stateless always-true callable.

vertex_slots/edge_slots retain the underlying high-water marks. Live counts, degrees, vertices, and edges are recomputed by scanning and testing; predicates are not memoized. const members can call mutable predicates through const_cast, so state changes can affect repeated queries.

Public vertex_range, edge_range, incident_range, and neighbor_range filter borrowed traversal. Their returned iterator classes are private implementation types. The incident implementation uses the outgoing iterator type for incoming ranges as well; graph types with differing in/out iterator types, notably directed plain CSR, may fail to instantiate those incoming operations. There is no pair-endpoint has_edge overload on this adapter.

Complexity and invalidation

Creation stores predicates and a pointer, without topology allocation. Filtering scans the underlying range and adds predicate costs for tested entries and endpoints. A rejected dense graph can still require a full square edge scan. The graph and view must outlive their iterators; topology/property invalidation follows the backing graph. Choose a materialized conversion when stable membership, independent lifetime, or unrestricted graph APIs are required.

micron::math::matrix_graph_view

Defined in header <micron/math/graph/views.hpp>.

A non-owning graph interpretation of the nonzero entries in a matrix's leading square submatrix.

Representation and semantics

The view stores const Matrix* and snapshots N=min(rows,columns). Direction defaults to directed_t; Index defaults to u32. All N vertices exist; a nonzero entry is an edge and its matrix value is the const edge property. Vertex/graph properties are empty markers. Edge IDs use row*N+column and edge_slots is N².

An undirected view enumerates only the upper triangle but row/column queries still read actual matrix entries. A symmetric matrix is therefore required for a coherent undirected interpretation. A zero-weight edge cannot be distinguished from absence. Unlike owning undirected graphs, loop degree is counted once by the view's scans. Index multiplication/representability is not explicitly guarded.

Public vertex_range, edge_reference/edge_range, neighbor_range, and incident_range borrow the view and matrix. Their returned iterator classes are private implementation types. as_graph_view creates the adapter.

Complexity and invalidation

Construction and pair lookup are O(1), edge count/enumeration O(N²), and degrees/neighborhoods O(N). Storage is O(1) beyond the matrix. Matrix replacement/destruction invalidates access; resizing also makes the cached dimension stale. Neither graph nor matrix storage is owned or copied.
