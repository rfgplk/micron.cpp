micron::math::graphs::min_cost_flow_result

Defined in header <micron/math/graph/min_cost_flow.hpp>.

An owned achieved flow, total cost, per-edge flow, per-vertex incoming/outgoing totals, and feasibility status.

Requirements and operations

Capacities are integral and nonnegative; costs are signed arithmetic and finite. capacity_cost_property provides the default .capacity and .cost fields. Explicit capacity/cost maps follow the ordinary weight-map dispatch. Graphs must be directed, and source/sink operations require distinct live endpoints. Capacity, cost negation, flow totals, and final flow-times-cost arithmetic have explicit overflow checks.

FunctionRequested problem and output
min_cost_flowAchieve the requested nonnegative integral flow, then minimize cost; insufficient capacity returns infeasible, without completed flow arrays
min_cost_max_flowMaximize source-to-sink flow, then minimize its cost
min_cost_circulationSigned supply array covering S slots; positive supply is net outflow and negative supply net inflow. Auxiliary source/sink enforce feasibility
verify_min_cost_flowReconstruct capacities/residuals, check balances/total cost, and reject a residual negative cycle; source/sink verification certifies the supplied flow value, not maximum possible value

Implementation and workspace

min_cost_flow_workspace<I,Capacity,Cost> owns residual rows, original capacities/costs, locations, levels/cursors, queue, potentials, shortest-search parents/flags, and binary heaps. Public arc_type and arc_vector name min_cost_residual_arc and its vector. edge_location contains source and arc offset. min_cost_residual_arc contains target, reverse, capacity, cost, original edge ID, forward, and auxiliary flags. Unlike the standalone max-flow construction, reverse indices account for self-loops.

The solver first attempts potential-based reduced-cost augmenting paths. If that path is inapplicable, Dinic obtains the required feasible flow; repeated Bellman-Ford negative-cycle cancellation then improves the full residual circulation. Disconnected negative-cost cycles can therefore alter flow and total cost even outside a source-to-sink path.

Circulation construction visits live vertices; nonzero supply entries for dead slots are not used in construction, while the circulation verifier rejects them. Supply arrays should therefore use zero for holes. feasible() means status==ok. Failure records can contain partial scalar progress, so inspect status before consuming arrays.

Complexity and lifetime

Let A be the number of shortest-path augmentations and K the number of canceled cycles. Potential/cycle searches use up to O(V*E) relaxation work per search; heap augmentation adds O((V+E)*log(V+E+1)) per augmentation, plus any feasibility-flow work. Cycle cancellation is value/cost dependent; no strongly polynomial bound is supplied by this implementation.

Residual/search storage is O(S+T+E), and results use O(S+T). reserve reuses outer buffers, but residual.clear/resize rebuilds nested arc vectors, and returned arrays allocate independently. Reuse of a workspace is not an allocation-free guarantee. Results own numeric arrays tied to original descriptor slots.
