Requirements

arb_solver accepts exactly the seven named solver tags. These empty types store no runtime engine state. Pinning a higher-level type does not force every recursively smaller operation into the same algorithm. Scratch must be sized for the actual named dispatch; ordinary and forced-tier _itch values are not interchangeable.
