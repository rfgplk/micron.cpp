micron::math::geometry::scaling

Defined in header <micron/math/geometry/scaling.hpp>.

Owns one factor per coordinate for axis scaling in 2 through 16 dimensions.

Operations and requirements

s is an embedded vec<F,Dim>. uniform(k) fills every factor, apply(p) multiplies coordinates, and composition multiplies corresponding factors. inverse takes 1/s[i] without checking zero or finiteness; all factors must be nonzero for an invertible scale. Negative factors are accepted and can reflect coordinates. Operations/copies cost O(Dim), with no allocator or retained pointers. from_scaling expands the value into a homogeneous transform but does not change the selected transform mode.
