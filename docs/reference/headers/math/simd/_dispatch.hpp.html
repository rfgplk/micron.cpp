micron::math::mk::elem_of

Defined in header <micron/math/simd/_dispatch.hpp>.

Type trait mapping each admitted native real register type to its coefficient type through member type.

Mapping and alias

f128/f256/f512 map to f32, and d128/d256/d512 map to f64, under the corresponding architecture/feature gates. elem_t<V> aliases elem_of<V>::type. The unspecialized native primary template has no member type; it does not infer arbitrary vector-size or user packet element types. WebAssembly defines the corresponding constrained trait from its packet-traits element type.

Accepted register concept

packed_real classifies the raw register types listed in the availability section. It does not classify v128/v256/v512 wrappers or guarantee a complete mathematical overload set for every classified width. Scalar accuracy-policy classes are independent types described by the scalar math reference.

micron::math::mk::lanes_of

Defined in header <micron/math/simd/_dispatch.hpp>.

Trait reporting a supported register's floating coefficient count as static member value.

Values

Registerlanes_of::value
f128, d1284, 2
f256, d2568, 4
f512, d51216, 8

Availability

lanes_v<V> is the variable-template shorthand. Native specializations share their register feature gates and the primary template has no value member. WebAssembly computes sizeof(V)/sizeof(elem_t<V>) for its real packet/composite types. This is a logical coefficient count, independent of how many machine instructions implement an operation.
