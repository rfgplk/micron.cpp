micron::math::splines::build_info

Defined in header <micron/math/splines/tags.hpp>.

Stores factory status, iteration count, and a builder-specific residual diagnostic.

Status inventory

build_statusMeaning
ok=0The builder's checks/solve completed
too_few_points=1Fewer points/controls than that factory requires
non_monotonic_x=2Sample coordinates fail strict increase, or knots descend
size_mismatch=3Input lengths disagree
degenerate=4Spacing, periodic closure, or refinement multiplicity is unsuitable
singular_system=5A checked factorization/solve failed
max_iter=6Adaptive-knot selection reached its knot budget above target error
invalid_argument=7A checked degree, shape, policy parameter, or bound is unsuitable

Diagnostic conventions

Defaults are status=ok,n_iterations=0,residual=0. Most simple factories write only status; reusing info does not reset the other fields. Fixed-lambda smoothing stores an unweighted squared residual sum; automatically selected smoothing stores the chosen lambda in residual instead. Adaptive knots stores the largest error at an input sample and its number of rebuilds. The default ok value alone does not establish that construction has been attempted.

micron::math::splines::bc_kind

Defined in header <micron/math/splines/tags.hpp>.

Selects natural, endpoint-slope, or not-a-knot boundary equations for cubic interpolation.

Policies

natural=0 uses zero endpoint second derivatives. clamped=1 uses supplied left/right first derivatives. not_a_knot=2 matches third derivatives across the first/last interior joins. Two points produce a line for every policy, ignoring supplied slopes; three-point not-a-knot produces the unique quadratic. Boundary metadata does not identify every builder's construction: slope-based Hermite/PCHIP/Akima/cardinal builders store bc=clamped.

micron::math::splines::extrap

Defined in header <micron/math/splines/tags.hpp>.

Selects the original nearest, linear, cubic, and polynomial-curve endpoint behavior.

Values

clamp_to_endpoints=0 holds an endpoint value; linear_continue=1 uses endpoint tangent lines for linear/cubic families; error_value=2 returns zero rather than throwing or returning NaN. These evaluators test x<=first and x>=last, so error_value also returns zero at the exact endpoints. Nearest interpolation holds endpoint samples for both clamp and linear_continue.
