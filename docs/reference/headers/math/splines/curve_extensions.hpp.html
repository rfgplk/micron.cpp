micron::math::splines::bspline_curve_nd

Defined in header <micron/math/splines/curve_extensions.hpp>.

Owns knot/control vectors and cached knot-denominator reciprocals for a vector B-spline path.

Layout and operations

D=2..16, degree=1..16, n_ctrl>=degree+1, knot_count=n_ctrl+degree+1, and a positive active domain are required by factories. Controls and knots are copied; __basis_inverse stores (n_ctrl-p)*p*(p+1)/2 reciprocals. mode defaults to clamp. Construction/cache generation is O(n*(D+p²)) time/storage. Evaluation uses p+1 local basis values, O(p²+p*D+log n) work and automatic fixed-capacity scratch.

Factories support explicit controls, interpolation, weighted least squares, and closed uniform paths. Interpolation factors a single p-band matrix and applies it across coordinates; least squares shares Givens/normal factors and vector right-hand sides. Closed construction repeats the first p controls and selects periodic extension; it is distinct from merely choosing periodic_uniform knots.

derivative evaluates basis derivatives directly; derivative_spline allocates reduced knots/controls and a rebuilt cache. As for scalar B-splines, a degree-1 derivative_spline result has degree 0 and evaluate returns a zero vector. Direct derivative(s,t,1) does not share that representation limitation. Extension modes handle endpoint tangents, reflection derivative signs, periodic mapping, zeros, or polynomial basis continuation.

micron::math::splines::nurbs_curve_nd

Defined in header <micron/math/splines/curve_extensions.hpp>.

Owns positive rational weights alongside the vector B-spline representation and basis cache.

Rational evaluation

make_nurbs_curve validates weight count/positivity and copies controls, knots, and weights. make_closed_nurbs_curve repeats the first p controls/weights with a uniform extended knot sequence. Evaluation contracts local weighted controls and divides by the local weight sum; if that sum is zero the value path leaves the numerator unnormalized rather than reporting an error. Derivative evaluation uses weighted basis derivatives and a binomial quotient recurrence, returning zero for a zero denominator.

Derivative orders above degree return zero in this implementation, although a rational curve can have nonzero derivatives above its polynomial numerator degree. For requested order r<=p, work includes O(p²*(r+1)) basis derivative work and O(D*(p*r+r³)) quotient/binomial work, plus search. Ordinary values cost O(p²+p*D+log n). Rational data can lose denominator positivity under polynomial extension; finite valid in-domain data remain the intended case.

micron::math::splines::bezier_curve_nd

Defined in header <micron/math/splines/curve_extensions.hpp>.

Owns 2 through 17 vector control points for a single Bezier segment on [0,1].

Polynomial and rational variants

bezier_curve_nd stores ctrl and extension mode; rational_bezier_curve_nd additionally owns one positive weight per control. Their factories copy arrays, reject incompatible counts, and default to clamp. De Casteljau interpolation uses automatic scratch for 17 vector controls; the rational form interpolates homogeneous weighted controls and weights. Evaluation is O(p²*D) with O(p*D) scratch, for degree p=n_ctrl-1.

Supported extension modes include endpoint clamping, zero, tangent-line continuation, parameter reflection/wrapping, and evaluating the interpolation polynomial/rational expression outside [0,1]. Rational zero final weight leaves the homogeneous numerator unnormalized. These types have value evaluation only in the reviewed surface; curve derivative/length helpers target cubic_curve_nd. There is no retained lookup cache, so immutable value evaluation does not mutate the representation.

micron::math::splines::closed_cubic_curve_nd

Defined in header <micron/math/splines/curve_extensions.hpp>.

Owns a cubic vector path built with periodic second-derivative equations and a repeated endpoint sample.

Construction and evaluation

make_closed_cubic_curve requires n>=4, matching strictly increasing parameter samples, and a first/last point match in each coordinate within a scaled 1e-5/1e-12 tolerance. It factors the cyclic scalar system once, solves vector right-hand sides, applies the rank-one correction, and builds O(n*D) coefficients/storage. Checked pivots can report singular_system.

The wrapper owns cubic_curve_nd curve and period metadata. evaluate wraps using curve.ts endpoints and supports an external cursor; period alone is not the mapping source. There is no direct closed-wrapper derivative overload, but the embedded curve remains accessible. A closed builder establishes periodic coefficient conditions; wrapping an arbitrary open cubic does not.

micron::math::splines::packed_cubic_curve_nd

Defined in header <micron/math/splines/curve_extensions.hpp>.

Owns an irregular cubic vector path with coefficient coordinates packed contiguously rather than in aligned vector segment records.

Layout and selection

ts owns n knots; coeff holds (n-1)*4*D scalars. Segment i has contiguous a[D],b[D],c[D],d[D] blocks at i*4*D. pack copies a cubic_curve_nd in O(n*D) and carries its extrap mode. make_packed_cubic_curve first builds the ordinary representation and then packs, so construction temporarily holds both.

Evaluation uses the same cached/binary segment lookup and O(D) Horner arithmetic with architecture-selected coordinate kernels; an external cursor overload is supplied. Packed storage avoids the per-vector alignment padding present in curve_seg, without changing polynomial degree or establishing a benchmark advantage. There are no packed derivative/arc-length overloads.
