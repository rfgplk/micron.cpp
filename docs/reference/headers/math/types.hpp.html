i192

Defined in header <micron/math/types.hpp>.

A global alias of micron::math::arbint<192>, with a 192-bit magnitude budget and a separate sign.

Extended-width aliases

<micron/math/types.hpp> defines these names in the global namespace, matching the placement of the project's basic aliases. Each uses the automatic multiplication solver and default allocator parameter; bounded storage itself is embedded. No additional arithmetic, saturation, overflow checking, or ABI wrapper is introduced.

Size and lifetime

The signed and unsigned aliases have their class's count, padding, and alignment in addition to limbs. sizeof(iN) need not equal N/8, and the signed representable magnitude is not reduced by a sign bit. Copying/moving has bounded-store costs and existing limb pointers continue to refer to the original object's embedded storage.
