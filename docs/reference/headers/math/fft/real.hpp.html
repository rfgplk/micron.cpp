micron::math::fft::r2r_plan

Defined in header <micron/math/fft/real.hpp>.

An owning separable real-to-real cosine/sine transform plan with an FFT embedding per selected axis.

Kinds and inverse pairs

r2r_kind enumerates dct_i, dct_ii, dct_iii, dct_iv, dst_i, dst_ii, dst_iii, dst_iv. A one-dimensional constructor accepts n and one kind; the descriptor constructor requires one kind per selected axis and kind==domain::complex in the descriptor. Lengths must be positive, and DCT-I requires n>=2.

Backward direction exchanges DCT-II with III and DST-II with III; kinds I and IV are self-paired. Each engine embeds reflected/antisymmetric or phased samples in a complex transform. Logical normalization lengths are 2*(n-1) for DCT-I, 2*(n+1) for DST-I, and 2*n otherwise. Type-IV embeddings use 8*n complex points. Ortho additionally adjusts endpoint coefficients according to the kind.

execute accepts F input/output and workspace_view and returns logical output bytes or the common negative statuses. The one-shot real_transform/dct/dst wrappers allocate plans, scratch, and outputs; dct/dst type arguments must be 1..4.

Complexity and storage

Each axis costs its embedding engine's O(m log m) line transform work plus embedding/gather/scatter. Plan state owns phase arrays and FFT coefficients. Scratch includes batch-volume complex staging, two maximum-length line spans, and the largest embedded engine workspace per worker. size() counts all logical real elements. Plan and scratch lifetimes follow the complex-plan family.
