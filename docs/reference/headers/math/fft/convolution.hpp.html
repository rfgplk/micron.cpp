micron::math::fft::convolution_plan

Defined in header <micron/math/fft/convolution.hpp>.

An owning fixed-kernel convolution/correlation plan with a precomputed kernel spectrum.

Descriptor and modes

convolution_descriptor owns input_shape, kernel_shape, optional period, mode=full, and correlation=false. Input/kernel ranks must agree and be nonempty. I/O is contiguous row-major. A nonempty kernel pointer is consumed during construction, copied into padded transform storage, and not retained.

convolution_modeOutput/crop per axis
fulln+m-1 samples, uncropped
samen samples beginning at floor((m-1)/2) of the full result
validn-m+1 samples beginning at m-1; requires n>=m on every nonempty axis
circularThe explicitly supplied positive period per axis; input and kernel dimensions must not exceed it

Implementation and errors

Linear modes pad each axis to next_fast_len(n+m-1). Linear correlation reverses/conjugates the kernel before transforming; circular correlation conjugates its spectrum. The short convolve/correlate length overload does not supply circular periods, so circular use requires the full descriptor.

A zero input/kernel dimension creates an empty plan/result, subject to remaining mode/period validation; execute then returns zero without dereferencing pointers. Otherwise execute embeds input, performs forward transform, pointwise multiplication, inverse transform, and crop. It returns output bytes, -22 for null sample pointers, or -105 for workspace failure. output_shape/output_size describe the cropped result.

Complexity and lifetime

Let P be padded transform volume. Planning computes one kernel transform; each execution computes two transforms plus O(P) multiplication/embedding and output cropping. Smooth multidimensional transform work is O(P*sum(log padded_axis)), with Bluestein costs where required. Plan storage includes O(P) kernel spectrum and FFT coefficients; scratch is two P-element arrays plus the FFT workspace.

The fixed kernel spectrum belongs to the plan and can be reused after the original kernel storage changes. Copies own independent coefficients. Distinct execution workspaces permit concurrent reuse of one const plan. convolve/correlate wrappers rebuild this state on each call.

        empty = true;
        break;
      }
    if ( empty ) {
      for ( usize a = 0; a < rank; ++a ) {
        usize n = d.input_shape[a], m = d.kernel_shape[a];
        if ( d.mode == convolution_mode::circular ) {
          usize p = d.period[a];
          if ( !p || n > p || m > p ) exc<except::invalid_argument>("fft: inputs exceed circular period");
        } else if ( d.mode == convolution_mode::valid && n && m && n < m )
          exc<except::invalid_argument>("fft: valid convolution requires input >= kernel");

        output[a] = 0;
      }
      input_size = kernel_size = output_size = 0;
      return;
    }
    for ( usize a = 0; a < rank; ++a ) {
      usize n = d.input_shape[a], m = d.kernel_shape[a];
      input_size = __mul(input_size, n);
      kernel_size = __mul(kernel_size, m);
      if ( d.mode == convolution_mode::circular ) {
        usize p = d.period[a];
        if ( !p || n > p || m > p ) exc<except::invalid_argument>("fft: inputs exceed circular period");
        shape[a] = output[a] = p;
      } else {
        usize full = n && m ? __add(n, m) - 1 : 0;
        shape[a] = next_fast_len(full);
        switch ( d.mode ) {
        case convolution_mode::full:
          output[a] = full;
          break;
        case convolution_mode::same:
          output[a] = n;
          crop[a] = m ? (m - 1) / 2 : 0;
          break;

          if ( n && m && n < m ) exc<except::invalid_argument>("fft: valid convolution requires input >= kernel");

          crop[a] = m ? m - 1 : 0;
          break;
        default:
          break;
        }
      }
      volume = __mul(volume, shape[a]);
      output_size = __mul(output_size, output[a]);

template<typename Input, typename Output, typename Runner>
  max_t
  __execute(const Input *input, Output *output, workspace_view<F> work, Runner &runner) const noexcept
  {
    if ( __geometry.empty ) return 0;
    if ( !input || !output ) return -22;
    usize base = 3 * __geometry.volume, per_worker = __fft.workspace_size() - __geometry.volume;
    if ( !runner.workers || runner.workers > (__impl::__limit - base) / per_worker || !work.data
         || work.size < base + runner.workers * per_worker )
      return -105;
    usize n = __geometry.volume;
    auto *time = work.data, *freq = time + n;
    workspace_view<F> scratch{ freq + n, work.size - 2 * n };
    for ( usize k = 0; k < n; ++k ) time[k] = {};
    for ( usize k = 0; k < __geometry.input_size; ++k )
      time[__impl::__embed_index(k, __desc.input_shape, __geometry.shape)] = complex<F>{ input[k] };
    __fft.__execute([&](ssize_t i) { return time[i]; }, [&](ssize_t i, complex<F> z) { freq[i] = z; }, scratch, direction::forward, runner);
    __impl::__multiply(freq, __kernel.data(), n);
    __fft.__execute([&](ssize_t i) { return freq[i]; }, [&](ssize_t i, complex<F> z) { time[i] = z; }, scratch, direction::backward,
                    runner);
    for ( usize k = 0; k < __geometry.output_size; ++k ) {
      usize index = k, source = 0, step = 1;
      for ( usize a = __geometry.output.size(); a-- > 0; ) {
        source += (index % __geometry.output[a] + __geometry.crop[a]) * step;
        index /= __geometry.output[a];
        step *= __geometry.shape[a];

        output[k] = time[source].real;
      else
        output[k] = time[source];
    }
    return max_t(__geometry.output_size * sizeof(Output));
  }
