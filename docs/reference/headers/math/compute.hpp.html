micron::math::compute::compute_status

Defined in header <micron/math/compute.hpp>.

Status enumeration for registry, binding, allocation/domain, scheduling and kernel failures.

Values

ok indicates success. invalid_plan, invalid_tensor, invalid_binding, incompatible_binding and missing_binding describe setup/use failures; allocation_failure and domain_failure describe storage/provider failure; dependency_failed, executor_failure and kernel_failure describe execution; overflow is available to registries/providers. Not every enumerator is emitted directly by this implementation: graph validation usually diagnoses through invalid_argument, and session allocation failure diagnoses through memory_error.

Defined in header <micron/math/compute.hpp>.

Execution result containing status and the failing operation identifier.

Access

Defaults to ok with an invalid failing_operation. succeeded() and explicit bool are true exactly for ok. Failure before a specific operation has an invalid identifier; scheduled direct failures identify the lowest failing index after all work finishes. The result owns no tensor data and does not imply rollback.

micron::math::compute::tensor_descriptor

Defined in header <micron/math/compute.hpp>.

Owned descriptor containing dtype, u16 domain, dimensions, signed byte strides, byte extent, alignment and access metadata.

Storage and operations

dimensions and strides are unchecked serial-allocator vectors; rank returns dimensions.size and scalar tests empty dimensions. Copying copies these vectors. Normalization computes missing contiguous strides and the addressed extent, checking arithmetic overflow. A descriptor does not allocate its tensor payload or validate addresses. tensor_access values read_only/read_write describe intended kernel access.

Defined in header <micron/math/compute.hpp>.

Borrowed void pointer plus descriptor pointer and access metadata supplied to registry kernels.

Access and lifetime

as<T>() reinterprets storage without checking dtype, alignment, rank or access. Const as returns const T*, while the mutable overload returns T*. Explicit bool accepts a nonnull pointer or a descriptor with zero byte extent. Session input/output view arrays and plan descriptors must remain alive; copying the view neither retains storage nor copies metadata/payload.

micron::math::compute::host_domains

Defined in header <micron/math/compute.hpp>.

Default domain provider implementing domain zero as aligned host memory.

Provider contract

domain_type is u16 and host is zero. valid accepts only zero; minimum_alignment returns alignof(max_align_t). allocate rounds bytes to alignment and rejects invalid/non-power-of-two/overflow requests; release frees through the matching aligned allocation seam. copy uses byte memcpy and reports invalid domain/null ranges; synchronize is an immediate success. domain_provider requires equivalent static validity/alignment/allocate/release/copy/synchronize expressions, but custom providers define their own actual domain behavior.

micron::math::compute::basic_tensor_storage

Defined in header <micron/math/compute.hpp>.

Shared byte-allocation owner with atomic reference counting, parametrized by a domain provider.

Ownership and complexity

A separately allocated control block stores pointer, bytes, alignment, domain and atomic count. Copies retain in O(1), moves transfer, and the last release invokes Domains::release then deletes the control block. allocate returns an empty owner when payload allocation fails, but control-block allocation can diagnose/throw; a zero-byte request still allocates a control block. data/size/alignment/domain/use_count inspect that owner. Atomic lifetime management does not synchronize mutable payload access. tensor_storage aliases basic_tensor_storage<host_domains>; domain_type aliases the provider's type.

micron::math::compute::compute_graph

Defined in header <micron/math/compute.hpp>.

Move-only graph builder parametrized by a statically dispatched operation registry and domain provider.

Members

add_input and add_state append descriptors; state must be read-write. add_operation/add/add_one append operations and return output tensor IDs, with add_one diagnosing a non-single result. set_descriptor changes a builder tensor; retain reserves its output root against temporary reuse. finalize performs inference, descriptor/alias validation, dependency construction and slot planning, moving operation values into its returned plan. Existing session execution is not affected by later independent builder edits because it consumes the plan, not this builder.

Registry requirements

operation_registry checks the named registry types/functions, including noexcept execute. The registry may additionally define aliases(operation,input_descriptors,output_descriptors,declarations). Registry inference/validation work and operation copy/move behavior are part of construction cost and failure behavior.

Member aliases

operation_type and dtype_type are selected from Ops; descriptor_type is tensor_descriptor<dtype_type>, and plan_type is compute_plan<Ops,Domains>. They expose the statically selected operation/metadata/plan types without runtime type erasure.

micron::math::compute::compute_plan

Defined in header <micron/math/compute.hpp>.

Move-only finalized tensor/operation/dependency metadata and arena-slot layout.

Inspection and lifetime

tensors_count, operations_count, slots_count and peak_bytes inspect metadata. descriptor(id) returns a borrowed normalized descriptor pointer or nullptr; retained/persistent return false for invalid IDs. registry_type, domains_type and descriptor_type identify the selected policies/metadata. micron::math::compute::compute_session

Defined in header <micron/math/compute.hpp>.

Nonmovable, noncopyable execution instance retaining a borrowed plan and its own registry context, storage slots and scheduling arrays.

Members and use

Construct from a plan and default/copied/moved context. Bind borrowed or shared inputs; initialize writable state through copy_from or typed data access; execute with an immediate or caller executor; inspect/export retained outputs. reset/hard_reset control validity and reuse without rebuilding the plan. Members return status values for ordinary binding/execution errors; construction/planning still use diagnostics for invalid setup or allocation. plan_type, operation_type, dtype_type, context_type, descriptor_type, storage_type and shared_tensor_type identify its policy-selected types.
