micron::math::quaternions::rotations

Defined in header <micron/math/quaternions/euler.hpp>.

An unsigned-byte axis tag for compile-time or runtime single-axis rotation.

Enumerators and operations

roll=0 selects X, pitch=1 selects Y, and yaw=2 selects Z. alpha, beta, and gamma alias roll, pitch, and yaw respectively; they are axis names, not extra independent axes. axis_quat<Axis> creates a rotation, rotate<Axis,Frame> updates a quaternion, rotated returns a copy, and rotate_axis<Axis> rotates a three-vector directly. Runtime rotate takes rotations and frame arguments.

A single-axis update computes one half-angle sincos and uses a specialized Hamilton multiplication. Ordinary updates preserve the input's norm only to arithmetic accuracy. rotate_safe/rotated_safe additionally divide by the computed norm; their internal near-unit renormalization has no degenerate/non-finite guard, despite the safe suffix. Caller inputs must meet that near-unit assumption. Each operation costs O(1) and allocates nothing.

micron::math::quaternions::frame

Defined in header <micron/math/quaternions/euler.hpp>.

An unsigned-byte tag selecting postmultiplication or premultiplication for a single-axis update.

Enumerators

body=0 selects intrinsic/body-axis q'=q*dq. world=1 selects extrinsic/world-axis q'=dq*q. Body is the default for templated and runtime rotate. These choices affect composition order; a single axis tag always identifies the corresponding X/Y/Z physical axis. The tag is stored by value and carries no state or allocation.

micron::math::quaternions::euler_order

Defined in header <micron/math/quaternions/euler.hpp>.

An unsigned-byte compile-time selection of twelve intrinsic three-angle rotation sequences.

Sequence inventory

Angles a,b,c follow the axes in the selected sequence. The first six sequences use three distinct axes; the final six repeat the first axis. Closed formulas construct the corresponding ordered quaternion or row-major rotation matrix.

FamilyEnumerators
Tait-BryanXYZ=0, XZY=1, YXZ=2, YZX=3, ZXY=4, ZYX=5
Proper EulerXYX=6, XZX=7, YXY=8, YZY=9, ZXZ=10, ZYZ=11

Conversions and singularities

from_euler accepts three angles or vector_3 and returns quaternion. from_euler_matrix returns mat<T,3,3>; from_euler_matrix4 embeds that rotation in a homogeneous 4x4 identity with no translation. to_euler_matrix extracts vector_3 from a 3x3 matrix; to_euler expands its input quaternion into matrix coefficients first and assumes unit length.

Extraction clamps the selected sine/cosine to [-1,1]. When its magnitude reaches 1-default_eps, the gimbal branch sets the third angle to zero and obtains the merged first angle by atan2. Other branches return the usual atan2 first/third angles, with middle angle from asin for Tait-Bryan or acos for proper Euler. The representation is nonunique at singularities; no separate gimbal-status flag is returned. Matrices are not checked for orthogonality.

orientate/orientate3/orientate4 default to YXZ and return quaternion/3x3/4x4 values. from_euler_zyx takes yaw,pitch,roll; to_euler_zyx returns the same order. All conversions use closed fixed formulas, O(1) time/local storage, and no iterative solver or allocation.
