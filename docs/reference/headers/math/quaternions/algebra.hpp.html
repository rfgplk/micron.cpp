micron::math::quaternions::quaternion

Defined in header <micron/math/quaternions/algebra.hpp>.

An owning x,y,z,w floating quaternion used by Hamilton algebra and rotation functions.

Construction and algebra

T satisfies ieee754_floating. Four public named components are aligned by vec_align_v<T,4>. Default construction yields all zeros; identity, pure(vector), scalar(real), and nan are explicit factories. dot, squared_norm, magnitude, all_finite, normalized, and is_normalized are members. Copy/move copy the four values without allocation or lifetime retention.

multiply and compose implement the Hamilton product, conjugate negates x,y,z, inverse divides the conjugate by squared norm, and inverse_unit returns the conjugate under a unit-input precondition. normalize is the returning free-function equivalent of normalized. The class does not declare componentwise or Hamilton operator*; select the named function. Runtime multiply has selected AVX2/FMA paths; constant evaluation and unsupported targets use scalar formulas.

Invalid inputs and precision

normalized/inverse reject non-finite components and squared norm at most the smallest positive normal T, returning four quiet NaNs. is_normalized checks finiteness and |squared_norm-1|<=eps, with default_eps by default. Component squares are summed directly without scaling. Finite components whose squared norm overflows can therefore normalize/invert to zero components rather than a unit/inverse value.

All scalar operations use O(1) time and local storage, in addition to square-root cost. No convergence state, allocation, or synchronization is present. Public component references remain associated with their object through assignment; destruction invalidates them. Use this type when the dedicated quaternion conventions and geometric free functions are required.

Rotation conversion and application

from_axis_angle scales the input axis by its maximum magnitude before normalizing it; a zero axis yields identity. from_unit_vectors assumes unit directions, whereas from_two_vectors normalizes arbitrary nonzero directions and returns identity for a zero direction. Near-opposite directions select a perpendicular half-turn axis. from_matrix uses trace/largest-diagonal formulas and normalizes the result, returning identity if its computed squared norm is unusable; it does not validate orthogonality or determinant.

to_matrix requires a unit input because it writes the usual unit-quaternion matrix without normalization. rotate(q,v) compensates for a nonunit quaternion by dividing by its squared norm; a zero quaternion returns v unchanged. Non-finite values have no separate status check. Axis constructors x_quat/y_quat/z_quat and quat_x/quat_y/quat_z return half-angle sine/cosine unit-axis quaternions. All fixed conversions and rotations cost O(1).
