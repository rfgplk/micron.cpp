Type reference

micron::math::linalg::decomp::householder_sequence

Defined in header <micron/math/linalg/householder_seq.hpp>.

Compact fixed sequence of K=min(R,C) real reflectors stored as V[R,K] and betas[K].

Operations and dynamic form

R>=2 is required. apply_left/right and their transposed forms mutate a dimension-compatible matrix, traversing reflectors in the order for Q or Q^T. explicit_form applies the sequence to an identity matrix. Work is O(K*R*M) for an R-by-M or M-by-R operand; fixed temporary vectors/sums are inline. householder_sequence_dyn owns dynamic V/betas and runtime R/K; its applications allocate a vector plus row/column temporary sums, and do not validate operand dimensions. The sequence itself owns coefficients, independent of the factored input.
