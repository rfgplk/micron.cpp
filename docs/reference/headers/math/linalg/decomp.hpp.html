micron::math::linalg::decomp::lu_result

Defined in header <micron/math/linalg/decomp.hpp>.

Unpivoted LU result containing separate L, U and singular flag.

Interpretation

L starts with unit diagonal and both matrices start otherwise zero. A zero computed U diagonal sets singular and returns partially completed factors. This flag detects the chosen unpivoted elimination's zero pivot, not a general rank test; use a pivoted factor for a matrix requiring row exchanges.

micron::math::linalg::decomp::lu_pivot_result

Defined in header <micron/math/linalg/decomp.hpp>.

Scaled partial-row-pivoted factor containing packed LU, perm, permutation sign and singular flag.

Packed factor and dynamic form

Strictly lower LU stores unit-lower multipliers; diagonal/upper LU stores U. perm[i] is the original row at factor row i. The sign changes with row swaps and singular is set for an exactly zero best pivot. lu_pivot_result_dyn uses owned dynmat LU and a serial-allocator usize vector for perm; it also allocates an O(N) scaling vector during factorization. lu_solve requires a valid nonsingular factor and enough RHS coefficients, overwriting the RHS with a solution.

micron::math::linalg::decomp::lu_full_result

Defined in header <micron/math/linalg/decomp.hpp>.

Complete-pivoted packed LU with row/column permutations, sign, singular flag and numerical rank.

Interpretation and dynamic form

The relation is P_row*A*P_col=L*U. perm_row/perm_col map pivoted coordinates to original row/column indices; sign tracks both kinds of swap. rank counts accepted pivots; best<=tol sets singular and returns the current factor. lu_full_result_dyn stores the same metadata using dynamic matrix/vector owners. lu_full_solve performs both permutation steps and unchecked triangular division, so it requires full rank rather than silently supplying a rank-truncated solution.

micron::math::linalg::decomp::chol_result

Defined in header <micron/math/linalg/decomp.hpp>.

Fixed lower-Cholesky result containing L and spd flag.

Failure and dynamic form

An updated diagonal <=0 clears spd and returns a partial lower factor; unfilled coefficients remain zero. The function reads the lower triangle and assumes symmetry/finite arithmetic. spd::chol_result_dyn has the same fields with an owned dynamic L and is returned by spd::chol. Callers must check spd before chol_solve; no symmetry or positive-semidefinite completion is supplied.

micron::math::linalg::decomp::log_det_result

Defined in header <micron/math/linalg/decomp.hpp>.

Two-field determinant record containing log_abs and integer sign.

Values

sign is zero for a singular/failed factor and otherwise +1 or -1. The singular record is {0,0}, not negative infinity in log_abs. The ordinary LU implementation accumulates log of absolute U diagonal entries and permutation sign; the SPD implementation doubles the sum of log Cholesky diagonal entries and reports sign=1.

micron::math::linalg::decomp::inv_result

Defined in header <micron/math/linalg/decomp.hpp>.

Pivoted inverse result containing owned X and singular flag.

Dynamic form

inv_result_dyn stores dynamic X. Both return zero X with singular=true when pivoted LU fails; otherwise each column is solved against an identity RHS. This differs from linalg::inv, whose convenience return replaces singular output with all NaNs. Dynamic inversion allocates the LU copy, permutation/scaling, X and RHS solve temporaries.

micron::math::linalg::decomp::qr_result

Defined in header <micron/math/linalg/decomp.hpp>.

Modified Gram-Schmidt result containing thin Q[R,C] and upper R[C,C].

Rank behavior

Zero column norms are left unnormalized; there is no rank, permutation or success field. Reconstruction coefficients remain the iteration's result, and least-squares/pseudoinverse conveniences divide by R's diagonal without detecting rank failure. Full orthogonality of Q's C columns requires a suitable full-column-rank tall input.

micron::math::linalg::decomp::qr_householder_result

Defined in header <micron/math/linalg/decomp.hpp>.

Explicit Householder QR with full Q[R,R] and upper-trapezoidal R[R,C].

Dynamic form

qr_householder_result_dyn stores Q/R as dynamic matrices. Both start Q as identity and copy A into R before applying K reflectors. They contain no rank or convergence field, and coefficients below each processed column are explicitly zeroed. Use a compact pivoted result when storing full Q is unnecessary or numerical-rank selection is required.

micron::math::linalg::decomp::qr_colpiv_result

Defined in header <micron/math/linalg/decomp.hpp>.

Column-pivoted compact QR containing Householder Q, R, column permutation, sign and rank.

Relation and dynamic form

A*P=Q*R; perm[k] gives the original column in pivoted position k. sign tracks column exchanges; rank counts accepted reflectors. The threshold is compared against a residual squared column norm. qr_colpiv_result_dyn stores the sequence, R and permutation dynamically. qr_colpiv_solve sets coordinates outside the leading rank block to zero before unpermuting, so rank deficiency does not imply a minimum-Euclidean-norm solution.

micron::math::linalg::decomp::qr_fullpiv_result

Defined in header <micron/math/linalg/decomp.hpp>.

Full-pivoted QR record containing compact reflector Q, R, row-swap history, row/column permutations, sign and rank.

Interpretation and dynamic form

Q stores only the Householder part; interleaved row transpositions are retained separately in row_transp, and cannot be recovered by treating Q.explicit_form() as the whole left transform. perm_row is the cumulative original-row permutation, perm_col identifies original columns, and sign tracks swaps. qr_fullpiv_solve replays row swaps with reflectors on the RHS. qr_fullpiv_result_dyn uses dynamic sequences/matrices/vectors and retains only K row_transp entries; the fixed form has R slots, with K used. tol is an absolute maximum-entry threshold.

micron::math::linalg::decomp::cod_result_dyn

Defined in header <micron/math/linalg/decomp.hpp>.

Dynamic complete orthogonal decomposition containing compact Q/Z, lower triangular T_lower, column permutation and rank.

Result and solve

The first phase is column-pivoted QR. A second QR of the transpose of the leading rank rows gives a rank-by-rank lower T_lower and right-space sequence Z. cod_solve applies Q^T, solves T_lower, pads remaining coordinates with zeros, applies Z and undoes the column permutation. Zero rank yields an empty triangular factor and a zero solution. A valid matching RHS and usable accepted diagonals are required; no independent solve-status record is returned.

Small symmetric eigensystem record with real values and eigenvector columns.

2x2 and 3x3 forms

eigen_result2 uses two values and a 2-by-2 vectors matrix. eigen_result3 uses three values and a 3-by-3 vectors matrix. The analytic 2x2 routine emits descending values and uses identity vectors for zero off-diagonal input, including the value/axis-order caveat stated above. Defined in header <micron/math/linalg/decomp.hpp>.

Small square SVD record with U, singular values S and V, representing A=U*diag(S)*V^T where its numeric construction succeeds.

2x2 and 3x3 forms

svd2_result and svd3_result use the corresponding square matrix/vector dimensions. Both derive V and squared singular values from A^T*A and form U=A*V/S.     // U row i

      F s = A.data[i * N + j];
      for ( usize k = 0; k < i; ++k ) s -= r.L.data[i * N + k] * r.U.data[k * N + j];

  }
  return r;

{
