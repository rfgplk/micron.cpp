Type reference

micron::math::dynmat

Defined in header <micron/math/matrix/dynmat.hpp>.

Runtime-shape owned row-major matrix with public vector storage and element leading dimension.

Members and storage

value_type is T; storage_type is vector<T,allocator_serial<>,false>. Public buf owns rows*ld coefficients, rows/cols are logical dimensions, and ld is the row stride in elements. The ordinary shape constructors set ld=cols; the fill constructor supplies a coefficient value. with_ld permits padded row storage and allocates rows*ld elements without checking that ld>=cols. size reports the buffer's element count, including padding, not necessarily rows*cols.

Ownership and access

Copying copies owned vector storage; moving transfers the vector and clears the source dimensions. at computes buf[r*ld+c] without validation. zero/identity allocate new storage; from_fixed copies coefficients. as_row_view/submat_view are O(1) borrowed descriptors, invalidated by storage replacement/destruction. Public metadata and buf can be changed independently, so consistency is a caller-maintained invariant. linalg::dynmat is an alias of this type; linalg::dynvec, vec and quat alias their quants counterparts rather than introducing new storage.
