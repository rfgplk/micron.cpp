micron::int4x4_t

Defined in header <micron/math/matrix/int4x4.hpp>.

Predefined i32 matrix alias with four columns and four rows; paired uint4x4_t uses u32.

Selection

Each alias names int_matrix_base with the displayed dimensions. The numbers describe the shape, including in int64x1_t; they do not select a 64-bit coefficient. All inherit the same inline ownership, alignment, indexing and arithmetic rules.
