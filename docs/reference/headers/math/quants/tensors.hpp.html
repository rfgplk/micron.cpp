micron::tensor3f

Defined in header <micron/math/quants/tensors.hpp>.

A fixed depth-major three-dimensional tensor alias with embedded arithmetic elements.

Alias family and layout

All aliases instantiate the same internal tensor implementation with positive compile-time D,H,W and at most 4096 component bytes. The object embeds a 64-byte-aligned array in offset order d*(H*W)+h*W+w. Public depth,height,width and size describe the fixed extent; category/mutability/memory tags identify a mutable stack-stored quantity.

Construction, access, and lifetime

Default construction zeros all elements. Fill and exactly D*H*W scalar arguments initialize owned values; an initializer list of another size reports library_error. Copy operations copy the whole array. Move construction/assignment also copy the whole array and then zero the source, so moving is O(D*H*W) rather than pointer transfer.

Flat [], three-index [], at(d,h,w), row(d,h), and slice(d) do not check indices. Despite its name, at does not report out-of-range errors. Iterators are raw pointers spanning the flat array. dim(0) returns D, dim(1) H, and every other axis value returns W. Assignment preserves embedded addresses; moving does not retarget existing source references, whose values become zero. Object destruction invalidates its element references.

Operations and products

Elementwise tensor +,-,*,/, scalar arithmetic, reductions, norms, elementary functions, clamp/saturate/sign, pow/atan2/fma, lerp, fill/zero/iota, and boolean all/any/none traverse embedded values. Scalar-left subtraction currently calls t.sub_scalar(s), yielding t-s. mean on integer tensors uses integer division. argmin/argmax retain the first extremum.

contract requires the left width equal the right depth and returns shape D,H,W2, summing A(d,h,k)*B(k,0,w). Only right-hand height index zero is used; additional right height rows do not contribute. bmm expects right shape D,W,W2 and multiplies matching depth slices. Both cost O(D*H*W*W2) and construct an embedded output. transpose_slices/transposed require square H==W; transpose_hw/dh/dw return permuted fixed shapes.

softmax applies one stable-max-subtracted normalization across the entire flat tensor. layer_norm normalizes each width row with population variance and an epsilon; it supplies no affine scale/bias. ReLU/leaky-ReLU and sigmoid operate componentwise. Floating-domain and non-finite inputs are not uniformly validated; layer_norm's epsilon is not checked.

Complexity and use

Index/pointer/extent access is O(1). Copy, move, elementwise arithmetic, reductions, activations, and axis permutation cost O(S), S=D*H*W, plus scalar function cost. A width-row layer normalization uses O(S) work; products have the larger bound above. Storage is O(S) inline per tensor/result, without heap allocation. The implementation's internal name contains avx, but these bodies are scalar loops with selected unrolling and do not establish an ISA-specific tensor contract. Choose this family for small compile-time extents whose copied result fits the fixed byte limit.
