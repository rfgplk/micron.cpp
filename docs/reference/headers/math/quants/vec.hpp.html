Parameters

The parameter declarations, including any default arguments, are:

  • const vec<T, N> &a
  • T s

Effects

Equivalent to the following definition. Expressions, calls, initialization, and conditional branches are evaluated in the order specified here.

Equivalent definition
template<arith_scalar T, usize N>
[[nodiscard, gnu::always_inline]] inline constexpr vec<T, N>
operator/(const vec<T, N> &a, T s) noexcept
{
  vec<T, N> r{};
  if constexpr ( micron::is_floating_point_v<T> ) {
    // reciprocal-multiply is exact-enough for floats and much faster
    T inv = T(1) / s;
    for ( usize i = 0; i < N; ++i ) r.data[i] = a.data[i] * inv;
  } else {
    // integral T: T(1)/s integer-divides to 0 for |s|>1, so divide directly
    for ( usize i = 0; i < N; ++i ) r.data[i] = a.data[i] / s;
  }
  return r;
}
