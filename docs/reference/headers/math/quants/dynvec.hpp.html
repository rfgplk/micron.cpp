Type reference

micron::math::dynvec

Defined in header <micron/math/quants/dynvec.hpp>.

An owning runtime-length contiguous vector of arithmetic values.

Storage and construction

Public buf has storage_type=vector<T,allocator_serial<>,false>. T satisfies arith_scalar. Default construction is empty; dynvec(n) constructs n value-initialized elements, dynvec(n,fill) fills n elements, and zero/filled are named factories. from(vec<T,N>) allocates N elements and copies the fixed array. Copies duplicate owned values; moves transfer the underlying allocation.

data, size, and empty expose the buffer. operator[] is unchecked; at explicitly reports library_error for i>=size even though the underlying vector uses Sf=false. Resizing and other container operations are available through public buf rather than a parallel dynvec interface. No arithmetic operators are declared by dynvec itself.

Complexity and invalidation

Indexed access, data, size, empty, and as_view descriptor creation are O(1). Construction/fill/copy/from perform O(n) element work plus allocation; moves transfer the vector resource. Destroying the vector destroys owned storage. Reallocation or replacement through buf invalidates element pointers/references and previously obtained views; element assignment alone preserves their addresses.

as_view returns vec_view<T> or vec_view<const T> with unit increment and the current logical size. The view retains no ownership and does not grow when buf grows. Choose dynvec for runtime dimensions with ordinary owning value semantics, or vec_view to describe data allocated elsewhere.
