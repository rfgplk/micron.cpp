micron::math::quants::vec_view

Defined in header <micron/math/quants/views.hpp>.

A borrowed vector descriptor containing an element pointer, logical length, and signed stride.

Layout and access

Public data,n,inc default to nullptr,0,1. Pointer construction, from, and strided store those fields without validation. raw_slice construction stores its pointer/length with unit stride. from(C&) accepts data()/size() compatible with T*, while from(const C&) produces vec_view<const T>. Copying or moving copies only the descriptor.

operator[](i) and addr(view,i) access data+ssize_t(i)*inc. Negative increments are supported when data points to the first logical element of the reversed sequence; zero increment repeatedly selects the same element. Caller storage must cover every resulting address, and length/index conversion and pointer arithmetic must be representable. No iterator, capacity, bounds, or nonnull checks are supplied.

Lifetime and complexity

Construction, copying, indexed access, size, and is_unit_stride are O(1), with no allocation or element traversal. is_unit_stride tests inc==1. A const descriptor's operator[] returns a const reference, but public pointer storage does not make a mutable element type an ownership or read-only guarantee; use vec_view<const T> to express const elements.

Views do not extend lifetimes. Reallocating, destroying, or otherwise invalidating the owner invalidates affected accesses. Descriptor assignment does not alter elements. Shared const-element reads are possible while their owner remains stable; overlapping writes require synchronization. Choose a view for BLAS-style strides and external buffers.
