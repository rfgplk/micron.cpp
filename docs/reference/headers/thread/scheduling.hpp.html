micron::schedulers

Defined in header <micron/thread/scheduling.hpp>.

Names Linux FIFO, round-robin, deadline, normal, idle, and batch scheduling policies.

Values

fifo, roundrobin, deadline, normal, idle, and batch map to the corresponding Linux values. none is the explicit 0xFFFFFFFF sentinel. The free get_scheduler() queries the calling process/thread id and reports a system error if the query fails.

micron::scheduler_t

Defined in header <micron/thread/scheduling.hpp>.

A cached Linux scheduling-policy and scheduling-attributes descriptor.

Configuration

Construction queries sched_attr for a pid. Copy copies the cache; move transfers it and resets the source to schedulers::none. set_scheduler(policy) updates the cache only, resetting relevant nice/priority/deadline fields. load_scheduler(pid) applies the policy first and the full cached attributes second; either failure reports a system error, and a partial change is not rolled back.

load_scheduler applies a legacy priority-99 scheduler call for deadline policy before its attribute call; that can fail before deadline attributes are applied. enable_deadline(time) sets runtime to time/2, deadline to (time/4)*3, and period to time only for deadline policy and time >= 1024. These are kernel scheduling time units, not the floating millisecond sleep interface. get_priority() returns cached nice for ordinary policies or realtime priority for FIFO/RR. Classification helpers do not query the kernel again.

State and copies are inline with constant wrapper work; construction/application perform syscalls. This descriptor does not own a thread, restore previous scheduling at destruction, or serialize concurrent reconfiguration.

Equivalent definition
void
  set_scheduler(const schedulers s)
  {
    sched = s;      // keep the cached policy in sync so is_*()/get_priority()/enable_deadline() reflect it
    properties.size = sizeof(struct sched_attr);
    properties.sched_policy = static_cast<u32>(s);
    properties.sched_flag = 0x01;
    if ( is_scheduled(s) ) {
      properties.sched_nice = 0;
      properties.sched_priority = 0;
      properties.sched_runtime = 0x0;
      properties.sched_deadline = 0x0;
      properties.sched_period = 0x0;
    }
    if ( is_realtime(s) ) properties.sched_priority = 99;
    if ( is_deadline(s) ) {
      properties.sched_runtime = 0;
      properties.sched_deadline = 0;
      properties.sched_period = 0;
    }
  }

  enable_deadline(u64 time)
