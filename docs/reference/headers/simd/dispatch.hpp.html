micron::simd::__simd_flags

Defined in header <micron/simd/dispatch.hpp>.

Internal hosted-x86 feature-query record with byte fields for FMA, SSE families, AVX/AVX2 and OSXSAVE.

Scope

The record and query helpers are absent in freestanding or non-x86 branches. The fields describe queried CPU capabilities; __os_avx_enabled also checks XCR0 SSE/YMM state. Constructing/querying this record does not select a function pointer or change compile-time overload availability. The public SIMD operations remain selected by the build's feature macros.
