Type reference

micron::simd::v512

Defined in header <micron/simd/types/simd512.hpp>.

Fixed 512-bit packet class enabled by AVX512F on x86, or a four-block WebAssembly packet alias.

Aliases

Scalar lanesAliases in simd and micron scopes
64*i8;32*i16z8, packet64c; z16, packet32s
16*i32;8*i64z32, packet16i; z64, packet8l
16*f32;8*f64zfloat, packet16f; zdouble, packet8d

Availability and members

AVX512F gates alias declarations, while individual integer 8/16-bit operations need BW and 64-bit multiplication needs DQ. The native class supplies a smaller member surface than v128/v256, deletes indexing, and returns lane-mask comparison results. Native is_simd_class does not include these z aliases unless the composite-width branch is selected, so free is_simd_class-constrained wrappers reject native z packets. This is a current classification limit, not a missing runtime CPU test.

Value semantics

Storage is inline. Move construction clears the source while move assignment preserves its bits. Full-width transfers require 64 addressable bytes and the corresponding alignment where requested. No generic dynamic resizing or per-lane exception/status storage is provided.
