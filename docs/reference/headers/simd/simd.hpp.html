Type reference

micron::simd::is_simd_class

Defined in header <micron/simd/simd.hpp>.

Concept enumerating the canonical packet aliases included by the current compile-time branch.

Classification

The concept checks exact type equality with the defined 128-bit aliases, enabled 256-bit aliases and, only under __micron_simd_wide_composite, 512-bit aliases. It is not a structural test of arbitrary packet-like classes, does not remove qualifiers, and currently omits native AVX512 z aliases. A successful concept test also does not prove that a particular free wrapper can convert the packet to a raw intrinsic operand.
