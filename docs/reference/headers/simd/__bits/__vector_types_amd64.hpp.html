Layout helpers

width_v<T> reports sizeof(T)*8 and lane_count_v<T,L> reports sizeof(T)/sizeof(L). is_v64/is_v128/is_v256/is_v512 test only object size; an unrelated record of the same size can satisfy them. The carriers and size concepts do not perform CPU checks, establish a supported numerical operation or allocate storage. The _u attribute changes alignment requirements, not numerical precision or lane count.
