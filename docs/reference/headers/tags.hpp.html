Type reference

micron::mutable_tag

Defined in header <micron/tags.hpp>.

Empty dispatch tag used in container member aliases. Tags select compile-time interfaces and carry no synchronization or ownership machinery.

Tag types

TagsRole
mutable_tag, immutable_tag, numeric_tagMutability or numeric classification supplied by a type.
array_tag, vector_tag, list_tag, double_list_tag, buffer_tag, slice_tag, bitfield_tagSequence or storage category.
map_tag, tree_tag, theap_tagAssociative, tree, or extractable-heap category. theap_tag differs from the storage tag heap_tag.
string_tag, pointer_tag, type_tagString, pointer, or type category.
heap_tag, stack_tag, thread_tagContainer-declared storage classification; a tag alone does not enforce allocation or thread access rules.
void_pointer_tag, owning_pointer_tag, weak_pointer_tag, threaded_pointer_tagPointer-wrapper classification; lifetime behavior comes from the wrapper implementation.
safe_tag, unsafe_tagSafety-policy classification, distinct from the Safe and Unsafe aliases.
