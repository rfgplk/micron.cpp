Type reference

micron::__core_memory_resource

Defined in header <micron/memory/allocation/core_resource.hpp>.

The internal typed storage descriptor used by container resource bases. It stores a pointer and an element capacity without owning destruction or release.

Representation and related types

memory addresses T storage and capacity counts whole T slots. Accepting a byte chunk checks its alignment, derives capacity by integer division by sizeof(T), and clears the supplied descriptor. Any trailing bytes that do not form a whole element are absent from that capacity.

Copy ownership is not supplied by this base. Moving transfers its pointer/capacity and clears the source. accept replaces the fields without freeing previous storage. Dereference as a chunk exposes the byte extent capacity * sizeof(T); reference access rejects an empty resource.

InterfaceDescription
memory_flagsread, write, exec, and none metadata values.
__core_memory_flags<T>Stores a flags value; it does not apply operating-system page protection.

Notes

Descriptor operations are constant time. An address/capacity pair does not record which elements have been constructed. Use through its owning container/resource layer; the base destructor does not free the pointed storage.
