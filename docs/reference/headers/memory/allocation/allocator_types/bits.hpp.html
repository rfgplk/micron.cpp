micron::abc_allocator

Defined in header <micron/memory/allocation/allocator_types/bits.hpp>.

A low-level wrapper around the selected abc heap. Its size arguments are bytes even when its template parameter is a wider integral type.

Member functions

allocate returns a byte chunk from the backend wrapper. allocate_aligned selects an explicit alignment. Sized and unsized deallocate forms return storage; the aligned form must match the original alignment convention. brk_allocate uses the same backend chunk allocation and does not itself change the process break.

The native abc::__abc_allocator<T>::calloc name denotes fetching a chunk; ordinary native fetch is not a zero-fill guarantee. The wasm wrapper uses zalloc, which clears its grant. Native sanitizer builds route the wrapper through the sanitizer's allocation functions.

unmanaged_allocate and its paired release use direct sys_allocator mappings on the native target. The wasm alternative uses the wasm heap. None of these functions construct T objects.

Notes

Backend calls report allocation failure through the wrapper's exception path. Pointer-only release ignores null, while the native sized wrapper rejects null. A copied wrapper has no ownership of any chunk. Use the policy allocators or allocator_traits when a container requires reconstructible logical grants.

micron::stl_allocator

Defined in header <micron/memory/allocation/allocator_types/bits.hpp>.

An element-count allocator compatibility class available only with MICRON_ALLOW_GLIBC_MALLOC.

Effects

allocate(n) checks n * sizeof(T), obtains that many bytes through the configured internal allocation entry point, and returns T* without constructing elements. Failed allocation reports the allocation error path. deallocate(pointer, n) releases the pointer and ignores n. Allocator instances compare equal.

This class's element units differ from abc_allocator<T> and the chunk allocators' byte units. Its availability macro does not by itself prove which allocation backend the internal entry point selects.
