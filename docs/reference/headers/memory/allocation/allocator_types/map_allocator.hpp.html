Type reference

micron::map_allocator

Defined in header <micron/memory/allocation/allocator_types/map_allocator.hpp>.

A stateless allocator that gives each allocation its own anonymous private native mapping.

Allocation and resizing

The default policy is serial_allocation_policy. Nonzero requests are policy-rounded and then rounded to page_size; the default alignment and automatic initial request are one page. Greater alignments are obtained by overmapping and unmapping the unused prefix and suffix. Returned grants contain the page-rounded capacity.

resize attempts mremap with mremap_maymove for alignments no greater than a page when preservation includes the relevant old prefix. Otherwise it maps replacement storage, copies the bounded preserved bytes, and unmaps the old storage. The returned address can change. destroy unmaps the chunk; it does not run object destructors.

create/allocate, alignment overloads, extent, recommendation, growth, and telemetry follow the allocator protocol. share is deleted. A mapping is not registered in the separate external-provenance table by this allocator.

Complexity and notes

Allocation and release make system calls and have operating-system-dependent cost. The replacement path copies a linear number of bytes. mremap can change page-table mappings without an explicit user-space payload copy; this does not imply constant latency.

Use this allocator when allocations require independent page mappings or protection boundaries. Small grants still occupy page-rounded mappings. Alignment/size validation and mapping failures use the allocator exception paths. Every successful relocating resize and every release invalidates pointers into the old mapping.

Equivalent definition
[[nodiscard]] static chunk<byte>
  resize(chunk<byte> old, usize bytes, usize preserve_bytes, usize alignment)
  {
    if ( old.ptr == nullptr ) return create(bytes, alignment);
    allocation_validate_alignment(alignment);
    const usize capacity = __capacity(bytes);
    const usize overlap = micron::min(old.len, capacity);

    if ( alignment <= page_size && preserve_bytes >= overlap ) {
      addr_t *result = micron::mremap(micron::ptr_cast<addr_t *>(old.ptr), old.len, capacity, mremap_maymove);
      if ( !micron::mmap_failed(result) ) return { reinterpret_cast<byte *>(result), capacity };
    }

    chunk<byte> next = create(bytes, alignment);
    const usize copied = micron::min(preserve_bytes, old.len, next.len);
    if ( copied != 0 ) micron::memcpy(next.ptr, old.ptr, copied);
    destroy(old, alignment);
    return next;
  }

Equivalent definition
inline chunk<byte>
__map_create_aligned(usize capacity, usize alignment, i32 extra_flags = 0)
{
  allocation_validate_alignment(alignment);
  capacity = allocation_round_up_or_throw(capacity, page_size);
  if ( capacity == 0 ) return { nullptr, 0 };

  usize mapping_len = capacity;
  if ( alignment > page_size ) mapping_len = allocation_add_or_throw(capacity, alignment);

  addr_t *mapping = micron::mmap(nullptr, mapping_len, prot_read | prot_write, map_private | map_anonymous | extra_flags, -1, 0);
  if ( micron::mmap_failed(mapping) ) exc<except::memory_error>("allocator: mmap failed");

  if ( alignment <= page_size ) return { reinterpret_cast<byte *>(mapping), capacity };

  const uintptr_t raw = reinterpret_cast<uintptr_t>(mapping);
  const uintptr_t aligned = (raw + alignment - 1) & ~(static_cast<uintptr_t>(alignment) - 1);
  const usize prefix = aligned - raw;
  const usize suffix = mapping_len - prefix - capacity;
  if ( prefix != 0 ) micron::munmap(mapping, prefix);
  if ( suffix != 0 ) micron::munmap(reinterpret_cast<addr_t *>(aligned + capacity), suffix);
  return { reinterpret_cast<byte *>(aligned), capacity };
}
