Type reference

micron::allocator_huge

Defined in header <micron/memory/allocation/allocator_types/huge_allocator.hpp>.

An independent native mapping allocator requiring explicit huge pages. Its default huge-page selector is map_huge_2mb and its default policy is huge_allocation_policy.

Effects and constraints

The selected huge-page flag determines the huge-page byte size. Policy grants are rounded to that size. Alignment must be a nonzero power of two no greater than the selected huge page. Allocation uses map_hugetlb with the selector and has no ordinary-page fallback. Kernel support and a satisfiable huge-page allocation are required.

create/allocate return the rounded byte grant and register huge external provenance. Resize allocates another huge-page mapping, copies a bounded preserved prefix, and releases the old mapping. Destroy unregisters and unmaps. auto_size is the huge-page size; recommendations apply the selected growth policy.

Complexity and lifetime

Mapping costs depend on the operating system. Replacement resize is additionally linear in preserved bytes. New allocations preserve existing mappings; resizing and destruction invalidate the old allocation. Use it for an explicit huge-page storage requirement, accounting for whole-huge-page rounding and possible allocation failure.

  create(usize bytes, usize alignment)
  {
    allocation_validate_alignment(alignment);
    if ( alignment > __huge_size() ) exc<except::invalid_argument>("allocator_huge: alignment exceeds the selected huge-page size");
    const usize capacity = __capacity(bytes);
    if ( capacity == 0 ) return { nullptr, 0 };
    addr_t *memory
        = micron::mmap(nullptr, capacity, prot_read | prot_write, map_private | map_anonymous | map_hugetlb | HugePageFlag, -1, 0);

    if ( !abc::register_external(reinterpret_cast<byte *>(memory), capacity, abc::external_provenance::huge) ) {
      micron::munmap(memory, capacity);
      exc<except::memory_error>("allocator_huge: provenance registration failed");
    }
    return { reinterpret_cast<byte *>(memory), capacity };
  }
