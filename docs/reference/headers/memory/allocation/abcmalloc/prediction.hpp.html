Type reference

abc::alloc_predictor

Defined in header <micron/memory/allocation/abcmalloc/prediction.hpp>.

A small allocation-growth history used by native abcmalloc's expansion path. It stores the last 32 sizes and maintains their sum and nonzero count.

Effects and complexity

operator+= replaces the oldest recorded size. predict_size(n) returns a page-aligned request based on the mean when the request is close enough and belongs to the same predictor class; otherwise it returns the page-aligned request itself. An empty history uses the request. Copy and move copy the bounded history.

History updates and predictions perform constant work with fixed storage. Predictions are sizing heuristics and do not promise a successful future allocation, a particular throughput, or a general-purpose statistical model.

inline alloc_predictor &
  operator+=(const usize n) noexcept
  {
    const u32 i = index;

    const usize old = allocs[i];
    running_sum -= old;
    running_div -= (old != 0);

    allocs[i] = n;
    running_sum += n;
    running_div += (n != 0);

    index = (i + 1) & (__max_cached - 1);

    return *this;
  }

[[nodiscard]] inline usize
  predict_size(const usize n) const noexcept
  {
    if ( __builtin_expect(running_div == 0, 0) ) return align_to_page(n);

    const usize mean_alloc = static_cast<usize>(running_sum / running_div);

    if ( mean_alloc == 0 || n > mean_alloc * 3 || of_class(n) != of_class(mean_alloc) ) {
      return align_to_page(n);
    }

    return align_to_page(mean_alloc > n ? mean_alloc : n);
  }
