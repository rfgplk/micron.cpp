abc::abc_inspect_desc

Defined in header <micron/memory/allocation/abcmalloc/inspect.hpp>.

A retained description of the compiled native allocator layout for an external debugger or memory inspector. The inline descriptor is emitted in .micron.abcmalloc.

Descriptor fields

The descriptor publishes magic/version/ABI/size, feature bits, pointer width, endian/architecture identifiers, a configuration fingerprint, addresses of allocator roots, mapping geometry, and byte offsets/sizes used to walk arena, tier, range, sheet, and book records.

InterfaceDescription
abc_tier_descPer-tier class size, maximum sheet count, cache capacity, TLSF/buddy kind, user/internal classification, minimum-block shift, and layout offsets. Six entries describe five user tiers plus metadata.
inspection::detail_descriptorOptional magic/version/size, feature mask, and indexed layout values for free lists, pending remote frees, quiescence fields, redzones, and doctor records/history.
inspection::fieldIndices into the detail descriptor's values array; an index is meaningful only when the corresponding feature is present.

Notes

abc_inspect_valid checks its implemented handshake fields; it does not prove that every pointed-to live record is readable, that the process is quiescent, or that the configuration fingerprint matches an inspector's expectations. The descriptor is not an owning snapshot. Readers must use the target's declared pointer width and offsets and coordinate live-state inspection independently.

MICRON_ABC_INSPECT_DETAILS publishes additional detail layout. MICRON_ABC_INSPECT_HISTORY, together with doctor mode, adds history layouts. The native allocator's internal __-prefixed arenas, books, caches, remote-free queues, and ledger records remain implementation types described through these offsets.

constexpr bool
abc_inspect_valid(const abc_inspect_desc *d)
{
  if !consteval {
    if ( d == nullptr ) return false;
  }
  if ( d->magic != abc_inspect_magic ) return false;
  if ( d->version != abc_inspect_version ) return false;
  if ( d->abi != static_cast<u16>(MICRON_ABI) ) return false;
  if ( d->size < __builtin_offsetof(abc_inspect_desc, details) ) return false;
  if ( d->ptr_width != sizeof(void *) ) return false;
  if ( d->n_tiers != abc_n_tiers ) return false;
  return true;
}
