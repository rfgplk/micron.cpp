Type reference

micron::mem_prots

Defined in header <micron/memory/mmap_bits.hpp>.

Scoped names for native page-protection bits. The related map_types enumeration names a subset of mapping flags.

Enumerations

InterfaceDescription
mem_protsexec, growsdown, growsup, none, read, and write; protection bits corresponding to the provided prot_* constants.
map_typesshared, mmap_private, shared_validate, droppable, type, fixed, file, anonymous, and anon.

Constants and notes

The header also defines integer prot_*, map_*, huge-page selectors, ms_*, madv_*/posix_madv_*, mcl_*, and mfd_*/seal constants used by the native wrappers. These values select raw operating-system behavior; their presence does not establish runtime kernel support, permissions, available huge pages, or success of a mapping operation. The scoped enumerations do not themselves add validation or apply page protection.
