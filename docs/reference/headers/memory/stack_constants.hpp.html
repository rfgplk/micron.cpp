Type reference

micron::stack_t

Defined in header <micron/memory/stack_constants.hpp>.

A non-owning stack-region descriptor containing addr_t* start and a byte count usize size.

Stack queries

get_stack, get_stack_start, and get_stack_size expose the registered main-stack bounds on a native freestanding build when those bounds are available. Otherwise the native implementation estimates a region below the current frame using default_stack_size and a 4096-byte alignment assumption; it does not query the operating system for the current thread's actual mapping. The wasm branch uses its runtime stack bounds.

These functions do not allocate a stack, extend object lifetimes, prove that a range is readable, or identify every thread's true stack extent. The native estimates are also used by some memory-checking helpers.
