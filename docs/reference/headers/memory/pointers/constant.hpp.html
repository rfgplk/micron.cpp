Type reference

micron::const_pointer

Defined in header <micron/memory/pointers/constant.hpp>.

Owner with an unchangeable stored pointer and const pointee access. Copy, move, assignment, release, and clear are deleted.

Scalar and array forms

The scalar default constructor allocates a default-constructed object. Argument construction allocates T with those arguments; adoption from T*& clears the supplied variable. Literal-null construction is deleted, but the raw pointer adoption overload does not reject an already null variable. data() and the call operator observe; arrow and dereference diagnose null.

The array form stores a pointer and fixed array length. Its default construction is empty; a size constructor allocates new T[size]; adoption takes a raw pointer variable and length. size() reports that length and indexing checks both null and index. Neither form provides get(), so helpers that assume it are not universally applicable.

Destruction deletes the owned object or array. Member types identify immutable ownership, but an external mutable alias to an adopted allocation remains the caller's responsibility. Construction/destruction have the corresponding allocation/element costs; observation is constant-time.
