Type reference

micron::unique_pointer

Defined in header <micron/memory/pointers/unique.hpp>.

Nullable exclusive owner of one object, with a separate T[] specialization for arrays. Copy is deleted; move transfers the stored pointer and clears the source.

Construction and modifiers

Default and null construction are empty. A nonempty argument pack constructs a new T; construction from T*&& adopts a compatible allocation and nulls the supplied pointer variable. Raw-pointer assignment also accepts an lvalue, forwarding to the consuming rvalue assignment. Replacing ownership destroys the old allocation.

get() observes, release() returns the pointer and empties the wrapper without deletion, reset(p) deletes the old object and adopts p, clear() deletes and empties, and swap exchanges pointers. Arrow and dereference diagnose null; Boolean conversion tests non-null. The unique<T>() helper also default-constructs an empty wrapper.

The array specialization constructs new T[n] through its size argument, adopts an array allocation, and uses delete[]. Arithmetic elements are not value-initialized by that array expression. Indexing checks null but not the index: the wrapper stores no public length. Unary & on the array wrapper returns the pointee rather than the wrapper's address.

Member types and lifetime

value_type and element_type name T; pointer_type, category_type, and mutability_type are owning_pointer_tag, pointer_tag, and mutable_tag. Ownership transfer preserves the pointee address; destruction, clear, reset, and replacement invalidate observers of the deleted object. Array addresses remain valid only while that array allocation remains owned. No internal synchronization is provided.
