Type reference

micron::atomic_pointer

Defined in header <micron/memory/pointers/atomic.hpp>.

Move-only owner storing its object or array pointer in an atomic_token<T*>. Pointer publication and pointee lifetime are separate responsibilities.

Operations

Default/null construction is empty; forwarded construction allocates a T, and raw-pointer construction consumes its source variable. get(order) defaults to an acquire load. Arrow, dereference, and array indexing take an acquire snapshot and diagnose null; array indexing does not check a bound.

reset, clear, replacement assignment, and destruction exchange the pointer and delete the displaced allocation. release() exchanges null without deleting. exchange(T*&&) returns the displaced pointer and consumes the incoming variable, leaving reclamation of the returned pointer to the caller. Swap is a sequence of three exchanges, with an intermediate null state, not one transaction over two wrappers.

The scalar specialization supplies compare_exchange_strong(expected,desired,success,failure). On success it consumes desired but does not delete the displaced pointer in expected. On failure expected is updated according to the atomic operation and desired remains with the caller. The array specialization does not provide this member.

Lifetime and complexity

A load does not retain ownership. Another thread can reset and delete the pointee immediately after the load, including before an arrow or dereference result is used. Provide external lifetime synchronization or a complete reclamation protocol around concurrent readers. The separate hazard-pointer scaffold is not integrated with these deletion paths.

Pointer work consists of fixed atomic operations; compare/exchange and underlying atomic implementation costs depend on the target. Reset/destruction additionally execute the object or array destruction and allocator operations. Atomic pointer replacement does not synchronize concurrent mutations of the object itself.
