micron::free_pointer

Defined in header <micron/memory/pointers/free.hpp>.

Legacy explicit-lifetime pointer handle. Copies duplicate the raw address and destruction does not delete it, although several assignments and clear do.

Ownership and operations

The scalar wrapper can wrap a raw/void pointer or construct a new object from arguments. Copy assignment overwrites the address without deleting the previous object; move and raw-pointer assignment first delete the destination's old object. release() returns and nulls the pointer, and the scalar call operator also releases it. convert<P>() passes the stored pointer as an rvalue to another wrapper.

clear() deletes the object but does not clear the stored address. A second clear, deleting assignment, or later dereference therefore uses a stale pointer unless the handle is separately emptied. Copies remain raw aliases and must not independently perform deleting operations. This is neither automatic shared ownership nor the passive lifetime behavior of weak_pointer.

Array specialization

The current array specialization instantiates its allocation helper with T[] and indexes as (*internal_pointer)[n], so ordinary scalar-element indexing is not a valid implementation. Its const release() attempts to modify a nonmutable pointer. Its category aliases are private, so it also fails the public pointer-tag protocol. These array members must not be assumed to implement the scalar wrapper's usable contract.
