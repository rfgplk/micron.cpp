micron::sec::sandbox

Defined in header <micron/sec/sandbox.hpp>.

Fixed-capacity configuration for applying child security/setup stages before program execution or a function body.

Launch results

spawn takes path/argv/envp; run takes i32(*)(). A successful child result means setup completed far enough to close the reporting pipe, not that the program/body later succeeded. child stores pid and fault; ok() requires a positive PID with no fault. run_to_completion also waits and returns result<exit_status>; ordinary spawn/run leave reaping to the caller.

exit_status stores the raw wait status. exited/signaled select the interpretation before code/signal; raw returns the original word. fault_t pairs stage and negative errno; its Boolean conversion tests stage, and stage_name returns a static name. Configurations retain their recorded first fault; configured() and config_fault() expose it. No child ownership or automatic cancellation is attached to the returned PID.

micron::sec::mount_spec

Defined in header <micron/sec/sandbox.hpp>.

Borrowed source/target/type/options strings with mount flags, readonly selection, and mount attributes.

Application

recursive() tests MS_REC; needs_remount() checks readonly/attribute changes. Sandbox bind defaults to recursive nosuid/nodev hardening. Recursive attributes use mount_setattr; nonrecursive bind attributes use remount. The builder does not create mount points or own the string storage.
