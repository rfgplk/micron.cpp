micron::sec::syscall_group_tag

Defined in header <micron/sec/groups.hpp>.

Marker for named static syscall-number arrays used by policy composition.

Named groups

Each group exposes policy_tag, calls, and count; is_syscall_group checks that protocol. Lists are architecture-dependent and do not inspect syscall arguments or deduplicate overlapping groups. Names such as readonly or network describe a grouping, not a complete filesystem or network authorization model.

GroupContent
baseline, baseline_ttyRuntime/basic file/memory/time calls; baseline_tty contributes ioctl alone and must be combined if desired.
memory, io, io_multiplexingMemory-management calls, descriptor/data operations, and polling/event/timer descriptors.
filesystem, filesystem_readonly, filesystem_no_mountBroad filesystem/mount operations, a smaller query group, and a mutation group without mount setup respectively.
process, process_no_nsCreation/exec/identity/control calls; process_no_ns omits clone3/unshare/setns but still includes clone and needs argument rules to restrict its namespace flags.
signal, time, ipc, capabilitiesSignal delivery/masks, clocks/timers including setters, shared IPC/event operations, and credential/capability control.
network, namespaces, mount_apiSocket operations, selected namespace entry/creation calls, and new mount API calls.
keyring, kernel_debug, uringKey operations, process/kernel inspection/module operations, and io_uring setup/enter/register.
kernel_attack_surfaceCombined namespace/new+legacy mount, keyring, and kernel-debug syscall list; a grouping name rather than an exhaustive security boundary.
