micron::sec::seccomp::arch

Defined in header <micron/sec/seccomp.hpp>.

Linux audit architecture identifiers for filter gates.

Selection

native_arch selects amd64, i386, ARMv7, or AArch64 at compile time. The enum also names several other ABIs for explicit data/gate construction; that does not add their syscall wrapper implementations. x32 syscall entry shares the amd64 audit architecture in practice, so the native builder gate also checks its syscall-number range.

micron::sec::seccomp::arg_cmp_t

Defined in header <micron/sec/seccomp.hpp>.

Argument index, unsigned comparison kind, comparison value, and optional mask.

Comparison kinds

cmp provides ne, lt, le, eq, ge, gt, and masked_eq. datum_a is the value and datum_b is the mask for masked_eq. Indices must identify arguments 0..5; the record and builder do not independently validate that range. arg_no_bits expresses masked equality with zero, rather than an any-bit-set predicate.

micron::sec::seccomp::filter_builder

Defined in header <micron/sec/seccomp.hpp>.

Fixed-capacity inline instruction array and state for a classic-BPF syscall filter.

State and modifiers

Max must be positive and no greater than the BPF instruction limit. count selects the live instruction prefix. Rule insertion reserves a slot for the default return; capacity failure marks overflowed and makes valid() false. Architecture gating must precede rules; upgrading an already weaker gate through require_native_arch is rejected. Ordinary rules after sealing do nothing.

allow/deny/deny_errno/trap_syscall emit individual actions; allow_batch emits a compact shared-return ladder; allow_range/deny_range use unsigned number comparisons. action_if and its wrappers add one argument predicate. default_* seals an action and finalize supplies default kill if needed. prog() can finalize but cannot retrofit a missing architecture gate; its fprog_t borrows insns.

Public array/state mutation bypasses builder invariants. valid() requires arch_ok, no overflow, nonempty sealed output, an initial architecture load, and a final return. It does not symbolically verify every jump/action or prove that the native x32 guard exists. Preserve the builder's lifetime until an install or sandbox launch has consumed its program.
