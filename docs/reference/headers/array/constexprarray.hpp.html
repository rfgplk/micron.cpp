micron::constexpr_array

Defined in header <micron/array/constexprarray.hpp>.

A fixed-extent contiguous array with constexpr construction, access, arithmetic, and queries.

Storage and construction

Requires is_constexpr_valid<T>. The public member stack is a 64-byte-aligned T[N], initialized with {}. Default construction retains those initialized values. Value construction assigns every slot. Initializer-list construction copies at most N values and value-initializes the remaining slots; excess values are silently ignored.

Copy and move operations process every element. A move retains the source's fixed extent. length and static_size equal N. The generator constructors appearing in a source comment are not part of the compiled interface.

Operations and complexity

at(i) checks its index; subscript is unchecked. Iterators and data() are raw pointers. fill, scalar compound arithmetic, array arithmetic on a prefix of extent M <= N, sum, mul, sqrt, all, and any use constexpr loops. Access and size queries are constant time; complete copies, fills, transforms, and reductions are linear in N.

Operations do not relocate the inline storage. Constant evaluation additionally requires every invoked element and math operation to be valid in a constant expression.

micron::constarray

Defined in header <micron/array/constexprarray.hpp>.

Alias template for constexpr_array<T, N>; N defaults to 64.

Notes

The alias denotes the mutable constexpr array type. It does not add const qualification, copy-on-write storage, or synchronization. <micron/array/constarray.hpp> is a convenience include for the defining header.
