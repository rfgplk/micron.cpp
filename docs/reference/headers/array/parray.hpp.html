micron::parray

Defined in header <micron/array/parray.hpp>.

A persistent fixed-size indexed value implemented by an atomically reference-counted branching trie.

Template parameters and storage

T satisfies is_movable_object; operations that copy leaves additionally require copying and assignment. K is 1 through 6, H is 1 through 8, and branching is B = 2^K. The fixed logical length is B^H, or 32768 with the defaults. The capacity must be representable in usize; the source additionally asserts K * H < 64.

The object stores one root pointer. Internal nodes hold B child pointers; leaves hold B constructed elements. Null subtrees represent default T{} values without allocating them. Default construction allocates no trie nodes. A repeated-value constructor builds one subtree per level and shares it across all equal branches. Initializer lists and contiguous sources materialize the occupied prefix and pad its final leaf.

Value operations and complexity

Copy construction retains the root in constant time; move construction transfers it. Assignment also releases the destination's previous tree, which may destroy its uniquely owned nodes. size() and max_size() always return the fixed length, and empty() always returns false, including for a default-constructed array.

set and update return a new version by copying the root-to-leaf path and retaining untouched branches. A lookup traverses H levels; a point update allocates H nodes and copies or initializes one leaf of B elements and B child entries per internal level, for O(B * H) work. set_many repeats this operation for each pair of members a (index) and b (value). at, set, and update check the fixed extent; get and subscript do not.

Scalar arithmetic constructs a complete new tree and visits the complete logical extent. Elementwise array arithmetic iterates the materialized leaves of the right operand and performs a point update for every visited slot. identity() exposes root identity, not value equality. Equality skips identical subtrees; distinct trivially copyable leaves are compared bytewise, while nontrivial elements use operator==.

Traversal and reduction semantics

Ordinary iteration visits every logical index, including implicit defaults, with O(H) dereference cost. for_each(index, value) instead visits only allocated leaves, including default-padded slots within each leaf. It skips entire null subtrees.

sum, mul_reduce, all, and any use that sparse traversal. In particular, all(value) is true and any(value) is false for a completely unmaterialized array, although indexed reads return defaults. Elementwise multiplication and division likewise leave left-hand indices in null right-hand subtrees unchanged. These functions do not have dense-array semantics for every sparse representation.

Iterator invalidation and thread safety

Creating another version does not mutate the original's elements. References remain valid while a version retaining the referenced leaf exists; an implicit-default reference denotes the shared default object. Iterators store a pointer to the container object and do not retain its root independently. Assignment, movement, swap-like replacement, or destruction of that owner changes or ends what an iterator observes.

Atomic reference counts support independent published versions in different threads. They do not serialize assignment to the same container object or synchronize mutable state reachable from an element.

micron::parray::const_iterator

Defined in header <micron/array/parray.hpp>.

An iterator storing a parray owner pointer and a logical index; iterator is an alias of this type.

Operations

Dereference and arrow traverse the owner's trie and return a const element reference or pointer. Increment, decrement, and index() operate on the stored index in constant time. Equality compares both the owner and index. The iterator provides no pointer arithmetic, iterator-category alias, or ownership of trie storage; the owner must remain alive and retain the intended version.
