Type reference

std::coroutine_handle

Defined in header <micron/__special/coroutine>.

Non-owning compiler coroutine-frame address with resume/destroy/done operations and optional typed promise access.

Frame protocol

The void specialization erases the promise type; a typed handle additionally obtains a frame from a promise and recovers that promise with compiler builtins. from_address does not allocate or validate a frame. Copying/destroying the handle value has no frame-lifetime effect. destroy explicitly destroys the frame, while resume/done require a valid frame in the appropriate suspended state; checking the handle's boolean only tests non-null.

coroutine_traits extracts Result::promise_type when present. suspend_always always suspends, and suspend_never is immediately ready. noop_coroutine returns a permanent special handle whose operations do nothing, whose boolean is true, and whose done is false. The supplied hash specialization hashes the numeric frame address. These primitives do not schedule tasks or synchronize access to a frame.
