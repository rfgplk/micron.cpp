Template parameters and storage

N is a positive bit count divisible by eight. ExpectedN, defaulting to N/8, must be positive and is used only to choose the default number of hash rounds. Default L rounds (N / ExpectedN) * ln(2) to the nearest integer and clamps it to 1 through 64; an explicitly supplied L is only required to be at least one.

A 64-byte-aligned inline bitfield<N> stores N/8 bytes of bits, plus alignment padding. The declared heap storage and immutable tags do not match physical allocation/update behavior: no heap buffer is allocated, and insertion mutates bits. The element/pointer/iterator aliases are conventional type aliases; keys are not retained and no key traversal is provided.

Operations and interpretation

Construction clears every bit. insert(key) and emplace(key&&) set one bit for each seeded hash64 round; emplace hashes its argument without storing or consuming it. contains(key) tests the corresponding bits. False means at least one required bit is absent; true means the representation may have been inserted or may collide with other inserted representations.

Hashing reads sizeof(T) bytes, including any padding. Equal values whose object representations differ need not produce the same bits; use keys with canonical, consistently initialized representations when value-level membership matters. There is no erase, element count, false-positive estimator, saturation management, or public clear operation. Copying duplicates bits; the bitfield move operation copies them and zeroes the source.

Complexity and thread safety

Insert performs L hashes of sizeof(T) bytes. Contains performs at most L hashes and stops evaluating later hashes after a missing bit is found. Initialization and copying process N/8 bytes. Storage is fixed and exposes no element references to invalidate. Concurrent insertion modifies ordinary bitfield bytes and requires external synchronization, including against readers.
