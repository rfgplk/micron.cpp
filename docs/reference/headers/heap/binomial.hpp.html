micron::__binomial_heap

Defined in header <micron/heap/binomial.hpp>.

An implementation-facing move-only binomial heap with comparator-defined minimum order and a recycled-node pool.

Representation and interface

C defaults to __binomial_less<T>. node_type is __binomial_node<T, C>. Public root-list, cached-minimum, node-count, comparator, and pool members expose the implementation directly; there is no separate unprefixed binomial_heap class in this header. Tree roots are maintained in increasing degree, and equal degrees are linked during union.

Insert and emplacement allocate or reuse one node, union it into the forest, and return its pointer. find_min returns a checked const reference. extract_min removes the cached extreme root, reverses its child chain into degree order, unions those children back, destroys/recycles the removed node, and returns its moved value. Clear recycles all active nodes; only pool draining at destruction or ownership replacement returns their raw storage.

decrease_key(node, value) accepts only comparator improvement and swaps values upward until ordered. delete_node swaps the selected value to a root then extracts that root. A node pointer therefore tracks a physical node, not one immutable logical value through key updates. find performs equality search and returns a node pointer or null. meld(other&) consumes the other's active tree forest; its recycled pool remains separately owned.

Complexity, handles, and limits

Cached minimum/size/empty queries are constant time. Binomial degree consolidation scans a logarithmic root list: insert, extraction, meld, decrease-key, and node deletion take logarithmic structural work under intact binomial invariants, apart from allocation/element cost. Equality search and clear are linear in nodes visited; moves transfer the graph and pool in constant time apart from releasing an old destination.

Nodes are relinked without reallocating surviving nodes, but value swaps can retarget what a node handle represents. Extracted/recycled nodes invalidate their handles and may be reused. Callers must supply a live member node, compatible comparators on meld, and distinct heaps; self-meld has no guard. Exposed internal mutation can invalidate all structural bounds. There is no synchronization, general iterator, or capacity reservation API.

inline node_type *
  merge_root_lists(node_type *h1, node_type *h2)
  {
    if ( !h1 ) return h2;
    if ( !h2 ) return h1;

    node_type *head;
    node_type **pos = &head;

    while ( h1 && h2 ) {
      if ( h1->degree <= h2->degree ) {
        *pos = h1;
        h1 = h1->sibling;
      } else {
        *pos = h2;
        h2 = h2->sibling;
      }
      pos = &((*pos)->sibling);
    }

    *pos = h1 ? h1 : h2;
    return head;
  }

inline void
  union_heap(__binomial_heap &other)
  {
    if ( !other.root_list ) return;

    root_list = merge_root_lists(root_list, other.root_list);
    other.root_list = nullptr;

    if ( !root_list ) {
      min_node = nullptr;
      node_count += other.node_count;
      other.node_count = 0;
      return;
    }

    node_type *prev = nullptr;
    node_type *curr = root_list;
    node_type *next = curr->sibling;

    while ( next ) {
      if ( (curr->degree != next->degree) || (next->sibling && next->sibling->degree == curr->degree) ) {
        prev = curr;
        curr = next;
      } else {
        if ( comp(curr->value, next->value) ) {
          curr->sibling = next->sibling;
          link(next, curr);
        } else {
          if ( !prev )
            root_list = next;
          else
            prev->sibling = next;
          link(curr, next);
          curr = next;
        }
      }
      next = curr->sibling;
    }

    update_min();
    node_count += other.node_count;
    other.node_count = 0;
    other.min_node = nullptr;
  }
