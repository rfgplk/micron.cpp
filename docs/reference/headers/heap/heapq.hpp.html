Type reference

micron::heapq

Defined in header <micron/heap/heapq.hpp>.

An exclusive-mutex-protected minimum-priority heap stored in a growing fvector.

Member types and interface

Declares value_type = T, size_type = usize, reference = T&, and const_reference = const T&. Default construction creates the underlying vector. Construction from fvector<T> copies values then performs bottom-up heapification. Copy construction locks and copies a source; move construction transfers its vector without locking the source. Assignments lock both objects in address order.

push(const T&) copies an appended value and sifts upward under <. pop() checks nonemptiness, copies the minimum, refills from the final value, removes that slot, and sifts downward. top() returns a const reference to the minimum after releasing its lock; data() similarly returns a reference to the underlying fvector. These references require external exclusion during later use.

Size/empty and for_each take the mutex. Nonconst for_each can modify keys without restoring the heap invariant, and callbacks execute while the nonrecursive mutex is held. There are no public clear, reserve, max_size, comparator, or rvalue-push members.

Complexity and iterator invalidation

Top and size queries are constant time apart from lock waiting. A push makes logarithmic sift steps and may also relocate a linear vector prefix; geometric growth amortizes relocation across pushes. Pop makes logarithmic sift steps. Construction from a vector is linear heapification plus copying. Copy/traversal are linear; moving a new object is constant time with exclusive source ownership.

Vector growth can invalidate all element references; sifts change slot values even without reallocation. Popping ends a slot lifetime. A temporary internal lock does not protect references retained after top/data return. Destruction and moving require coordination with concurrent callers.

void
  sift_down(usize idx)
  {
    usize n = heap.size();
    while ( true ) {
      usize left = 2 * idx + 1;
      usize right = 2 * idx + 2;
      usize smallest = idx;

      if ( left < n && heap[left] < heap[smallest] ) smallest = left;
      if ( right < n && heap[right] < heap[smallest] ) smallest = right;

      if ( smallest != idx ) {
        micron::swap(heap[idx], heap[smallest]);
        idx = smallest;
      } else {
        break;
      }
    }
  }
