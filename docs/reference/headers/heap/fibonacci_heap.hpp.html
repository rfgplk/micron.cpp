micron::fibonacci_heap

Defined in header <micron/heap/fibonacci_heap.hpp>.

A move-only node-based max-heap with circular root/child lists and deferred equal-degree consolidation.

Representation and operations

Each node owns one value, parent/child pointers, circular sibling links, degree/mark fields, and its exact allocator extent. Nodes are individually allocated through Alloc; moving transfers the root graph, while copying is deleted. The root member is named min_root internally, but comparisons select the largest value.

Copied or moved insertion adds a singleton root and updates the cached maximum. max() checks nonemptiness and returns a mutable reference. pop() checks nonemptiness, promotes the removed root's children, consolidates equal-degree roots, moves out the value, and destroys/frees that node. clear destroys/frees the whole forest. Size/empty are cached constant-time queries.

There are no public handles, decrease-key, erase-by-handle, or meld members. Private cut helpers and a mark field do not by themselves expose the full conventional Fibonacci-heap interface.

Complexity and reference invalidation

Insertion performs constant pointer work plus one node allocation and construction. A pop can scan a linear number of roots after many insertions; deferred consolidation gives logarithmic amortized consolidation work for ordinary insert/pop sequences under the degree invariants, rather than a logarithmic worst-case single pop. Clear is linear in nodes; moving a new heap is constant time.

Nodes are relinked without moving their values. A reference to an unremoved node's value survives insertion/consolidation but ends when that node is popped or cleared. Mutating the reference returned by max does not repair heap order. No synchronization is provided. Consolidation uses a fixed 64-entry degree table, with oversized degrees clamped rather than dynamically growing the table.

  pop()
  {
    if ( !min_root ) exc<except::library_error>("fibonacci_heap::pop() empty");
    node *z = min_root;
    if ( z->child ) {
      node *c = z->child;
      do {
        node *next = c->right;
        c->left = min_root;
        c->right = min_root->right;
        min_root->right->left = c;
        min_root->right = c;
        c->parent = nullptr;
        c = next;
      } while ( c != z->child );
    }

    z->left->right = z->right;
    z->right->left = z->left;

    if ( z == z->right )
      min_root = nullptr;
    else {
      min_root = z->right;
      consolidate();
    }

void
  consolidate() noexcept
  {
    if ( !min_root ) return;
    constexpr usize max_degree = 64;
    node *A[max_degree] = { nullptr };

    usize nroots = 0;
    {
      node *r = min_root;
      do {
        ++nroots;
        r = r->right;
      } while ( r != min_root );
    }
    node *w = min_root;
    for ( usize k = 0; k < nroots; ++k ) {
      node *x = w;
      node *next = w->right;
      usize d = x->degree;
      while ( d < max_degree && A[d] ) {
        node *y = A[d];
        if ( x->value < y->value ) micron::swap(x, y);
        link(y, x);
        A[d] = nullptr;
        d++;
      }
      if ( d >= max_degree ) d = max_degree - 1;
      A[d] = x;
      w = next;
    }

    min_root = nullptr;
    for ( usize i = 0; i < max_degree; i++ ) {
      if ( A[i] ) {
        if ( !min_root ) {
          min_root = A[i];
          min_root->left = min_root->right = min_root;
        } else {
          A[i]->left = min_root;
          A[i]->right = min_root->right;
          min_root->right->left = A[i];
          min_root->right = A[i];
          if ( A[i]->value > min_root->value ) min_root = A[i];
        }
      }
    }
  }
