Differences from stack

Uses the same contiguous resource, initial-capacity parameter, automatic growth, top-relative indexing, bottom-to-top iteration, copying, moving, comparison, reserve, and clearing model as stack. Top, pop, call-operator, subscript, and pop-range do not check bounds or nonemptiness. A caller must establish those conditions before every operation.

The specialization selected for movable noncopyable elements deletes copying, initializer-list construction, and copied push. It retains moved push, default construction, emplacement, and ownership transfer. Most data-path functions, including automatic allocation and element construction, are noexcept; exceptions terminate rather than propagate as a recoverable stack error.

Complexity and iterator invalidation

The ordinary heap-stack bounds and reallocation invalidation rules apply. Removing checks does not remove linear relocation on a growing push, linear destruction, or element comparison cost. operator()() has the same extra move-through-pop behavior as stack. No synchronization or separate fixed-capacity guarantee is provided.
