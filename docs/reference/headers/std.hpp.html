Type reference

sig_t

Defined in header <micron/std.hpp>.

Global alias of void (*)(int), a pointer to a function taking one int and returning void.

Use

The alias describes a function-pointer signature. It does not install a signal handler, own a callable object, or extend the lifetime of code in a loaded module.
