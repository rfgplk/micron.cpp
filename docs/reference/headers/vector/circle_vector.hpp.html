micron::circle_vector

Defined in header <micron/vector/circle_vector.hpp>.

A fixed-capacity inline ring whose append operations overwrite the oldest element when full.

Member types and storage

N must be a positive power of two and satisfy the underlying carray<T, N> extent constraint. A carray member default-constructs all N slots. The ring stores a read index, a write index, and a logical count; wrapping uses N - 1 as a bit mask. max_size() and capacity() both return N.

difference_type is ptrdiff_t; iterator is circular_iterator<false> and const_iterator is circular_iterator<true>. Logical elements need not occupy one contiguous physical run. data() returns the physical buffer base, which need not be the logical front.

Operations

push, push_back, move_back, and emplace_back assign into the next existing slot. At full capacity they advance the front index and discard the oldest logical value. pop() moves out the oldest value and returns T{} when empty; pop_front() only advances the front and is a no-op when empty. Popping does not destroy the vacated slot.

clear() resets indices and count. For nontrivially destructible T, it additionally assigns T{} to the live logical slots. Copy/move construction linearizes logical contents into the destination's physical prefix; moving also clears the source. The carray member continues to own every physical element lifetime.

at always checks the logical index. Subscript and front/back checks depend on Sf. Push/pop/copy/move members are noexcept; throwing element construction or assignment therefore cannot be treated as a recoverable container exception.

Complexity and iterator invalidation

Indexing, push, pop, and iterator arithmetic take constant time, apart from the element operation. Default construction constructs N slots. Copy and move construction additionally copy or move live logical values. Clear is constant time for trivial destructors and linear in logical size otherwise.

Physical element addresses never reallocate. An iterator stores the owner and logical offset and uses the owner's current front index at dereference. Popping the front, overwriting a full ring, or clearing can therefore retarget an existing iterator to a different element. Saved physical references refer to slots whose values can be overwritten by future pushes. No synchronization is provided.

micron::circle_vector::circular_iterator

Defined in header <micron/vector/circle_vector.hpp>.

A logical-position iterator for a ring, parameterized by const access.

Member types and operations

value_type is T, difference_type is ptrdiff_t, and pointer/reference select T*/T& or their const counterparts from Cnst. Dereference, arrow, subscript, increment/decrement, offset arithmetic, and difference use the stored logical index and the owner's current front.

Equality compares the owner and index. Ordering and difference compare indices only and require iterators from the same owner for meaningful results. An iterator does not keep the owner alive or check dereference bounds. The public aliases provide mutable and const forms; no iterator-category alias is declared.
