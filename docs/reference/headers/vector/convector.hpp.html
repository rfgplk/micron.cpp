Storage and synchronized operations

The allocation and capacity model matches vector, with an additional fast_mutex. Count/list/value construction, deep-copy construction, move construction, copy/move assignment, resize, append, weld, insertion, erasure, sorting, and clearing are provided. Copy construction captures and copies a locked source snapshot. npos is the largest size_type value; find_index returns it on absence.

push_back, emplace_back, move_back, reserve, size queries, index search, contains, removal, fill, and clear acquire the mutex. Const subscript, const at, and const front/back copy the selected value while locked. for_each(fn) holds the mutex across every callback. append, weld, swap, and copy assignment acquire both involved mutexes in address order. remove(values...) performs a separate locked pass per value rather than one combined atomic operation.

Escaping references and thread safety

Nonconst subscript, at, front, and back return references after releasing their temporary lock. data, begin/end, get/cget, itr, and last provide unsynchronized pointers or iterators. These results require external exclusion from conflicting element writes, reallocation, and destruction. Slice and byte-slice members instead copy under the lock and return independent owned snapshots.

Move construction transfers a source resource without taking its mutex; move assignment locks only the destination. The source therefore requires exclusive ownership during those operations. Low-level inherited resource access bypasses the mutex. Callbacks invoked by for_each must not call another locking member of the same container: the mutex is not recursive. A const for_each body still passes elements through the stored mutable pointer.

Complexity and iterator invalidation

Apart from lock waiting and element copies, mutable-vector access, growth, search, suffix-shifting, and invalidation bounds apply. sort holds the lock while copying to a temporary ordinary vector, sorting it, and copying values back, so it uses an additional O(size()) element buffer. Mutex acquisition does not extend the lifetime of returned pointers and does not make an externally retained iterator safe during growth.
