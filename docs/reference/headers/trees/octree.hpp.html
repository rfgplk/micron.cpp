Type reference

micron::octree

Defined in header <micron/trees/octree.hpp>.

A three-dimensional point-region bucket tree, sharing the quadtree API and storage implementation with eight children per internal node.

Template parameters and domain

F defaults to float, Capacity to 8, and MaxDepth to 12. Point and box types have dimension three. The default universe is [-1048576,1048576] on every axis; out-of-universe insertion returns false. MaxDepth stops subdivision, after which coincident or closely grouped points accumulate in overflow leaves.

Operations and ownership

The operations are the same as quadtree: copied-value insertion allowing duplicates; exact one-occurrence point/value erasure; box and radius queries; nearest with squared distances; enumeration, transformation, structural folding, stoppable traversal, and node reservation/accounting. No unique-key lookup or iterator is supplied. The shared arena owns values and byte-relocates them on expansion; copying is deleted and movement transfers storage.

Complexity and invalidation

The quadtree bounds apply with eight instead of four children. Descent is bounded by MaxDepth, while overflow chains and unpruned queries can be linear in population. Nearest maintains a sorted list of at most k results and can take O(n*k) work. Slab growth, subdivision, and erasure invalidate affected value addresses; shared callback and noexcept restrictions also apply.
