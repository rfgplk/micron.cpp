micron::radix_tree

Defined in header <micron/trees/radix.hpp>.

A compressed radix trie owning nonempty sequence-key fragments and mapped values, with exact and longest-prefix lookup.

Key requirements and representation

Key and Value are constrained to be copy- and move-constructible. The implementation additionally default-constructs both, indexes and measures Key, takes substrings, appends fragments with +=, and assigns values. A string-like owning Key is the intended model; a non-owning Key carries its own backing-storage lifetime requirements.

Each pooled node owns an edge fragment, a default-constructed Value, child/sibling links, and a has_value flag. Sibling first elements are unique but unsorted. Insertion splits a partially matching fragment. Erasure clears the value and prunes empty terminal nodes; it does not merge remaining unary fragments. Empty keys are rejected by insert_or_assign, and find never returns a value for them.

Member functions

insert preserves existing values, while insert_or_assign replaces; both report whether a new key was added. find is nullable; at reports absence. longest_prefix_match(query) returns the value attached to the longest complete stored key prefix, not a pointer to the prefix text. operator[] inserts Value{} for nonempty absence; an empty argument cannot be inserted and its current body then dereferences null.

There are no begin/end iterators or ordered bounds. For_each reconstructs complete keys into a temporary accumulator and supplies (const Key&, Value&); key references must not escape the callback. Traverse accepts the same entry shape and supports stopping, but does not act on skip_children. Its const overload currently permits a mutable Value& callback. radix<Key,Value> aliases this class. Copying is deleted; move and swap transfer the pool.

Complexity

Let L be the query length and S the number of sibling edges inspected along its path. Lookup is O(L+S) element comparisons; S depends on fanout and can make lookup linear in the node population. Updates additionally copy substrings and allocate/split nodes. Enumeration reconstructs keys and can copy substantially more than n units of key data. Erasure records at most 64 path nodes for pruning; deeper searches still find values but may leave unused nodes unreclaimed until clear.

Reference invalidation and use

Pool growth does not relocate nodes, but splitting a fragment moves an existing Value into a new tail node, changing its logical address. Erasure resets a value and may free its node. No stable-value-address contract should be inferred from pooling. Use for actual sequence prefixes, with nonempty keys and callback-bounded reconstructed key lifetimes.

template<class VV>
  bool
  insert_or_assign(const Key &k, VV &&v)
  {
    if ( k.size() == 0 ) return false;
    __ensure_root();
    node *cur = __root;
    usize off = 0;

    for ( ;; ) {
      node *e = __find_edge(cur, k, off);
      if ( !e ) {

        node *n = __mk();
        n->frag = k.substr(off);
        n->value = micron::forward<VV>(v);
        n->has_value = true;
        __link(cur, n);
        ++__size;
        return true;
      }

      const usize m = __match_at(e->frag, k, off);
      if ( m == e->frag.size() ) {
        off += m;
        if ( off == k.size() ) {
          const bool fresh = !e->has_value;
          e->value = micron::forward<VV>(v);
          e->has_value = true;
          if ( fresh ) ++__size;
          return fresh;
        }
        cur = e;
        continue;
      }

      node *tail = __mk();
      tail->frag = e->frag.substr(m);
      tail->child = e->child;
      tail->has_value = e->has_value;
      if ( e->has_value ) tail->value = micron::move(e->value);

      e->frag = e->frag.substr(0, m);
      e->child = nullptr;
      e->has_value = false;
      __link(e, tail);

      if ( off + m == k.size() ) {

        e->value = micron::forward<VV>(v);
        e->has_value = true;
      } else {
        node *branch = __mk();
        branch->frag = k.substr(off + m);
        branch->value = micron::forward<VV>(v);
        branch->has_value = true;
        __link(e, branch);
      }
      ++__size;
      return true;
    }
  }

bool
  erase(const Key &k)
  {
    if ( !__root || k.size() == 0 ) return false;

    node *parent = __root;
    node *cur = nullptr;
    usize off = 0;
    node *path_parent[64];
    node *path_node[64];
