Type reference

micron::sync_channel

Defined in header <micron/tasks/sync_channel.hpp>.

A bounded FIFO MPMC channel using native futex-backed permit waits.

Operations and limits

Cap defaults to 256, with exactly Cap admission permits over a power-of-two Crossbeam ring allocation. push(T) waits for space and rejects close; pull(out) waits for an item and returns true for a received value or false when closed and drained. try_push/try_pull test permits but can still spin on queue publication/consumption. close() aborts both native semaphores and permits buffered draining.

The underlying basic_semaphore::wait can return on unexpected futex errors without obtaining a permit; the channel does not distinguish that result before spinning on its ring. Count overflow, misuse of reset/abort externally, and premature destruction remain unsupported. Blocking use inside a task parks the native worker. Producer close races can publish after an earlier open check; coordinate shutdown explicitly. Copying/moving are unavailable.
