Type reference

micron::generator

Defined in header <micron/tasks/generator.hpp>.

A lazy move-only synchronous single-pass coroutine range.

Iteration and values

The nested promise_type stores a pointer to the currently yielded value and a diagnostic string. begin() resumes to the next yield; every additional begin advances again rather than creating an independent iterator. Prefix/postfix increment resume the same frame, and comparison with sentinel tests null or done. Postfix increment returns void. There is no random access, size cache, or multipass guarantee.

iterator::operator* and arrow borrow the object passed to co_yield. Advancing or destroying the generator can end that object's lifetime. Reference-like yielded expressions still require an appropriately surviving referent; no copied yield buffer is provided. The arrow declaration is T*, so a reference T cannot form that return type and is not a supported general reference-generator specialization.

Move transfers the coroutine handle; destruction destroys it and all live coroutine locals without completing iteration. Escaped exceptions become a fixed library-error diagnostic when advancement reaches done. No scheduler or worker thread is started by iteration. Iterator copies refer to the same frame and concurrent iteration is unsupported.
