micron::coro::async_lock_guard

Defined in header <micron/tasks/async_locks.hpp>.

A movable scope owner for an already acquired async_mutex.

Acquisition and ownership

co_await coro::scoped_lock(m) awaits the mutex and returns an owning guard. Direct construction from (mutex_pointer, owned) trusts the supplied ownership flag and does not acquire. Default construction is empty. Copying is deleted; move transfers state, releasing the destination's old ownership on assignment.

unlock() and destruction release only retained ownership. owns_lock() observes this wrapper and mutex() borrows its pointer. There is no release-without-unlock member. The mutex must outlive the guard. Holding the guard across suspension is permitted by its lifetime protocol, but user lock order and progress still determine deadlock.
