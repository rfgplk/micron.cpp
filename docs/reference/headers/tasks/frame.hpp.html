Type reference

micron::coro::eventual

Defined in header <micron/tasks/frame.hpp>.

An immovable construct-once result slot for a structured child task.

Value lifetime

The primary template contains uninitialized union storage, a has-value flag, and an error-string pointer. Successful child return constructs T directly in that storage; destruction destroys it only if constructed. get() & returns its protected-by-join reference; rvalue dereference moves a result by value but leaves the stored object alive. Reading an error or reading a nonvoid slot before production reports a library error.

The slot has no atomic readiness wait and does not retain a producing frame. Read only after the corresponding join/call completion, and do not overwrite a live constructed result with another child. The void specialization stores only error state; its successful dereference performs no readiness check. Copy and move are not available.
