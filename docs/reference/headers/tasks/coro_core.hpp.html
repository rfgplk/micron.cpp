Type reference

micron::coro::worker

Defined in header <micron/tasks/coro_core.hpp>.

A cache-line-aligned scheduler record holding one worker's continuation deque and dispatch state.

Storage and constraints

The record contains a fixed or growable Chase-Lev deque, an owner-private overflow list, an active flag, resident fiber pointer, id, and inbox-poll cadence counter. Deque bottom operations belong to its worker; thieves use the steal interface. Direct field manipulation is scheduler-internal and does not transfer frame ownership. current_worker() returns the native thread's TLS record or null off-engine.

The engine owns the worker array and destroys it after joining workers. A borrowed record becomes invalid when runtime stop releases that array. Initial deque allocation and growth follow the selected queue's contracts; the worker object is not a user-level task handle.

[[gnu::always_inline]] inline std::coroutine_handle<>
__child_complete(__frame_base *child) noexcept
{
  __frame_base *parent = child->__parent;
  worker *w = __cur_worker;
  __frame_base *cont = (w != nullptr) ? w->deque.pop_bottom() : nullptr;
  // balanced pop
  if ( cont == parent && cont != nullptr && cont->__pushed_kind == __frame_base::__kind_fork ) return parent->__self;
  // detached
  const u32 r = parent->__joins.add_fetch(1, micron::memory_order_acq_rel);
  const bool ready = (r & __frame_base::__joiner_bit)
                     && (r & __frame_base::__credit_mask) == ((r >> __frame_base::__expected_shift) & __frame_base::__expected_mask);
  if ( cont != nullptr ) {
    if ( cont == parent ) return parent->__self;
    __count_take(cont);
    if ( ready ) {
      cont->__pushed_kind = __frame_base::__kind_plain;
      if ( w->deque.push_bottom(cont) ) [[likely]] {
        __notify_work();
      } else {
        // deque full
        // WARNING: __NEVER__ spin here; this thread is the only valid popper, so yielding cannot make room
        cont->__ovf_next = w->ovf;
        w->ovf = cont;
      }
      return parent->__self;
    }
    return cont->__self;
  }
  return ready ? parent->__self : std::noop_coroutine();
}
