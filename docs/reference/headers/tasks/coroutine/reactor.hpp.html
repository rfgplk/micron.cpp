micron::coro::io_stats_t

Defined in header <micron/tasks/coroutine/reactor.hpp>.

A value snapshot of aggregate coroutine-reactor activity counters.

Fields and observation

Fields count submits, enters, inline completions, SQ-full flushes, parks, wakes, and cancels. io_stats() sums relaxed-loaded per-ring counters with MICRON_CORO_STATS, otherwise returns zeros. The snapshot is not atomic across counters or rings. io_pending() similarly sums in-flight logical-operation counters; it is not a retained-task count or a stable completion fence. These APIs are present only with the reactor enabled.
