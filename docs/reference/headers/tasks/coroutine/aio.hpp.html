micron::coro::io::timeout

Defined in header <micron/tasks/coroutine/aio.hpp>.

A relative nanosecond timeout tag for a one-shot reactor operation.

Use

after(ns) returns this tag. Piping an unsubmitted one-shot awaitable into it returns a timed awaitable with the same operation/fixed-buffer requirement and a linked timeout SQE. Both SQEs are reserved together; failure returns an error instead of silently submitting untimed. It borrows all original operation data and does not own a descriptor or buffer.

micron::coro::io::mrecv_t

Defined in header <micron/tasks/coroutine/aio.hpp>.

An immovable owner of multishot-receive state whose kernel user_data points into the object.

Arm, consume, cancel

mrecv_arm requires the current worker's live ring and provided-buffer registration, returns 0 on successful submission, -95 for unsupported setup, -114 if already armed, or -105 for no submission room. mrecv_next awaits one event; inactive/drained state synthesizes -61. Only one consumer may await/pop this event queue.

mrecv_data(event) borrows the provided buffer when present; mrecv_recycle(event) returns it to its originating ring. Process each event and recycle its buffer exactly once, retaining data only until recycle. mrecv_live tests whether more kernel completions remain promised. mrecv_cancel and the live destructor synchronously cancel and drain before the state can die; they may wait indefinitely on kernel/reaper progress. Concurrent destruction, consume, and rearm are unsupported.
