micron::coro::discard_t

Defined in header <micron/tasks/quasi_pointer.hpp>.

An empty tag selecting evaluation without result storage for a bound fork or call.

Use

The inline constant coro::discard is passed to the fork/call binder. It suppresses destination storage, not execution, lifetime obligations, child joining, or error recording for structured forks. It allocates no memory and carries no cancellation state.
