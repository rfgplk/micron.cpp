micron::fixed_string

Defined in header <micron/string/fixed_string.hpp>.

Structural constexpr-capable char-array string used for literal template arguments and compile-time string transformations.

Size and storage

Stores public zero-initialized char buf[N]. Literal construction copies N bytes; pointer/count construction copies at most N-1 into the zero-initialized buffer. size/capacity/max_size report N-1, while len() scans the actual first null with a bound of N. begin/end delimit len() content, so iteration length need not equal size(). Public buffer_size is N and npos is the unsigned all-ones sentinel. Element/pointer/reference aliases use char and usize.

Operations and results

Find/rfind and set searches are constexpr loops; substring search can take O(n*m) comparisons and set search O(n*k). len() itself is O(N) and is recomputed by many operations. at checks against len, while operator[] is unchecked. Comparisons return strong_ordering or bool. to_lower/to_upper/trim/reverse return new fixed_string<N> values; substr<Pos,Cnt> returns fixed_string<Cnt+1> and checks the static buffer boundary. Concatenation returns fixed_string<A+B-1>, copying actual logical content rather than unused slots. No heap storage is used.
