micron::__old::sstring

Defined in header <micron/string/__old_sstring.hpp>.

Legacy unaligned inline string in the internal __old namespace, storing public T memory[N] and usize length.

Storage and behavior

Default construction zeroes N slots; copy/move operations copy inline storage, with moves clearing the source. Capacity is fixed and most checked edits reject a result reaching N. The interface includes byte/string searches, case/trim, replacement/removal, insertion, truncation, and copied substrings. Suffix movement uses bytemove with unscaled character counts, limiting full-width character editing behavior. Append and length updates often rely on existing zero slots; null_term explicitly restores a terminator.

Selection and complexity

It has no current sstring alignment policy, no dynamic growth, and no retained ownership outside the object. Copy/clear cost O(N); suffix shifts and direct substring comparisons have their corresponding linear/product costs. Use micron::sstring for the public inline-string interface. The legacy class remains separately named so reading its source does not imply that its behavior describes the current class.
