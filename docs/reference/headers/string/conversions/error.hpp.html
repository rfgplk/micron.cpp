Type reference

micron::format::parse_error

Defined in header <micron/string/conversions/error.hpp>.

Small parse-error value storing a nonnegative errno-style code.

Values and access

The explicit i32 constructor converts negative codes to their unsigned magnitude; default code zero means no error. Explicit bool reports code!=0 and message() looks up the code through micron::error::get_errno. parse_malformed uses invalid_arg for missing/invalid numbers or trailing input; parse_out_of_range uses not_representable for a consumed literal beyond the target range. The type owns no message string and performs no allocation.
