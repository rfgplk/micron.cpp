micron::__impl::digit_pair

Defined in header <micron/string/conversions/bits.hpp>.

Internal two-byte decimal digit record used by the ordinary integer conversion backend.

Digit tables

char d[2] stores a pair from 00 through 99 in the 100-entry __digit_tbl. Decimal u64 output divides into 10^8 groups and emits them through pairs; full-width 128-bit decimal output divides four 32-bit limbs by 10^9. Power-of-two radix output uses masks/shifts and other radices use division. These are implementation records rather than standalone string containers.

micron::__impl::max_digits

Defined in header <micron/string/conversions/bits.hpp>.

Internal specialized trait supplying conservative decimal temporary-buffer sizes for supported integer and character types.

value and requirements

Each specialization exposes static constexpr usize value; max_digits_v<I> forwards it. Values include sign/slack space and are not a query for an individual value's current digit count. Specialized types include the fixed-width integer family through u128/i128, applicable distinct long long forms, char/wchar_t, and c8/c16/c32. The primary template has no definition, so unsupported types do not acquire a generic fallback. Stack decimal conversion constraints use this bound plus a terminator slot.
