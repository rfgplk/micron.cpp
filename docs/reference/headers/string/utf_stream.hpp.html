micron::unicode::encoding

Defined in header <micron/string/utf_stream.hpp>.

Input-encoding selector for stream_decoder: automatic, utf8, utf16_le, or utf16_be.

Detection

Automatic mode inspects the initial four bytes, or all available final bytes. UTF-8/UTF-16 BOMs select and consume the matching signature. BOMless UTF-16 is recognized from the initial byte layouts for <?. Other ordinary input defaults to UTF-8. Automatic mode rejects UTF-32 BOM/signature forms as unsupported. Explicit encodings still process BOMs and reject an incompatible signature; this is byte-signature detection rather than a general XML encoding-declaration parser.

micron::unicode::decode_result

Defined in header <micron/string/utf_stream.hpp>.

Decoding result containing status, current-chunk consumption, decoded scalar, and original-stream byte offset.

Fields and lifetime

status defaults to need_input; consumed is a usize count of bytes taken from the current input argument, not the cumulative stream position; scalar is a u32 value meaningful on scalar status; byte_offset is a u64 offset into the original byte stream. Offsets include any skipped BOM. A result owns only values and can outlive both decoder and input. It contains no borrowed character span.

micron::unicode::stream_decoder

Defined in header <micron/string/utf_stream.hpp>.

Allocation-free value-type decoder retaining partial UTF-8/UTF-16 input and a small encoding-detection prefix between calls.

next and ownership

Construct with an encoding selector, automatic by default, and call next(input,size,final). Supply a readable size-byte range. Advance the caller's chunk pointer by result.consumed after every call and preserve unconsumed bytes. The initial probe may consume up to four bytes before returning its first scalar; later calls can return scalar with consumed==0 while draining that probe. Partial code units/scalars are copied into fixed decoder state, so already consumed chunks may be released. Each call returns at most one scalar.

Completion and errors

Set final when no later bytes will arrive. Exhaustion then yields done at a complete boundary or truncated for partial encoded input. Malformed continuation/surrogate/scalar values yield invalid. Errors are sticky: subsequent calls return the stored failure with zero consumption. Supplying extra input after done becomes invalid. No reset member is provided; construct a fresh decoder to restart. State is copyable for a checkpoint and is not synchronized for concurrent mutation.

Inspection and complexity

source_encoding and had_bom expose detection; byte_offset tracks cumulative bytes; at_scalar_boundary requires completed detection, drained probe, no pending scalar/unit, and a nonfinished state. advance_ascii advances the byte position for a separately validated UTF-8 ASCII run only at such a boundary, checking offset overflow. Total decoding is O(input bytes) with O(1) object storage and no heap allocation. Character normalization and grapheme segmentation are not performed.

constexpr bool
decode_utf8(const Character *input, usize size, usize &position, u32 &scalar) noexcept
{
  static_assert(sizeof(Character) == 1);
  if ( position >= size ) return false;
  const auto head = static_cast<u8>(input[position++]);
  if ( head < 0x80 ) {
    scalar = head;
    return true;
  }
  u32 count = 0, minimum = 0;
  if ( head >= 0xc2 && head <= 0xdf ) {
    scalar = head & 31;
    count = 1;
    minimum = 0x80;
  } else if ( head >= 0xe0 && head <= 0xef ) {
    scalar = head & 15;
    count = 2;
    minimum = 0x800;
  } else if ( head >= 0xf0 && head <= 0xf4 ) {
    scalar = head & 7;
    count = 3;
    minimum = 0x10000;
  } else
    return false;
  if ( count > size - position ) return false;
  while ( count-- ) {
    const auto byte = static_cast<u8>(input[position++]);
    if ( (byte & 0xc0) != 0x80 ) return false;
    scalar = (scalar << 6) | (byte & 63);
  }
