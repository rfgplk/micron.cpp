Type reference

micron::string_view

Defined in header <micron/string/string_view.hpp>.

Nonowning read-only half-open pointer pair selected from a source string type S.

Construction and lifetime

S must satisfy is_string; its const_pointer determines the stored pointer type. Construct from a C string, pointer pair, explicit char pointer/count, or compatible string object. Default and move constructors are deleted; copy construction/assignment copy only two pointers. There is no retained ownership or automatic terminator at the view boundary. Source destruction/reallocation invalidates the view. Equal-width cross-type constructors reinterpret pointers rather than transcode.

Operations and results

size/empty and element access are O(1); at/last check their relevant bounds. substr(a,b) uses an exclusive endpoint b, not a count; substr(a) requires a strictly interior start and rejects a==size. advance(n) likewise rejects advancing exactly to the end. set(source,n) views the suffix beginning at n, whereas the source/count constructor views a prefix. Assignment/set from an empty source leave the previous view unchanged. __advance/__move/__push perform unchecked boundary changes. No c_str member promises termination.

Member types

value_type is the pointed-to code-unit type; const_pointer and const_iterator are the selected const pointer; size_type is usize. cstring_view<S> is an alias of this same class, with no additional constness or ownership. Comparisons are lexicographic; char-specific interoperability is constrained to char values.
