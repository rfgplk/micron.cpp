micron::hstring

Defined in header <micron/string/string.hpp>.

Contiguous mutable heap string parametrized by scalar-literal element type, check flag, and allocator (allocator_small by default).

Storage and construction

The memory resource holds element pointer, logical length, and allocation capacity. Default and capacity constructors allocate a buffer and create an empty string; the one-argument numeric constructor reserves capacity rather than creating n characters. The count/character constructor creates repeated content. C-string/array construction copies text and most constructors explicitly write a terminator. Copy construction allocates from logical length; move transfers storage and empties the source. There is no inline small-string union or shared reference-counted buffer.

Access and modifiers

value_type=T, size_type=usize, pointer/iterator=T*, const_pointer/const_iterator=const T*, and reference/ref=T& with const-reference counterparts. Public category/contiguity/mutability/memory tags describe string, contiguous, mutable, heap storage. size and len are O(1); max_size is capacity. Mutable begin/end are also returned from const overloads, so this implementation does not uniformly enforce const iteration. cbegin/cend provide const pointers. operator& returns representation-byte storage rather than the object's address; operator* returns a chunk descriptor.

Growth and invalidation

Appending or inserting reserves logical length plus payload plus a terminator through the resource's recommended-capacity policy. Reallocation invalidates every borrowed pointer/view. Insertion repairs its own iterator argument after growth, but arbitrary aliased source ranges are not made into independent snapshots. clear zeroes capacity; fast_clear only changes length. resize(n,ch) grows with fill or truncates, while set_size/_buf_set_length publish a raw-buffer length without allocating. reserve and try_reserve share the same implementation.

Results and limits

find(character) and find_substr return indices/npos. substr(pos,count) uses a count, defaults to the remaining suffix, and allocates an independently terminated result. stack() copies into sstring<256,T> and rejects length >=255. Iterator at overloads return a pointer offset and use a fixed 0..256 check rather than the actual string length. Wide c_str/w_str/uni_str conversions are reinterpretations; they do not validate or transcode characters.
