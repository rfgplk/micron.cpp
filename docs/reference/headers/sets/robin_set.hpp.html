micron::robin_set

Defined in header <micron/sets/robin_set.hpp>.

A move-only fixed-capacity set retaining original keys in a Robin Hood hash table.

Capacity and operations

Alloc defaults to allocator_serial<>. Construction optionally requests a slot count, rounded upward to a power of two with at least 16 slots. max_size() is physical slots; new keys stop at floor(7*C/8) entries or the map's probe-distance limit. There is no reserve or growth API.

insert first checks membership and returns false for a duplicate; otherwise it inserts and returns true. Capacity and probe failures report the map's library error. emplace constructs a temporary K before insertion. contains, count, erase, clear, const iterators, and const-key for_each delegate to the map. Copying is explicitly deleted; movement transfers ownership.

Complexity

Membership is expected O(1) and subject to the backing map's probe bound. Insertion performs a preliminary lookup and Robin Hood insertion; erasure may shift a cluster. Their worst-case structural work is O(C). Clear and complete iteration scan C slots.

Iterator invalidation and use

Insertion may swap stored keys, and erasure shifts displaced keys. References and iterators into affected slots are not stable even though capacity is fixed. Choose this adapter for a planned maximum population when mutable set membership and original-key equality are required.
