Type reference

micron::posix::seccomp_data_t

Defined in header <micron/linux/sys/seccomp.hpp>.

System-call number, architecture, instruction address, and six u64 arguments inspected by seccomp filters.

Description

seccomp_notif_t adds request ID/PID/flags around that data. seccomp_notif_resp_t supplies the matching ID, signed result/error, and response flags. seccomp_notif_sizes_t reports kernel sizes. These are kernel protocol values; the raw notification helpers borrow a listener descriptor and request/response records without allocating a supervisor or validating request lifetime.
