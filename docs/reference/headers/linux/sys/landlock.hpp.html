micron::posix::landlock_ruleset_attr_t

Defined in header <micron/linux/sys/landlock.hpp>.

Handled filesystem/network rights and scoping fields for a Landlock ruleset.

Description

The size helper selects the ABI-supported prefix. landlock_path_beneath_attr_t is packed to 12 bytes and pairs allowed filesystem rights with a borrowed parent descriptor. landlock_net_port_attr_t pairs rights with a host-endian port number. Callers must query/select an appropriate ABI, initialize reserved fields, and distinguish handled rights from the rights granted by individual rules. The security module's policies build on these raw records.
