micron::prctl_mm_map

Defined in header <micron/linux/sys/prctl.hpp>.

Borrowed process-memory layout descriptor for the PR_SET_MM_MAP option.

Description

u64 fields describe code/data/heap/stack and argument/environment bounds, with an auxv pointer/size and executable descriptor. This is a kernel-control payload, not a mapped-memory owner. prctl zero-fills unused argument slots and accepts at most four option arguments; numeric pointer arguments must be passed in the required unsigned-long form.
