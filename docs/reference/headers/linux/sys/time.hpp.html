micron::timespec_t

Defined in header <micron/linux/sys/time.hpp>.

Seconds and nanoseconds record used by native clock/sleep/timer calls.

Description

tv_sec is time64 on all native targets; tv_nsec is native signed long on LP64 and i64 on width-32. Width-32 clock/timer paths select the time64 syscalls. timeval_t remains the legacy seconds/microseconds layout on 32-bit targets. itimerspec_t and itimerval_t pair an interval with a current/initial value in their corresponding units.

tms_t holds process/child CPU tick counters. timex_t holds clock-discipline fields; adjtimex success can be a nonzero clock state, and tai_offset returns its queried TAI value after checking negative errors. sigevent_t is a reduced notification record with value/signo/notify, without a full thread-callback notification union; it is not a complete libc sigevent replacement. The global micron::sigval_t here is distinct from posix::sigval_t.

inline clock_t
clock(void)
{
  timespec_t tm;
  if ( clock_gettime(clock_process_cputime_id, tm) != 0 ) return -1;
  // clock_t is width-32 on a width-32 target, so this wraps at ~36 min of cpu time -- the same
  // contract every libc has here; the cast says the narrowing is meant
