micron::posix::cap_hdr_t

Defined in header <micron/linux/sys/capabilities.hpp>.

Capability protocol header containing a version and target PID.

Description

cap_data_t stores one 32-bit word each of effective/permitted/inheritable bits. Version 3 operations use an array of two records; conversion helpers join/split the low and high halves of the u64 masks. These records do not include ambient or bounding sets, which require separate prctl operations.
