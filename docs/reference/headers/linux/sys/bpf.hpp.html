Type reference

micron::bpf::insn_t

Defined in header <micron/linux/sys/bpf.hpp>.

Eight-byte classic BPF instruction with opcode, true/false skip counts, and immediate operand.

Description

stmt and jump construct values without validating control flow, supported loads, or arithmetic. fprog_t borrows an instruction array and stores its u16 count. The constants describe classic BPF classes/sizes/modes/operations for the seccomp layer; this is not an eBPF program loader or verifier. The policy builder supplies a higher-level construction interface.
