micron::posix::sigaction_t

Defined in header <micron/linux/sys/signal.hpp>.

Userspace signal-action record converted to the selected kernel signal-action layout.

Description

The handler union stores a one-argument handler or SA_SIGINFO callback, alongside sa_mask, flags, and a restorer pointer. The wrapper supplies mandatory x86 restorer trampolines; ARM uses its kernel-provided restorer path. It converts the action around rt_sigaction rather than passing this userspace record unchanged.

sigset_t reserves 128 bytes, but rt_sig* calls use the kernel's eight-byte mask. Set operations address signal numbers directly without validating bounds; use valid positive signal numbers and initialize the record. sigemptyset clears all words while sigfillset and set combinations initialize only the kernel-relevant prefix. siginfo_t is the 128-byte tagged event payload; access the _sifields alternative appropriate to si_code/signal. sigval_t stores a queued integer or borrowed pointer. stack_t describes caller-owned alternate-stack storage; sigaltstack does not allocate it.

Equivalent definition
inline int
sigaction(int sig, const sigaction_t &action, sigaction_t *old)
{
  __syscall_sigaction_t __system_action = {};
  __syscall_sigaction_t __system_oldaction = {};

  __system_action.k_sa_handler = action.sigaction_handler.sa_handler;
  micron::voidcpy(&__system_action.sa_mask, &action.sa_mask, sizeof(posix::sigset_t));
  __system_action.sa_flags = (u32)action.sa_flags;
#if !defined(__micron_syscall_generic) && !defined(__micron_arch_arm32)
  // WARNING: amd64/i386 have no kernel-provided default restorer, so a userspace SA_RESTORER
  // trampoline is mandatory; arm32 (and arm64) GET a kernel restorer via the sigpage/vDSO;
  // installing a user Thumb restorer there is BROKEN
  __system_action.sa_flags |= 0x04000000;      // SA_RESTORER
  __system_action.sa_restorer = &restore_rt;
#endif
  // restorer
  int result
      = static_cast<int>(micron::syscall(SYS_rt_sigaction, sig, &__system_action, old ? &__system_oldaction : nullptr, __sig_syscall_size));
  if ( old && result >= 0 ) {
    old->sigaction_handler.sa_handler = __system_oldaction.k_sa_handler;
    micron::voidcpy(&old->sa_mask, &__system_oldaction.sa_mask, sizeof(posix::sigset_t));
    old->sa_flags = static_cast<u32>(__system_oldaction.sa_flags);
#if !defined(__micron_syscall_generic)
    old->sa_restorer = __system_action.sa_restorer;
#else
    old->sa_restorer = nullptr;
#endif
  }
  return result;
}
