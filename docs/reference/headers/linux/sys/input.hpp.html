Type reference

micron::posix::input_id_t

Defined in header <micron/linux/sys/input.hpp>.

Input-device bus/vendor/product/version identity, accompanied by evdev/uinput payload records.

Description

input_absinfo_t stores current value, range, fuzz, flat, and resolution. input_keymap_entry_t stores keycode plus bounded scancode bytes; input_mask_t stores event type, byte count, and a numeric user pointer. uinput_setup_t holds identity, an 80-byte name, and force-feedback capacity; uinput_abs_setup_t pairs an axis code with its absolute-axis description.

The global input_event stores timeval_t, u16 type/code, and signed value. Numeric event/button/key/axis constants are supplied separately by event_codes.hpp. These are plain ABI records and compile-time ioctl encoders; opening an input device, retaining buffers, and interpreting event frames belong to the caller or the input module.
