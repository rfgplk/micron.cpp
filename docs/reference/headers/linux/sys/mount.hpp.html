micron::posix::mount_attr_t

Defined in header <micron/linux/sys/mount.hpp>.

Explicit set/clear/propagation/user-namespace fields for mount_setattr.

Description

Fields default to zero, and userns_fd is a numeric descriptor rather than an owner. The call passes the record's size. mnt_ns_info_t separately describes a mount namespace with size, mount count, and namespace ID for nsfs ioctls. Namespace descriptor getters returning a new descriptor transfer responsibility for closing it to the caller; the scalar-record helpers do not manage that lifetime.
