Type reference

micron::key

Defined in header <micron/linux/process/keyctl.hpp>.

Copyable non-owning kernel key serial or special keyring selector.

Description

A zero ID is invalid; negative keyring_spec values are valid selectors. Destruction does not revoke, unlink, or invalidate a key. add_key/request/search return a zero key after a raw error and discard its errno. Other operations preserve raw status.

read, describe, and get_security return the kernel's required/true length, which can exceed the supplied buffer size. Do not treat a positive result as an in-bounds copied length without comparing it with capacity. key_perm is an OR-composable permission mask divided into possessor/user/group/other fields; keyring_spec identifies thread/process/session/user and request-related keyrings. The API adds constant local work and delegates lookup/lifetime to the kernel.
