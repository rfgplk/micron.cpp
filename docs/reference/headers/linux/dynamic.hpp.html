micron::host_dso

Defined in header <micron/linux/dynamic.hpp>.

Borrowed view of an already discovered host ELF module.

Description

Construction finds an existing host module by soname and throws if absent. The default is empty. sym resolves a defined symbol through the module's dynamic metadata; sym_as casts the result without checking a callable signature. Copies do not pin or retain a host mapping. The registry metadata and module code/data must remain alive for every retained pointer, path, or soname view.

Related types and selection guide.

micron::dso

Defined in header <micron/linux/dynamic.hpp>.

Move-only owning native ELF handle with soname or explicit-path construction.

Description

Each instance owns an independent mapping through elf::handle_t; it does not deduplicate or share dlopen-style references. Destruction releases the handle, and moving transfers it. Symbol pointers are borrowed from that mapping and expire on destruction/replacement. Use host_dso to inspect a module already owned by the host, and the dynamic module registry when its explicit reference/dependency protocol is required.

Related types and selection guide.
