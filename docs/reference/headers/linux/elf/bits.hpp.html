micron::elf::fmt_class

Defined in header <micron/linux/elf/bits.hpp>.

ELF file-class selector with invalid, elf32, and elf64 values.

Related scalar types

fmt_data selects invalid, lsb, or msb encoding. addr32/off32/word are u32; addr64/off64/xword are u64; sword/sxword are signed 32/64-bit; half is u16. These describe file field widths, not ownership or validated addresses. native_class/native_data derive from target definitions.
