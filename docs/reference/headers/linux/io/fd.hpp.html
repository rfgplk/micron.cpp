micron::posix::fd_t

Defined in header <micron/linux/io/fd.hpp>.

A copyable, non-owning Linux descriptor/error integer.

Representation and lifetime

The only field is i32 fd. Default construction produces 0, not the invalid sentinel; invalid_fd is -1. open() and bool test fd >= 0; closed() tests exactly -1; invalid() tests any negative number. has_error() returns the unsigned magnitude of a negative value. reset() stores -1 without closing. Destruction, copying, and moving do not close, duplicate, or transfer an OS resource.

Comparison, integer conversion, arithmetic, and increment/decrement operate only on the stored number. Arithmetic can accidentally select another descriptor and is subject to signed overflow. A copied fd_t aliases the same open file description; external close/reuse invalidates that interpretation for all copies. close(fd_t&) resets even after a close error; the raw-int close overload cannot reset a caller's variable. Use an owner when scope-based close is required.
