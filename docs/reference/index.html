micron reference

The micron reference describes the library’s facilities, function overloads, and headers. Choose a section below, browse the function, header, and symbol indexes, or search by name.

This reference is self-contained and can be opened from a local filesystem.

Language support

Types and language supportFundamental types, configuration definitions, byte order, and the foundation header. Include the specific facility needed by a translation unit.
Build configurationPreprocessor definitions and build modes select library facilities at compile time. Define a configuration macro consistently before including the headers that use it.
Type traits and conceptsCompile-time predicates, transformations, constraints, comparison utilities, and container tags.
Ranges, iterators, and viewsRange and iterator utilities and sequence views. Ownership and storage are properties of the particular type; inspect the selected type before retaining a pointer into it.
Functions, tuples, and sum typesCallable wrappers, tuples, sum types, matching, and control-flow utilities.
Errors and exceptionsError values, exception types, allocation operators, and process termination support. Availability of exception handling depends on build configuration.
ReflectionCompile-time reflection helpers. These interfaces require the compiler and build options required by the C++ reflection implementation.

Containers and strings

ArraysFixed-size and specialized array containers, including mutable, immutable, persistent, and multidimensional forms.
VectorsDynamically sized and fixed-capacity sequence containers. The vector family includes mutable, immutable, persistent, concurrent, and segmented variants.
StringsCharacter sequences, string views, formatting, and numeric conversions.
MapsAssociative containers for keys and values, including Robin Hood, hopscotch, Swiss, persistent, and tree-backed forms.
TreesTree containers include B-trees, red-black trees, and radix-based structures. The selected type determines key ownership and traversal order.
QueuesFIFO containers and concurrent queues, including single-producer/single-consumer and multi-producer/multi-consumer forms.
StacksLast-in, first-out containers with fixed, dynamic, immutable, and concurrent variants.
HeapsPriority containers and related heap structures, including binary, Fibonacci, binomial, and quake heaps.
SetsKey-only associative containers, including immutable and Swiss-table variants.
ListsLinked sequences provide node-based storage and iterator traversal.

Algorithms

AlgorithmsAlgorithms operate on iterator ranges or containers, depending on the overload. The lazy algorithms have a separate section.
Functional algorithmsFunctional operations transform, select, combine, and reduce container contents. The selected operation determines its result container and error behavior.
Lazy algorithmsPull-based views in micron::lz compose with operator|. A view chain is evaluated when a terminal consumes it.
SortingSorting and selection algorithms in micron::sort. Overloads accept containers or iterator ranges as specified by the algorithm.
HashingHash functions, checksums, and hash types for byte sequences and values. Select the function and seed required by the data format or container.
Regular expressionsCompiled regular-expression matching and capture results.

Memory management

AllocationAllocation interfaces expose byte chunks, allocators, memory resources, and the abcmalloc allocator. A chunk describes an address and length; it does not release the allocation on destruction.
Memory operationsMemory copying, movement, filling, comparison, and address utilities. Select the overload according to whether its count is expressed in elements or bytes.
Pointer utilitiesOwnership and observation wrappers for dynamically managed objects.

Concurrency

Atomic operationsAtomic values, operations, and memory-order selections for synchronization between execution contexts.
Mutexes and locksMutexes, guards, barriers, and other locking primitives.
SynchronizationSynchronization utilities include semaphores, futures, channels, latches, and yield operations.
ThreadsThread objects, thread groups, pools, scheduling, and CPU affinity. Backend selection depends on the build configuration.
Parallel algorithmsParallel execution helpers and algorithms for applying operations to ranges and work items.
Tasks and coroutinesCoroutine tasks, executors, and asynchronous coordination facilities.

Input and output

Input and outputDescriptors, files, streams, formatted output, serialization, and filesystem operations. Low-level data-path operations report byte counts or negative error values.
Files and filesystemFile handles, paths, directory traversal, filesystem operations, and whole-file helpers.
Asynchronous file I/OThe micron::io::flash interfaces use io_uring for file operations. The available operation tier depends on kernel capabilities and successful ring initialization.
SerializationSerialization facilities frame data and reconstruct values from byte sequences or files.
Terminal controlTerminal-control sequences and ANSI formatting helpers.
Input devicesInput-device abstractions, event decoding, key mapping, polling, virtual devices, and Wayland input sources. Availability depends on the host environment.
Coroutine I/OCoroutine-oriented file, pipe, filesystem, and stream operations. The coroutine and I/O backends must be available in the selected build.

Numerics and mathematics

Mathematical functionsScalar and packed mathematical functions, numeric types, and specialized mathematical facilities. Subsections describe their respective data structures and algorithms.
Numeric typesComplex, rational, decimal-conversion, and reduced-precision floating-point facilities.
Symbolic expressionsSymbolic expression storage, operations, and evaluation support.
Packed mathematical functionsPacked mathematical functions operate on vector values using the available compile-time SIMD backend.
Arbitrary-precision integersArbitrary-precision integer arithmetic and low-level multi-precision limb operations.
BLASVector and matrix operations in micron::math::blas, including level 1, 2, and 3 operations and supported dispatch variants.
Matrices and linear algebraMatrix types and linear algebra operations, including decompositions and systems of equations.
GraphsGraph representations, traversal, paths, connectivity, flows, matching, and graph I/O.
Fourier transformsFourier transforms, transform plans and workspaces, frequency helpers, and convolution.
Random numbersRandom-number engines, distributions, and random sampling facilities.
IntegrationNumerical quadrature, derivatives, cubature, and integration workspaces.
Splines and interpolationInterpolation and spline construction, evaluation, and differentiation.
GeometryGeometric primitives, transformations, projections, and spatial calculations.
ManifoldsEmbedded manifolds, Lie groups, tangent-space operations, and metrics.
Quantities and quaternionsVectors, quantities, and quaternion operations for rotations and related computations.
Sparse matricesSparse matrix representations, conversion, and arithmetic.
Computation graphsStatic-shape computation graphs, reusable storage, and executors for numeric workloads.

System interfaces

Date and timeClocks, durations, calendar calculations, parsing, formatting, and time-zone facilities.
WebAssembly targetThe wasm32 target provides a linear-memory allocator and a host ABI for diagnostics, clocks, randomness, and execution. Threaded builds require the corresponding host and shared-memory support.
Linux interfacesLinux types, system-call interfaces, process operations, and low-level operating-system facilities. Individual interfaces can depend on kernel support and process permissions.
SecuritySecurity policies and Linux security interfaces, including seccomp, namespaces, Landlock, and SELinux helpers. Kernel support and process privileges determine which operations are available.
Dynamic loadingDynamic-module loading, symbol lookup, and module metadata.
ELFELF image loading, execution, and symbol inspection facilities.
Module attachmentEntry points and argument structures used for attaching modules and continuations. These interfaces are enabled by their corresponding build definitions.

Graphics

GraphicsGraphics abstractions and platform support, with OpenGL and Vulkan interfaces in their respective subsections.
OpenGLOpenGL-facing types, operations, and platform integration. The corresponding graphics implementation and context must be available at runtime.
VulkanVulkan-facing types, functions, allocation callbacks, and loader integration. The corresponding Vulkan implementation must be available at runtime.

SIMD

SIMDPacked vector types, operations, and compile-time architecture selection. Available operations depend on the target and enabled instruction-set features.

Implementation notes

Implementation notesInternal headers implement architecture selection, compiler support, low-level dispatch, and runtime machinery. Names beginning with __ are implementation details. Public interfaces are indexed under their owning modules.
